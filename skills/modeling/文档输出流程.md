# 文档输出流程

> 论文生成的最后一步：将 Markdown 论文转化为可提交的 .docx / .pdf 文档。
> 嵌入位置：`skills/modeling/数学建模完整流程.md` 阶段 8 之后 → 新增阶段 8.5

---

## 输出格式选择

```
paper/论文初稿.md（Markdown）
    ↓
    ├──→ .docx 路线：python-docx 格式化写入
    │     └── 输出：paper/Word/论文终稿.docx
    │
    └──→ .pdf 路线：LaTeX 编译 或 pandoc 转换
          └── 输出：paper/LaTeX/论文终稿.pdf
```

| 格式 | 适用场景 | 优势 | 劣势 |
|------|----------|------|------|
| .docx | CUMCM/GMCM 国赛 | 官方模板为 .doc | 公式排版不如LaTeX |
| .pdf | MCM/ICM 美赛 | 最终提交格式，排版精美 | 需要 LaTeX 环境 |
| .md→.docx | AI 辅助快速生成 | 自动化程度高 | 复杂公式需手动调 |

---

## .docx 生成流程（推荐路线）

### 步骤 1：准备模板

使用官方 .doc 模板，通过 python-docx 读取并保留样式。

### 步骤 2：逐模块写入

```
模块顺序（与论文结构一致）：
  封面页 → 摘要 → 问题重述 → 问题分析 → 模型假设 → 符号说明
  → 模型建立 → 模型求解 → 结果分析 → 模型评价 → 参考文献 → 附录
```

### 步骤 3：格式规范

| 元素 | 格式 |
|------|------|
| 一级标题 | 黑体 三号 居中 |
| 二级标题 | 黑体 四号 左对齐 |
| 正文 | 宋体 小四 1.5倍行距 |
| 公式 | 居中，编号右对齐（LaTeX公式转OMML） |
| 表格 | 三线表，标题在上 |
| 图片 | 嵌入，标题在下，≥300dpi |
| 页码 | 底部居中 |

### 步骤 4：公式处理

Markdown 中的 LaTeX 公式需转为 OMML（Office Math Markup Language）：
- 行内公式：`$...$` → `<m:oMath>...</m:oMath>`
- 独立公式：`$$...$$` → `<m:oMathPara>...</m:oMathPara>`

### 步骤 5：图表嵌入

从 `results/图表/` 读取生成的 PNG/JPG 图片，按论文中的引用顺序嵌入。

---

## 质检清单

```
□ 所有公式正确渲染（OMML 或 MathType）
□ 图片清晰度 ≥ 300 dpi
□ 表标题在上，图标题在下
□ 页码连续
□ 目录已更新
□ 参考文献格式统一
□ 无空行/多余空格
□ 中文无乱码（字体嵌入）
□ 文件大小 < 50MB
```
