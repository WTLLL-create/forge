# 模型选择决策树

> 能力定义：在「题型识别」完成后，AI 根据问题特征在决策树中行进，最终输出具体的模型选择方案及其理由。
> 本文件回答数学建模中最关键的问题——**"为什么选择这个模型？"**
>
> **参考实现**：选定模型后，ML 方法的具体 API 和 Pipeline 使用见 `models/sklearn_integration.md`

---

## 使用方式

```
题型识别结果 + 问题具体特征
        ↓
沿决策树逐级判断
        ↓
抵达叶子节点（具体模型）
        ↓
输出：模型名称 + 选择理由 + 验证方案
```

每个分支节点的判断规则不超过 3 个条件，确保 AI 能快速决策。

## 总入口：核心诉求判断

```
题目的核心诉求是什么？
│
├─ 推断未知数值 ──→ 进入 [决策树 A：预测]
├─ 比较/排序/打分 ──→ 进入 [决策树 B：评价]
├─ 找最优方案 ──→ 进入 [决策树 C：优化]
├─ 划分样本类别 ──→ 进入 [决策树 D：分类]
├─ 发现数据内在分组 ──→ 进入 [决策树 E：聚类]
├─ 描述物理过程 ──→ 进入 [决策树 F：机理建模]
└─ 多诉求混合 ──→ 拆分为子问题，分别入对应树
```

## 决策树 A：预测

```
是否有明确的时间维度（历史→未来）？
│
├─ 是 ──→ 时间序列预测
│   │
│   ├─ 数据点 < 30？
│   │   └─ 是 → GM(1,1) 灰色预测
│   │         理由：小样本下，灰色系统比统计方法更稳定。
│   │         验证：后验差比 C < 0.35 为合格。
│   │
│   ├─ 数据点 30-200，有明显季节性？
│   │   └─ 是 → SARIMA
│   │         理由：季节性自回归移动平均，自动处理周期模式。
│   │         验证：残差白噪声检验（Ljung-Box p > 0.05）。
│   │
│   ├─ 数据点 30-200，无明显季节性？
│   │   └─ 是 → ARIMA / Holt-Winters
│   │         理由：ARIMA 适合平稳或差分后平稳的序列。
│   │         验证：AIC/BIC 值对比，选择最小者。
│   │
│   └─ 数据点 > 500？
│       └─ 是 → LSTM / Prophet
│             理由：大数据量下深度学习可捕捉复杂非线性。
│             验证：训练集/验证集 loss 曲线不分离（无过拟合）。
│
└─ 否 ──→ 非时序预测
    │
    ├─ 有大量输入特征（>10 个）？
    │   ├─ 非线性关系明显？
    │   │   └─ 是 → XGBoost / 随机森林
    │   │         理由：决策树集成方法自动捕捉非线性交互，无需特征工程。
    │   │         验证：5 折交叉验证 RMSE，特征重要性排序合理。
    │   │
    │   └─ 需解释每个因素的影响？
    │       └─ 是 → 多元线性回归（逐步回归）
    │             理由：系数直接表示边际影响，可做显著性检验。
    │             验证：R² > 0.7、各变量 p < 0.05、VIF < 10。
    │
    └─ 特征少（<5 个），有物理公式参考？
        ├─ 公式已知 → 参数估计（最小二乘法拟合公式参数）
        │             验证：拟合优度 R²、残差正态性。
        └─ 公式未知 → 多项式回归 / 样条回归
                      验证：交叉验证选择最优阶数。
```

## 决策树 B：评价

```
有专家可以给出两两比较的重要性判断吗？
│
├─ 是 ──→ AHP（层次分析法）
│         理由：专家经验可直接转化为判断矩阵，CR<0.1 保证一致性。
│         验证：一致性比率 CR = CI/RI < 0.1。
│         适用：指标少（<7 个），有领域专家。
│
└─ 否 ──→ 指标值是否可以直接从数据中提取？
    │
    ├─ 是 ──→ 有多少个评价对象？
    │   │
    │   ├─ 少量（<10）→ 熵权法 + TOPSIS
    │   │   理由：熵权法根据数据离散度分配客观权重；
    │   │        TOPSIS 基于"贴近理想解"排名，几何直观。
    │   │   验证：排序结果是否与常识一致；
    │   │         权重改变 ±10% 后排序是否稳定。
    │   │
    │   └─ 大量（>50）→ 秩和比法 (RSR)
    │        理由：适合大规模排序，结果可分级（优/良/中/差）。
    │        验证：RSR 值分布是否接近正态。
    │
    └─ 否 ──→ 指标描述含模糊/定性语言？
        │
        └─ 是 → 模糊综合评价
              理由：将"较好""一般"转为隶属度，适合定性指标量化。
              验证：不同隶属函数下结果是否一致。
              适用：教学质量评估、满意度调查类题目。
```

### 评价类模型补充规则

| 场景 | 直接推荐 | 理由 |
|------|----------|------|
| 要同时考虑收益和成本 | DEA 数据包络分析 | 多输入多输出效率评价的标准方法 |
| 指标间存在相关性 | 主成分分析(PCA) + TOPSIS | 先降维消相关，再评价 |
| 需要给出分级而非精确排名 | 秩和比法(RSR) | 自动分档，结果易懂 |
| 多人主观评分，存在个体偏差 | Z-score 标准化校准 + 可靠性加权 | 先消除评委偏差再排名，Kendall tau + Shapley 验证 |

## 决策树 C：优化

```
Step 1: 决策变量是连续的还是离散的？
│
├─ 连续 ──→ 目标和约束是否都是线性的？
│   ├─ 是 → 线性规划（单纯形法）
│   │       验证：影子价格分析、灵敏度报告。
│   └─ 否 → 非线性规划
│           验证：KKT 条件检验、多起点搜索避免局部最优。
│
└─ 离散 ──→ Step 2: 变量取值范围多大？
    │
    ├─ 小（≤15 个变量，状态数可枚举）──→ Step 3a
    │   ├─ 问题有最优子结构？→ 动态规划
    │   │   验证：小规模实例 vs 枚举法验证。
    │   └─ 否则 → 整数规划（分支定界）
    │       验证：gap = (UB-LB)/UB < 5%。
    │
    └─ 大（不可枚举）──→ Step 3b
        ├─ 问题可建模为图？
        │   └─ 是 → 图论算法
        │          ├─ 最短路径 → Dijkstra / Floyd / A*
        │          ├─ 最大流 → Ford-Fulkerson
        │          └─ TSP 变体 → 蚁群 / 遗传
        │          验证：小规模 vs 精确解对比。
        │
        └─ 通用组合优化 ──→ 问题性质？
            ├─ 目标是单目标吗？
            │   ├─ 是 → 遗传算法 / 模拟退火
            │   │       验证：多次运行取统计结果；
            │   │             收敛曲线是否趋于平稳。
            │   └─ 否（多目标）→ NSGA-II / 加权单目标
            │           验证：Pareto 前沿是否均匀分布；
            │                 Hypervolume 指标。
            │
            └─ 有群体智能特征？
                └─ 是（路径/调度）→ 蚁群算法 / 粒子群
                    验证：与遗传算法对比结果。

### 优化算法选择速查表

| 算法 | 何时优先选择 | 何时避免 |
|------|-------------|----------|
| 线性规划 | 所有关系都是线性的 | 任何非线性关系 |
| 整数规划 | 离散变量且范围小 | 变量超过 100 个 |
| 动态规划 | 阶段明显、状态可递推 | 状态空间爆炸 |
| Dijkstra | 正权图最短路径 | 有负权边 |
| 遗传算法 | NP-hard、编码自然 | 必须得到精确解 |
| 模拟退火 | 需要逃离局部最优 | 时间非常紧张 |
| 蚁群算法 | TSP/VRP 及其变体 | 非路径类问题 |
| NSGA-II | 多目标且需看权衡 | 目标可合并为单目标 |
```

## 决策树 D：分类

```
样本量 vs 特征数的关系？
│
├─ 样本数 >> 特征数（>10倍）→ 有标签数据？
│   ├─ 是 → 线性可分？
│   │   ├─ 是 → 需要概率输出？
│   │   │   ├─ 是 → Logistic 回归（二分类）/ softmax（多分类）
│   │   │   │       验证：混淆矩阵、ROC-AUC > 0.8。
│   │   │   └─ 否 → LDA 线性判别
│   │   │           验证：投影后类间距离/类内距离比最大。
│   │   └─ 否 → 非线性边界
│   │         ├─ 高维数据 → SVM (RBF核)
│   │         │   验证：不同 C/γ 参数下的网格搜索。
│   │         └─ 表格数据 → 随机森林 / XGBoost
│   │             验证：OOB 误差、特征重要性。
│   └─ 否（无标签）→ 转决策树 E: 聚类
│
└─ 样本数 << 特征数（高维小样本）
    └─ 先 PCA 降维，再选 SVM/Logistic
        理由：高维下距离度量失效，必须先降维。
        验证：降维后方差解释率 > 85%。
```

## 决策树 E：聚类

```
已知要聚成几类？
│
├─ 是 ──→ 类是球形分布？
│   ├─ 是 → K-means
│   │       验证：肘部法确定 K、轮廓系数 > 0.5。
│   └─ 否 → GMM（高斯混合模型，EM 算法）
│           理由：软聚类（概率归属），适合边界模糊的情况。
│           验证：BIC/AIC 选择分量数。
│
└─ 否 ──→ 数据量大小？
    ├─ 大数据（>10万）→ DBSCAN（密度聚类）
    │   理由：不需要预设 K，能发现任意形状簇，自动标记噪声点。
    │   验证：调整 eps/minPts 看聚类数是否合理。
    └─ 中数据 → 层次聚类
        理由：生成树状图，可根据需要切割任意层数。
        验证：树状图结构是否与领域知识一致。
```

## 决策树 F：机理建模

```
有已知的物理学/化学/生物学方程？
│
├─ 是 → 方程是 ODE（常微分）还是 PDE（偏微分）？
│   ├─ ODE → 有解析解？
│   │   ├─ 是 → 直接推导解析式
│   │   │       验证：带入初值检验。
│   │   └─ 否 → Runge-Kutta (ode45) 数值求解
│   │           验证：改变步长，结果收敛。
│   │
│   └─ PDE → 边界条件是否规则？
│       ├─ 规则 → 有限差分法 (FDM)
│       │       验证：网格加密，结果收敛（Richardson 外推）。
│       └─ 不规则 → 有限元法 (FEM)
│               验证：不同网格划分下的稳定性。
│
└─ 否 ──→ 从文献查找领域标准方程
          → 补充题给数据确定参数
          → 灵敏度分析确定关键参数
          → 数值求解（同上面分支）
          验证：模型预测 vs 实测数据对比。
```

## 模型选择的通用验证规则

无论选择什么模型，都需通过以下验证：

| 验证维度 | 方法 | 通过标准 |
|----------|------|----------|
| **准确性** | 测试集误差指标（MAE/RMSE/准确率） | 优于基线模型 10% 以上 |
| **稳定性** | 交叉验证 / 多次运行统计 | 标准差 < 均值的 15% |
| **可解释性** | 变量重要性/系数显著性 | 关键变量与常识一致 |
| **鲁棒性** | 敏感性分析（输入±10%扰���） | 输出变化 < 20% |

## 模型选择 Failover 机制（参考 LangGraph 条件路由思想）

> 来源：langchain-ai/langgraph（~37.8k stars）— 状态图 + 条件边 + 检查点设计模式。
> 当首选模型不满足要求时，AI 应自动降级到备选方案。

### Failover 规则

```
首选模型选择完成
    │
    ▼
【Checkpoint 1】数据条件是否满足最低要求？
    ├─ 满足 → 继续
    └─ 不满足 → 自动降级（如 ARIMA→GM(1,1)）
    │
    ▼
模型求解
    │
    ▼
【Checkpoint 2】求解是否收敛？
    ├─ 收敛 → 继续
    └─ 不收敛 → 换备选算法（如 BFGS→Nelder-Mead）
    │
    ▼
【Checkpoint 3】验证指标是否达标？
    ├─ R²>0.7 / 准确率>基线 → 通过
    ├─ 0.4<R²≤0.7 → 警告但可用（论文标注局限）
    └─ R²<0.4 → 触发重评估（回到决策树重新选模型）
```

### 典型降级路径

| 场景 | 首选 | 降级条件 | 降级方案 |
|------|------|---------|---------|
| 时间序列 | ARIMA | 数据点<30 | GM(1,1) |
| 非线性优化 | BFGS | 无梯度 | Nelder-Mead |
| 分类 | 随机森林 | 样本<200 | Logistic |
| 聚类 | K-means | 轮廓系数<0.3 | DBSCAN |
| 线性规划 | linprog | 不可行 | 放松约束+罚函数 |

## 优化问题子类型识别（参考 OR-Tools 分类体系）

> 来源：google/or-tools（~11k stars）— "问题类型 × 求解方法" 二维分类。

在决策树 C（优化）入口处，先判断子类型：

```
优化问题 → 根据关键词确定子类型:
│
├─ "路线/路径/配送/巡回" → 路径规划 (VRP/TSP)
│   工具: linear_sum_assignment / milp
│
├─ "装入/分配/容器/背包" → 装箱/背包 (Bin packing)
│   工具: milp (0-1整数规划)
│
├─ "排班/调度/时间表" → 调度 (Scheduling)
│   工具: milp + 自定义约束
│
├─ "资源分配/产量/配比" → 资源分配
│   工具: linprog / minimize
│
└─ "选址/布局/位置" → 选址 (Facility Location)
    工具: milp
```
