# 数学建模论文章节级写作自查清单

> 用途：论文写作/修改阶段的章节级自查 reference。加载本清单后，逐章对照
> 检查；每章给出「核心任务 / 必查项 / 常见失分」。写作规范借鉴
> zLanqing/codex-claude-academic-skills 的 writing_checklists 与
> Adkid-Zephyr/anti-defensive-writing-Skill 的发布会原则；失分点对齐
> `skills/review/math-modeling/常见失分问题.md`。
> 数字事实一律使用 ModelResult 绑定（info_class=original/confirmed），
> 禁止静态文本携带数字；推断/建议类表述须显式标注（info_class=inferred/suggestion）。

## 0. 通用写作规范（每章适用）

- 论文是发布会，不是项目总结：只讲最强优势，不自我削弱（禁"遗憾的是/效果有限/有待进一步完善"）。
- 模糊词必须配数字：禁"显著提升/较好/一定程度"而无测量值。
- 因果句必须有验证证据：禁"证明了/必然导致"而缺检验、灵敏度、对比或误差分析。
- 数字只来自 ModelResult：论文中每个数字都能在 `model_result.json` 找到来源。

## 1. 摘要（≤1 页，2026 规范）

**核心任务**：让评阅人 1 分钟看懂「问题—方法—结果—结论」。
**必查项**：
- [ ] 四要素齐备：针对的问题、建立的模型/算法、关键数值结果（含单位）、结论与建议
- [ ] 每个数字可溯源（绑定 ModelResult）
- [ ] 无自我削弱、无模糊词、无因果过度声明
- [ ] 不超过 1 页，无公式推导细节
**常见失分**：摘要写成背景介绍；结果只给结论不给数；出现未在正文出现的数字。

## 2. 问题重述与分析

**核心任务**：用自己的话复述问题，提炼待解决的子问题，明确数据口径。
**必查项**：
- [ ] 重述不照抄原题，突出关键约束与目标
- [ ] 明确假设前提与数据来源（数据文件、采样点、单位）
- [ ] 划分子问题时逻辑自洽（并列/递进）
**常见失分**：大段抄题；数据口径混乱（单位、时间窗、样本量不一致）。

## 3. 模型假设

**核心任务**：列出使模型成立的必要假设，并说明合理性。
**必查项**：
- [ ] 假设数量适中（过多显牵强，过少显粗糙）
- [ ] 每个假设有依据或说明（实际背景/数据支撑）
- [ ] 假设与后续建模一致（未用到的假设不写，用到的假设不漏）
**常见失分**：假设无依据；假设与模型脱节；把明显不合理的假设硬写。

## 4. 模型建立

**核心任务**：给出变量定义、模型表达式、约束条件与求解思路。
**必查项**：
- [ ] 符号表/变量定义清晰（公式变量有说明）
- [ ] 模型公式正确、量纲一致、边界条件明确
- [ ] 模型选择有理由（为何用该模型而非其他）
- [ ] 参数来源可追溯（拟合数据/文献/经验值，标注 info_class）
**常见失分**：公式堆砌无解释；参数凭空设定；模型与问题目标脱节。

## 5. 模型求解

**核心任务**：说明求解算法、工具与关键步骤，保证可复现。
**必查项**：
- [ ] 算法步骤清晰（含收敛条件/停止准则）
- [ ] 求解代码随附录提交且可运行（可复现）
- [ ] 数值结果与代码输出一致（结果回填，禁止手抄）
**常见失分**：只给结果不给算法；代码不可运行；结果与代码输出不一致。

## 6. 模型检验（评阅重点）

**核心任务**：证明模型可靠——误差分析、灵敏度/稳健性、对比验证。
**必查项**：
- [ ] 有误差指标（RMSE/MAE/相对误差）且数值可溯源
- [ ] 有灵敏度或稳健性检验（参数扰动、样本扰动）
- [ ] 有对比基线或合理性解释
- [ ] 检验结论与因果表述匹配（不夸大）
**常见失分**：无检验章节；检验与结果矛盾；用"效果较好"代替具体误差。

## 7. 模型评价与改进

**核心任务**：客观评价模型优缺点，给出改进方向（不自我否定）。
**必查项**：
- [ ] 优点用证据支撑（对比/数值）
- [ ] 缺点表述为"边界条件/适用场景"而非自我削弱（发布会原则）
- [ ] 改进方向是 suggestion 类（info_class=suggestion），不冒充已实现结果
**常见失分**：缺点写成"遗憾地效果有限"；改进方向写成已实现的结果。

## 8. 参考文献与附录

**核心任务**：文献真实可核验；附录支撑材料完整。
**必查项**：
- [ ] 每条文献格式规范（作者/标题/来源/年份；DOI 可核验）
- [ ] 无编造文献（DOI 经 CrossRef 核验或标注待核验）
- [ ] 附录含：支撑材料文件清单、可运行源码、AI 工具使用详情（如适用）
- [ ] 参考文献之前已放置 AI 工具使用声明（2026 规定）
**常见失分**：文献不可查；附录缺源码；漏放 AI 声明。
