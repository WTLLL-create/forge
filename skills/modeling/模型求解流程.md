# 模型求解流程

> 模型选择完成后 → 形式化 → 准备参数 → 调用求解器 → 输出结果
>
> 本文件定义从"选了什么模型"到"得到数值结果"的标准 5 步流程。
>
> **参考实现**：数值求解的 SciPy API 详见 `numerical_computing/scipy_integration.md`；
> ML 模型求解的 sklearn API 详见 `models/sklearn_integration.md`

---

## 总览

```
模型选择决策树 输出：模型名称
    │
    ▼
Step 1: 模型形式化     → 数学表达式（变量/参数/目标/约束）
    │
    ▼
Step 2: 参数准备       → 参数值 + 数据准备
    │
    ▼
Step 3: 求解方法选择   → 匹配 numerical_computing / data_processing 能力
    │
    ▼
Step 4: 运行求解       → 可复现实验记录
    │
    ▼
Step 5: 结果输出       → 数值 + 图表需求 + 解释文本
```

## Step 1: 模型形式化

### 输入
模型名称（来自 `模型选择决策树.md` 的叶子节点）

### 输出
标准数学表达式，包含：变量定义、参数定义、目标函数、约束条件

### 各模型的形式化模板

#### 线性规划 (Linear Programming)

```
变量: x = [x₁, x₂, ..., xₙ]  (决策变量)
参数: c (目标系数), A (约束矩阵), b (约束右端项)
目标: min cᵀx  (或 max)
约束: Ax ≤ b, x ≥ 0
调用: scipy.optimize.linprog(c, A_ub=A, b_ub=b, bounds=...)
```

#### 非线性优化 (Nonlinear Programming)

```
变量: x = [x₁, ..., xₙ]
参数: 初始值 x₀
目标: min f(x)
约束: g(x) ≤ 0, h(x) = 0, lb ≤ x ≤ ub
调用: scipy.optimize.minimize(f, x₀, method=..., bounds=..., constraints=...)
```

#### 曲线拟合 (Curve Fitting)

```
变量: θ = [θ₁, ..., θₖ]  (待定参数)
数据: (x_i, y_i), i=1,...,n
目标: min Σ(y_i - f(x_i; θ))²
调用: scipy.optimize.curve_fit(f, x_data, y_data, p0=θ₀)
```

#### 线性方程组 (Linear System)

```
变量: x = [x₁, ..., xₙ]
参数: A (n×n 矩阵), b (n×1 向量)
方程: Ax = b
调用: numpy.linalg.solve(A, b)
```

#### 常微分方程 (ODE)

```
变量: y(t) = [y₁(t), ..., yₙ(t)]
参数: 初值 y(t₀) = y₀, 时间跨度 [t₀, t_end]
方程: dy/dt = f(t, y)
调用: scipy.integrate.solve_ivp(f, [t₀, t_end], y₀, method=...)
```

#### 时间序列预测 (ARIMA/GM)

```
变量: 未来 m 期的预测值 ŷ
数据: 历史序列 y₁, y₂, ..., y_T
调用:
  - ARIMA: statsmodels.tsa.arima.model.ARIMA
  - GM(1,1): 自定义累加生成 + 最小二乘
```

#### 评价模型 (AHP/TOPSIS/熵权法)

```
变量: n 个对象的 m 维评分
参数: 指标权重 w (主观/客观)
流程:
  1. 数据标准化 (data_processing → zscore)
  2. 计算权重 (AHP 判断矩阵 / 熵权法)
  3. 加权综合评分
  4. 排序
调用: numpy 矩阵运算 + 自定义逻辑
```

## Step 2: 参数准备

### 检查清单

| 检查项 | 来源 | 典型问题 |
|--------|------|----------|
| 参数值是否已知？ | 题目给出 / 数据估计 / 文献 | 题给参数往往不完整 |
| 数据是否已清洗？ | `data_processing/workflow.md` | 缺失值/异常值/类型错误 |
| 初始值是否合理？ | 物理意义 / 先验知识 | 随机初始可能导致不收敛 |
| 边界条件是否完整？ | 题目约束 + 物理限制 | 遗漏隐含约束 |
| 单位是否统一？ | 数据检查 | km vs m, 元 vs 万元 |

### 参数来源优先级

```
1. 题目直接给出          → 直接使用，论文标注"题给参数"
2. 从数据中估计          → 标注估计方法（OLS/MLE/矩估计）
3. 从文献中引用          → 标注引用来源
4. 基于先验知识设定      → 标注"根据经验/行业标准设为..."
5. 敏感性分析确定        → 标注"通过敏感性分析，取 X 范围中 Y 值"
```

## Step 3: 求解方法选择

### 映射表

| 模型类型 | 求解方法 | 对应 Skill 模块 | API |
|----------|---------|----------------|-----|
| 线性规划 | 单纯形/内点法 | numerical_computing | `scipy.optimize.linprog` |
| 非线性优化 | BFGS/SLSQP/Nelder-Mead | numerical_computing | `scipy.optimize.minimize` |
| 曲线拟合 | Levenberg-Marquardt | numerical_computing | `scipy.optimize.curve_fit` |
| 线性方程组 | LU 分解 | numerical_computing | `numpy.linalg.solve` |
| 特征值问题 | QR 迭代 | numerical_computing | `numpy.linalg.eig` |
| ODE 求解 | Runge-Kutta | numerical_computing | `scipy.integrate.solve_ivp` |
| 积分计算 | 自适应求积 | numerical_computing | `scipy.integrate.quad` |
| 统计检验 | t/F/χ² 检验 | numerical_computing | `scipy.stats` |
| 时间序列 | ARIMA/指数平滑 | 外部库 | `statsmodels` |
| 灰色预测 | GM(1,1) | 自定义 | 累加+最小二乘 |
| 评价模型 | 加权求和 | numerical_computing | `numpy` 矩阵运算 |
| 聚类 | K-means/DBSCAN | 外部库 | `sklearn.cluster` |
| 分类/回归 | RandomForest/XGBoost | 外部库 | `sklearn` |

### 备选/降级方案

当首选求解器失败时（见 `建模任务状态管理.md` Failover 机制），自动使用：
- 梯度方法失败 → 无梯度方法（Nelder-Mead）
- 局部最优不满足 → 全局优化（differential_evolution）
- 求解不收敛 → 换初始值或简化模型

## Step 4: 运行求解

### 实验记录格式

每次求解应记录（供论文和复现）：

```
【实验记录】
日期: 2026-07-29
模型: 线性规划 (linprog, HiGHS 求解器)
输入参数:
  - c = [300, 200]
  - A_ub = [[2, 4], [3, 1]]
  - b_ub = [100, 80]
  - bounds = [(0, None), (0, None)]
结果:
  - x_opt = [22.0, 14.0]
  - f_opt = -9400 (利润 = 9400)
  - 求解状态: 成功
  - 迭代次数: 2
验证:
  - 约束满足: ✓
  - KKT 条件: ✓
  - 敏感性分析: 目标系数 ±10% 范围内方案稳定
```

## Step 5: 结果输出

### 输出三要素

| 要素 | 内容 | 论文位置 |
|------|------|----------|
| **数值结果** | 最优解、预测值、评分排名、参数估计值 | 正文"结果分析"章节 |
| **图表需求** | 趋势图、对比柱状图、帕累托前沿、热力图 | 正文"可视化"部分 |
| **解释文本** | 结果含义、实际意义、与常识一致性检验 | 正文"结果讨论" |

### 输出检查

- [ ] 数值结果是否在合理范围内？（物理可行性检验）
- [ ] 是否标注了单位？
- [ ] 是否保留了有效数字？（一般 3-4 位）
- [ ] 图表标题和坐标轴标签是否完整？
- [ ] 解释文本是否用中文写出，适合直接放进论文？
