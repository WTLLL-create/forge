# 模型替代规则（Model Substitution Rules）

> 专家不会死磕一个模型。模型失败后，不是"换个模型试试"，而是"根据失败原因，走向特定的替代"。
> 对接 Stage 27.2 model_diagnosis → 本文件提供"失败→替代"的预定义路径。

---

## 一、预测模型替代链

```
ARIMA 失败了？
  ├─ 原因：非平稳且差分无效 → 转监督学习(RF+Lag特征) 或 LSTM(Nt>500)
  ├─ 原因：强非线性 → RF+Lag(N>200) / LSTM(Nt>500)
  ├─ 原因：多变量 → VAR(Nt>50) / 监督学习(N>200)
  ├─ 原因：Nt<30 → GM(1,1) / 指数平滑
  └─ 原因：数据右删失 → Tobit回归 / 放弃时序，转截面模型

RF 失败了？
  ├─ 原因：过拟合 → 降max_depth + 正则化（留在RF）
  ├─ 原因：外推需求 → 机理模型 / 线性回归 / GM(1,1)
  ├─ 原因：N太小(<100) → SVR + PCA降维
  ├─ 原因：忽视时序结构 → 构造Lag/滑动特征后重新RF
  └─ 原因：精度到天花板 → XGBoost (N>500)

XGBoost 失败了？
  ├─ 原因：过拟合 → RF（更稳定），或降低max_depth
  ├─ 原因：训练太慢 → 降n_estimators + early_stop
  ├─ 原因：解释性不足 → RF+SHAP / GAM
  └─ 原因：数据太少 → RF（XGBoost需要更多数据）

LSTM 失败了？
  ├─ 原因：过拟合（Nt<500）→ ARIMA/Prophet/RF+Lag
  ├─ 原因：不收敛 → 简化网络(1层LSTM+Dropout50%)
  ├─ 原因：解释性需求 → 放弃LSTM，用RF+Lag+SHAP
  └─ 原因：训练太慢 → Prophet（快速基线）
```

## 二、优化模型替代链

```
LP 失败了？
  ├─ 原因：无可行解 → 松弛约束 + 报告松弛后的解
  ├─ 原因：非线性 → LP近似 + GA精调 / 直接用NLP
  └─ 原因：退化 → 加小扰动 + 报告替代解

MIP 失败了？
  ├─ 原因：求解时间爆炸 → LP松弛→启发式→报告最优性间隙
  ├─ 原因：精确解不可行 → 变量重构（减少整数变量）
  └─ 原因：约束太复杂 → CP-SAT(ortools) / 约束规划

GA 失败了？
  ├─ 原因：不收敛 → 增大N_GEN + 检查适应度函数
  ├─ 原因：早熟收敛 → 增大变异概率 + 多起点 + 小生境GA
  ├─ 原因：所有解不可行 → 改进编码方式 + 罚函数调参
  ├─ 原因：可精确求解 → 回到LP/MIP（不应该用GA）
  └─ 原因：解不稳定 → 多起点 + 报告均值±标准差

NSGA-II 失败了？
  ├─ 原因：前沿退化 → 检查代理模型质量 + 报告退化原因
  ├─ 原因：目标无冲突 → 加权求和（Pareto没必要）
  ├─ 原因：前沿不均匀 → 目标值标准化 + 调整拥挤距离
  └─ 原因：3+目标 → NSGA-III / MOEA/D
```

## 三、评价模型替代链

```
TOPSIS 失效了？
  ├─ 原因：排名无区分度 → 检查指标是否冗余(PCA) + 换灰色关联
  ├─ 原因：结果不稳定 → 三维敏感性分析（可能留在TOPSIS）
  ├─ 原因：有定性指标 → 模糊综合评价
  └─ 原因：样本太少(<5) → 灰色关联分析

AHP 失效了？
  ├─ 原因：CR>0.1 → 调整判断矩阵 / 换客观赋权（熵权）
  ├─ 原因：无专家 → 熵权法 / CRITIC法
  └─ 原因：指标太多(>12) → 先PCA降维再AHP

熵权法 失效了？
  ├─ 原因：指标变异度都差不多 → CRITIC法
  └─ 原因：需要主客观结合 → AHP+熵权组合赋权
```

## 四、分类模型替代链

```
SVM 失败了？
  ├─ 原因：训练太慢（N>10000）→ LinearSVC / Logistic
  ├─ 原因：强噪声 → 降低C（更多容错） / RF
  ├─ 原因：极度不平衡 → SMOTE + 代价敏感SVM
  └─ 原因：线性不可分 + RBF也不行 → RF / XGBoost

RF Classification 失败了？
  ├─ 原因：极度不平衡 → SMOTE + class_weight='balanced'
  ├─ 原因：需要概率 → 检查是否 calibrate（可用CalibratedClassifierCV）
  └─ 原因：小样本 → 朴素贝叶斯 / LDA
```

## 五、使用方式

```
Stage 27.2 诊断出模型失败 + 根因
    ↓
查本文件 → 按"模型 + 失败原因"找到替代路径
    ↓
验证替代模型是否可用（查 model_selection_matrix 确认条件匹配）
    ↓
重新进入 Stage 27.1 决策流程
```

    ↓

    ↓

    ↓
