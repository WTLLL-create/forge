# 线性规划 (LP) — 专家知识卡

> **一句话定位**：优化类问题的"第一关检查"。能用 LP 绝不用启发式——审稿人一定会问"为什么不直接用线性规划？"
> **决策入口**：任何优化问题 → 先检查是否能写成 LP 形式

---

## 1. LP 可解的判定（三问）

```
一问：目标函数是决策变量的线性组合吗？
  max/min c₁x₁ + c₂x₂ + ... + cₙxₙ
  没有 x₁×x₂, x², sin(x), log(x) ?

二问：所有约束是决策变量的线性不等式/等式吗？
  a₁x₁ + a₂x₂ + ... ≤ b
  没有非线性项？

三问：决策变量连续吗（可以取任意实数）？
  不是整数、不是0-1？

三问全 ✓ → LP，用单纯形法/内点法，有全局最优解保证。
```

---

## 2. 专家判断速查

| 条件 | 方法 | 求解器 |
|------|------|--------|
| 三问全 ✓ | LP — 单纯形/内点 | scipy.optimize.linprog(method='highs') |
| 有整数变量 + 变量<100 | MIP — 分支定界 | scipy.optimize.milp |
| 变量>10000 | LP — 内点法 | 专用求解器（Gurobi/CPLEX） |

---

## 3. 常见失败

| 症状 | 含义 | 处理 |
|------|------|------|
| 无可行解 | 约束冲突 | 松弛最不关键的约束，报告"原问题不可行，松弛后..." |
| 无界解 | 漏了约束 | 检查约束完整性 |
| 多最优解（退化） | 约束冗余 | 报告解不唯一，展示替代方案 |

## 6. vs 启发式算法的态度

```
如果问题能用 LP 精确求解而你用了 GA：
→ 评委第一反应："为什么不直接用线性规划？"
→ 回答必须是技术性的（不能用"GA 更通用"这种话搪塞）
→ 如果无法回答 → 论文直接扣分

只有在以下情况才放弃 LP：
1. 目标函数或约束确实非线性（有证据）
2. 规模太大精确求解不可行（有定量证明）
3. 问题天然是组合优化（整数变量 >1000）
```
