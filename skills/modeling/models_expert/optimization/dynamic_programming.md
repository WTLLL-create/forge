# 动态规划 (DP) — 专家知识卡

> **一句话定位**：当问题具有最优子结构和重叠子问题时的精确求解利器。比 GA/PSO 强大得多——因为它保证全局最优。
> **决策入口**：问题可分解为递推阶段 + 每阶段决策只依赖当前状态

**适用**：背包问题、最短路径、资源分配、多阶段决策、排产调度(小规模)

**不适用**：状态空间爆炸(维度灾难)、无最优子结构、连续变量(离散化后精度损失)

**论文必须展示**：状态定义(数学描述)、状态转移方程、边界条件、复杂度分析 O(状态数×决策数)

**论文表达**："该问题具有最优子结构——第k阶段的最优决策仅依赖于第k-1阶段的状态。定义状态 [s_k]，状态转移方程 [公式]，边界条件 [公式]。DP 求解复杂度为 O([分析])，保证了全局最优性。"
