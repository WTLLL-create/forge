# MIP/MILP — 专家知识卡

> **一句话定位**：有整数/0-1变量的 LP。关键判断不是"能不能用"，而是"规模是否在精确求解范围内"。
> **决策入口**：LP + 至少一个整数变量

---

## 1. 规模判断

```
变量数 < 100 + 约束 < 500：
  → 分支定界精确求解 ✓

变量数 100-1000：
  → 先求 LP 松弛得到下界
  → 再求启发式可行解得到上界
  → 上下界差距 < 5% → 可以接受启发式解
  → 差距 > 5% → 论文讨论"最优性间隙"

变量数 > 1000：
  → 放弃精确解
  → 启发式 / 元启发式
  → 论文论述"精确求解不可行"
```

---

## 2. 经典适用场景

| 场景 | 典型问题 | 变量类型 |
|------|----------|:---:|
| 选址 | 在N个候选点选K个建仓库 | 0-1 |
| 排产/调度 | 多订单分配到多机器 | 0-1 + 整数 |
| 运输 | 货量分配到车辆 | 整数 |
| 背包 | 选哪些物品能装下且价值最大 | 0-1 |

---

## 3. 常见失败

| 症状 | 原因 | 处理 |
|------|------|------|
| 求解时间指数增长 | MIP 是 NP-hard | 限制求解时间 + 报告最优性间隙 |
| 松弛解与整数解差距大 | 问题"整数性"强 | 加有效不等式(cutting planes)缩小间隙 |
| 内存溢出 | 分支定界树太大 | 限制节点数 / 用启发式 |

---

## 4. 论文表达

```
该问题包含 [整数/0-1] 决策变量，属于混合整数规划，是 NP-hard 问题。
变量总数=[X]，约束数=[Y]，规模 [小/中/大]。

[小规模]：使用分支定界法精确求解，得到全局最优解。
[大规模]：先求LP松弛得下界 [Z_LB]，再用遗传算法得启发式上界 [Z_UB]。
最优性间隙 = (Z_UB-Z_LB)/Z_LB = [Y%]，
表明启发式解与理论最优的差距在可接受范围内。
```
