# NSGA-II — 专家知识卡

> **一句话定位**：多目标优化的事实标准。不是"多目标就上 NSGA-II"，而是"目标确实冲突且权重未知→用 Pareto 揭示权衡"。
> **决策入口**：≥2个目标 + 目标冲突 + 无先验权重

---

## 1. 决策入口（三问）

```
一问：几个目标？
  1个 → 单目标优化，不用 NSGA-II
  ≥2个 → 继续

二问：目标之间冲突吗？
  一个变好 → 另一个变差？
  是 → 需要 Pareto ✓
  否 → 加权求和即可，不必用 NSGA-II

三问：有先验权重吗？
  有（如题目给出"排放权重40%，成本60%"）→ 加权求和，不必用 NSGA-II
  无 → 用 NSGA-II，让数据说话 ✓
```

---

## 2. 专家检查清单（论文中必须覆盖）

```
□ 编码方式：决策变量如何编码为染色体？
  - 实数编码（连续变量）→ SBX交叉 + 多项式变异
  - 排列编码（排序问题）→ PMX/顺序交叉
  - 二进制编码（0-1变量）→ 均匀交叉 + 位翻转

□ 约束处理：不可行解如何惩罚？
  - 罚函数法：约束违反量加入目标函数
  - 约束支配：可行解总是支配不可行解
  - 论文必须说明惩罚系数如何确定

□ 收敛判定：
  - Pareto前沿不再移动？
  - 超体积指标收敛？
  - 论文必须给收敛图

□ Pareto前沿分析（NSGA-II的核心价值）：
  - 前沿的形状（凸/凹/线性）说明了什么权衡特征？
  - 膝盖点在哪里？意味着什么？
  - 极端点对应的决策方案是什么？
```

## 3. 常见失败模式

| 症状 | 根因 | 修复 |
|------|------|------|
| Pareto前沿退化（所有点重叠） | 代理模型不准确 / 约束过严 / 右删失 | 诊断代理模型质量 + 报告退化原因（这本身就是发现） |
| 前沿不收敛 | 代数不够 / pop 太小 | 增加 N_GEN ≥ 100, POP ≥ 80 |
| 前沿不均匀 | 拥挤距离算子失效 | 检查目标值尺度差异 → 标准化目标值 |
| 所有解都不可行 | 约束过严 / 编码不支持可行解 | 松弛约束 / 改进编码方式 |

## 5. 创新改进方向

| 改进 | 适用 | 论文表达 |

| NSGA-II + 代理模型 | 目标函数评估昂贵 | "使用RF代理函数替代真实目标评估，加速优化" |
