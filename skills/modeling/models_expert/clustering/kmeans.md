# K-Means — 专家知识卡

> **一句话定位**：最通用的聚类方法。但聚类不是为了聚类——而是为了"分而治之"。
> **决策入口**：需要将数据分组以便后续分层/分群处理

---

## 1. 专家核心认知：K-Means 在竞赛中不是目标，是手段

```
❌ "本文使用K-means将数据分为4类"
   → 评委：所以呢？

✅ "审计发现不同工况下排放-功率关系差异显著（图X），
   这意味着单一全局模型无法胜任。
   因此，本文先用K-means识别4种典型工况，
   再为每种工况独立训练代理模型。
   肘部法（图Y）+轮廓系数（0.72）支持K=4的选择。"
   → 评委：聚类有动机、K有依据、后续有应用
```

---

## 2. K值选择

| 方法 | 做法 | 论文表达 |
|------|------|----------|
| 肘部法 | SSE vs K 曲线，找拐点 | "SSE在K=4后下降趋缓→K=4" |
| 轮廓系数 | 计算每个K的silhouette score | "K=4的轮廓系数(0.72)最高→K=4" |
| Gap Statistic | 与随机数据的差距 | "Gap在K=4达到峰值→K=4" |
| 业务知识 | K=工况数/分类数（题目给定） | "根据[题目描述]，分为[N]类" |

**必须同时使用≥2种方法**，否则K值选择缺依据。

---

## 3. 常见失败

| 症状 | 根因 | 修复 |
|------|------|------|
| 每次聚类结果差异大 | 初始中心随机 + N小 | 固定random_state + 多次运行 |
| 有些簇几乎没有样本 | K太大 | 减K + 合并小簇 |
| 轮廓系数全程<0.3 | 数据无强聚类结构 | 论文说明"数据连续性高，聚类仅用于粗分" |
| 高维数据聚类失效 | 欧氏距离在高维失去意义 | PCA降到2-3维再聚类 |

---

## 4. 创新方向

| 改进 | 做法 | 论文表达 |
|------|------|----------|
| K-means + PCA | 先降维后聚类 | "先PCA去相关→在低维空间聚类，避免高维距离失效" |
| K-means + GMM | 软聚类替代硬聚类 | "GMM允许样本以概率属于多类，比K-means硬分配更精细" |
| 聚类 + 标签应用 | 聚类结果作为下游模型输入 | "将聚类标签作为新特征→下游模型利用群组信息" |
| 聚类 + 可视化 | t-SNE 2D投影 | "t-SNE图验证聚类结果在低维空间中确实形成明显群组" |
