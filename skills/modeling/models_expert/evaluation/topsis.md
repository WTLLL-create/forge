# TOPSIS — 专家知识卡

> **一句话定位**：评价类问题的排序标准方法。但 TOPSIS 只是打分工具，指标体系才是论文的灵魂。
> **决策入口**：多个对象 + 多个可量化指标 + 需要排序

---

## 1. 专家核心判断：TOPSIS 不是问题，指标体系才是

```
普通做法：
  随便选几个指标 → 熵权 → TOPSIS → 排名 → 结束
  → 评委问："你的指标体系有什么依据？"

专家做法：
  目标层 → 准则层 → 指标层 → 逐个定义(公式+来源+方向性)
  → 赋权(有理由) → TOPSIS → 排名 → 三维敏感性分析
  → 评委看到："三层指标体系、有理有据、结果鲁棒"
```

---

## 2. 适用范围与不适用范围

| 条件 | 能否用 | 说明 |
|------|:---:|------|
| 指标均可量化 | ✅ | TOPSIS 基础要求 |
| 有模糊/定性指标 | ⚠️ | 先模糊化再 TOPSIS |
| 指标高度相关 | ⚠️ | 先 PCA 再 TOPSIS，否则重复计算 |
| 样本量极小 (<5) | ❌ | 灰色关联分析更适合 |
| 只需分类不需排序 | ❌ | 聚类+评价更合适 |

---

## 3. 常见失败

| 症状 | 根因 | 修复 |
|------|------|------|
| 排名与直觉不符 | 指标方向性弄反 | 逐个检查正向/负向/中间型/区间型 |
| 结果不稳定 | 权重不稳健 | 三维敏感性分析 |
| 正负理想解距离区分度低 | 指标冗余 | PCA 降维 |
| TOPSIS得分集中在0.4-0.6 | 对象间差异小 | 论文中说明"对象本质接近" |
