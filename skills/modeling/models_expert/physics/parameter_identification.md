## 决策入口

**什么时候需要参数辨识？**

| 条件 | 判断 |
|------|:---:|
| 有物理/机理模型，但部分参数未知 | 是 → 辨识 |
| 有实验/观测数据可用 | 是 → 数据足够 |
| 参数数量 < 数据点数量 ÷ 10 | 是 → 可辨识 |

→ **三个"是" → 参数辨识是连接机理模型和实验数据的桥梁**

---

## 方法选择决策树

```
参数数量？
├── 1-2 个 → 最小二乘 (scipy.optimize.least_squares)
│           直接拟合，稳定可靠
│
├── 3-10 个 → 非线性最小二乘 + 多起点
│             防止局部最优
│
├── >10 个 → 贝叶斯估计 / 正则化
│           避免过拟合
│
└── 参数有先验范围 → 有界优化
    scipy.optimize.minimize(method='L-BFGS-B')
```

## 为什么选这个？

| 方法 | 适用 | 不适用 |
|------|------|--------|
| **最小二乘** | 线性参数/小噪声/1-3参数 | 强非线性/多局部最优 |
| **非线性最小二乘** | 残差可导 | 参数多(>10)→过拟合 |
| **贝叶斯估计** | 有先验知识/需不确定性 | 先验未知→退化为MLE |
| **遗传算法** | 全局最优/不可导 | 计算量>100× 最小二乘，仅当其他方法失败 |
| **网格搜索** | 参数少(<3)+离散 | 连续参数→精度不足 |

**铁律**: "能用最小二乘绝不用GA —— 物理参数辨识通常是光滑连续的"

## 必须验证

- [ ] **残差无系统性偏差** — 残差 vs 预测值图中无 U 型/趋势
- [ ] **R² > 0.90** — 至少解释 90% 的方差
- [ ] **参数物理合理性** — k>0, h>0 等（辨识出负数则建模错误）
- [ ] **多起点一致性** — 5 个不同初值收敛到同一组参数（<1%差异）
- [ ] **置信区间** — 报告每个参数的标准误差（`result.jac` 可计算）

## 常见失败模式

| 失败 | 症状 | 根因 | 修复 |
|------|------|------|------|
| 参数不可辨识 | 多个初值收敛到不同结果 | 参数间强相关 | 固定部分参数/增加实验条件 |
| 过拟合 | R²_train=0.99, R²_test=0.6 | 参数太多 | 减少参数/正则化/交叉验证 |
| 初值敏感 | 某些初值不收敛 | 目标函数非凸 | 多起点 + 物理合理初值 |
| 负参数 | h_identified < 0 | 模型结构错误 | 加参数约束 or 重新建模 |

## 与纯统计模型的区别

| 对比维度 | 参数辨识 | 纯统计模型 |
|------|------|------|
| 模型来源 | 物理定律推导 | 数据拟合 |
| 参数含义 | 物理可解释（k是导热系数） | 统计量（β是回归系数） |
| 外推能力 | ✅ 物理保证 | ⚠️ 仅插值范围 |
| 数据需求 | 少（校准用） | 多（训练用） |
| 论文加分 | 高（展示物理理解） | 中 |
