# Geometry Mechanism Model — 几何机理专家卡

> model_family: physics | 子类型: geometry_modeling
> 典型题目: 2015 A 太阳影子, 2024 A 板凳龙, 2016 A 系泊系统(几何部分)

---

## 决策入口

| 条件 | 判断 |
|------|:---:|
| 核心关系是空间几何而非物理过程？ | 是 → 几何模型 |
| 涉及角度/距离/坐标变换/投影？ | 是 |
| 不需要守恒律(质量/能量/动量)？ | 是 — 用几何代替物理方程 |

→ **几何建模的三个层次**:

| 层次 | 复杂度 | 工具 |
|:---:|------|------|
| L1 解析几何 | 直线/圆/球/三角形 关系 | 向量运算 |
| L2 坐标变换 | 旋转/平移/投影 (2D↔3D) | 旋转矩阵/四元数 |
| L3 微分几何 | 曲线弧长/曲率/Frenet标架 | 数值积分 |

## 核心方法

### L1: 解析几何 — 太阳影子问题

```
太阳位置 → 天球坐标 (高度角h, 方位角A)
          → 地面坐标系
          → 杆的影子长度 L = H / tan(h)
          → 影子方向 = A + 180°

关键公式:
  sin(h) = sin(φ)sin(δ) + cos(φ)cos(δ)cos(ω)
  其中: φ=纬度, δ=赤纬, ω=时角

反问题: 已知 L(t) 序列 → 反推 (φ, δ) → 纬度+日期
         → 严重不适定, 需多时刻+多假设
```

### L2: 坐标变换 — 板凳龙问题

```
每个队员的身体 = 刚体, 受前一队员位置约束
→ 递推: 队员_i 位置 = f(队员_{i-1} 位置, 弯曲角度限制)
→ 坐标系: 全局XY → 局部切线-法线 (Frenet标架)

关键约束:
- 相邻队员距离固定
- 转弯半径 ≥ R_min (避免碰撞)
- 螺线/圆弧的参数方程
```

## 不适用

| 场景 | 原因 | 替代 |
|------|------|------|
| 过程中有能量/力 | 纯几何不够 | structural_mechanics |
| 数据驱动预测 | 几何无学习能力 | ML模型 |
| 高维参数空间 | 解析几何难处理 | 数值优化 |

## 必须验证

- [ ] 坐标变换一致性 (正变换→逆变换=恒等)
- [ ] 几何约束无违反 (距离/角度在可行域内)
- [ ] 反问题适定性评估 (是否唯一解？如否则需报告不确定性)

## 论文表达模板

```
（天球几何）太阳位置由高度角h和方位角A确定, h通过球面三角公式计算。
（反问题）由影子长度反推位置是一个典型的几何逆问题——
         单一时刻无法唯一确定(纬度+日期)组合, 需多时刻联合反演。
（不确定性）本文识别出参数空间的多个可行域, 并通过附加假设缩小范围。
```
