# Fluid Process Model — 流体过程专家卡

> model_family: physics | 子类型: fluid_dynamics
> 典型题目: 2019 A 高压油管, 2015 A 油管压力

---

## 决策入口

| 条件 | 判断 |
|------|:---:|
| 问题涉及液体/气体在管道/容器中流动？ | 是 → 流体模型 |
| 压力、流速、密度是核心变量？ | 是 |
| 流动是层流(Re<2300)还是湍流？ | 竞赛中通常假设层流简化 |

→ **两条简化路线选一条**:

| 路线 | 适用 | 不适用 |
|------|------|------|
| **管路系统模型** | 管长>>管径, 压力-流量关系为主 | 需详细速度场 |
| **伯努利+连续方程** | 稳态、无粘/低粘、重力影响显著 | 长管路摩擦不可忽略 |

---

## 核心方程

### 管路系统 (一维非稳态)

```
∂ρ/∂t + ∂(ρv)/∂x = 0           (质量守恒)
∂(ρv)/∂t + ∂(ρv²+P)/∂x = -λρv²/(2D)  (动量守恒，含摩擦)

简化假设:
- 不可压缩: ρ=constant → 连续性自动满足
- 长管路: 轴向速度均匀
- 摩擦系数 λ (Darcy-Weisbach)
```

### 伯努利方程 (稳态简化)

```
P₁/ρg + v₁²/(2g) + z₁ = P₂/ρg + v₂²/(2g) + z₂ + h_loss

适用条件: 稳态 + 不可压缩 + 沿流线
典型应用: 油箱→管道→喷口 的压力转化
```

---

## 不适用

| 场景 | 原因 | 替代 |
|------|------|------|
| 湍流主导 | 摩擦模型复杂化 | CFD简化或经验公式 |
| 复杂几何(弯头/阀门) | 一维假设失效 | 局部阻力系数经验修正 |
| 仅需稳态结果 | 非稳态过度设计 | 伯努利方程 |

## 必须验证

- [ ] 质量守恒 (进出口流量差 <1%)
- [ ] 压力在安全范围内
- [ ] Re数计算 (确认层流假设成立)
- [ ] 时间步长满足 CFL (如有非稳态求解)

## 论文表达模板

```
本文基于一维非稳态管路模型描述高压油管内的压力动态。
模型考虑了燃油的可压缩性和管壁摩擦, 假设轴向速度均匀(Re≈1800, 层流成立)。
通过质量守恒和动量守恒联立求解, 得到喷油周期内的压力-时间曲线。
```
