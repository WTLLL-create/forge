# Mechanism Model — 机理建模专家卡

> model_family: physics | 适用题型: A题（工业过程/能量系统/动力系统）

---

## 决策入口

**三问判定**：

1. 问题是否涉及物理/化学/生物过程？→ 是
2. 是否有可用的守恒律（质量/能量/动量）？→ 是
3. 是否有实验/观测数据可供校准？→ 是/否

→ **三个都是"是" → 机理建模是首选路线**

---

## 适用条件

| 条件 | 说明 |
|------|------|
| 过程可微分 | 系统行为可用微分/代数方程描述 |
| 参数物理可解释 | k, c, α 等参数有物理含义，非纯统计量 |
| 边界条件已知 | 初始值/边界值可从题目获取 |
| 不需要大量历史数据 | 与数据驱动互补——机理模型在小数据场景下更可靠 |

## 不适用

| 场景 | 原因 | 替代方案 |
|------|------|----------|
| 过程完全未知 | 无法写出方程 | 纯数据驱动（RF/XGBoost） |
| 参数无法测量/校准 | 机理模型不可辨识 | 纯统计模型 |
| 维度极高 | 数值求解不收敛 | 降维+代理模型 |
| 仅需预测，不关心机制 | 机理模型过度设计 | 时序预测（ARIMA/LSTM） |

---

## 标准建模流程

```
1. 识别守恒律
   质量守恒 / 能量守恒 / 动量守恒 / 电荷守恒
        ↓
2. 写出控制方程
   微分方程 / 代数方程 / 差分方程
        ↓
3. 确定边界条件 + 初始条件
        ↓
4. 参数辨识（如果参数未知）
   最小二乘 / 贝叶斯估计 / 优化方法
        ↓
5. 数值求解
   有限差分 / 有限元 / Runge-Kutta
        ↓
6. 实验验证
   R² / RMSE / 残差分析
```

## 必须验证

- [ ] 量纲检查（方程两边量纲一致）
- [ ] 参数物理合理性（k>0, c>0 等）
- [ ] 网格独立性（加密网格后结果变化 <5%）
- [ ] 与实验/观测数据对比（R²>0.9）
- [ ] 敏感性分析（关键参数 ±20% 的影响）

---

## 常见失败模式

| 失败 | 症状 | 根因 | 修复 |
|------|------|------|------|
| 方程过于简化 | 预测与实验偏差 >20% | 忽略了关键物理过程 | 增加能量损失/非线性项 |
| 数值不收敛 | 残差振荡/发散 | 网格太粗/时间步太大 | 细化网格/减小Δt |
| 参数不可辨识 | 多个参数组合拟合效果相同 | 参数间强相关 | 固定部分参数/增加实验条件 |
| 过度复杂 | 求解时间数小时 | 全耦合3D模型 | 降维（对称性→一维/二维） |

## 论文表达模板

```
（开篇矛盾）XX过程的核心在于YY物理机制与ZZ工程约束之间的耦合。
（建模路径）本文基于能量守恒定律建立了...
（参数意义）模型中k表示对流换热系数, c为比热容——而非统计拟合参数。
（验证方式）模型预测与实验数据对比R²=0.97，残差无系统性偏差，
           表明模型捕捉了主要物理过程。
（局限性讨论）模型假设一维传热，忽略了边缘效应（<2%影响）。
```

## 创新空间

- **L2 组合创新**: 机理模型 + 数据驱动残差修正（physics-informed ML）
- **L3 问题重构**: 将3D问题通过对称性降为1D（竞赛中最常见的加分项）
- **L4 机制发现**: 从实验数据反推未知物理参数，提出改进的机理假设
