# Structural Mechanics Model — 结构力学专家卡

> model_family: physics | 子类型: structural_mechanics
> 典型题目: 2016 A 系泊系统, 2021 A FAST 馈源(索结构)

---

## 决策入口

| 条件 | 判断 |
|------|:---:|
| 问题涉及绳索/缆索/杆件的力学行为？ | 是 → 结构力学 |
| 变形不可忽略（柔性体）？ | 是 → 悬链线/大变形理论 |
| 变形可忽略（刚性体）？ | → 静力平衡即可 |

→ **两条路线**:

| 路线 | 适用 | 典型题目 |
|------|------|------|
| 悬链线模型 | 自重不可忽略, 大变形柔性索 | 2016A 系泊链 |
| 抛物线近似 | 均布载荷, 小垂度 | 2021A 馈源支撑索 |

---

## 核心方程

### 悬链线 (Catenary)

```
y = a·cosh(x/a) + C

其中 a = T₀/w
  T₀ = 水平张力分量
  w  = 单位长度重量

索长: S = a·sinh(x₂/a) - a·sinh(x₁/a)
张力: T = w·y  (最大张力在最高点)
```

### 抛物线近似 (小垂度)

```
y = (w·x²)/(2T₀) + C

适用条件: 垂度 << 跨度, 即 d/L < 0.1
竞赛中常见: FAST 馈源索(张紧状态) → 抛物线简化
```

---

## 解题策略（系泊系统为例）

```
1. 识别系统的力平衡
   浮标: 浮力 = 重力 + 系泊链张力(垂直分量)
   锚点: 水平力平衡

2. 系泊链建模
   - 自重不可忽略 → 悬链线
   - 链长已知 → 可解出形态

3. 联立求解
   - 未知量: 吃水深度, 链形态, 锚点力
   - 方程数 = 力平衡(2) + 几何约束
   → 非线性方程组 → scipy.optimize.fsolve
```

---

## 不适用

| 场景 | 原因 | 替代 |
|------|------|------|
| 刚性杆件/桁架 | 无弯曲 → 用结构力学单元 | 有限元或解析桁架 |
| 材料非线性 | 悬链线假设线弹性 | 非线弹性模型 |
| 动力响应 | 静力平衡不够 | 动力学方程(常微分) |

## 必须验证

- [ ] 力平衡（水平和垂直方向，误差 <1%）
- [ ] 索长一致性（计算索长 = 给定索长，误差 <1%）
- [ ] 张力在材料安全范围内
- [ ] 小垂度假设检验（d/L < 0.1 才可用抛物线）

## 论文表达模板

```
（悬链线模型）系泊链在自重作用下呈悬链线形态, 其水平张力分量T₀为常数。
              链形态方程为 y = a·cosh(x/a), 其中 a = T₀/w。
              通过浮标力平衡和几何约束联立求解, 得到吃水深度和链形态。
（小垂度简化）对于FAST馈源支撑索, 垂跨比 d/L ≈ 0.03 ≪ 0.1,
              可采用抛物线近似 y = wx²/(2T₀) 简化计算而不损失精度。
```
