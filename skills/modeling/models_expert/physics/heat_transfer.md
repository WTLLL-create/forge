# Heat Transfer Model — 传热模型专家卡

> model_family: physics | 子类型: heat_transfer
> 典型题目: 2020 A 炉温曲线, 2018 A 高温服装, 2019 A 高压油管

---

## 决策入口

| 条件 | 判断 |
|------|:---:|
| 问题涉及温度场随时间/空间变化？ | 是 → 传热模型 |
| 有明确的热源/冷源边界？ | 是 → 边界条件可定义 |
| 材料热物性参数已知或可查表？ | 是 → k/c/ρ 可获取 |
| 仅需稳态温度分布？ | → 稳态（傅里叶定律） |
| 需要温度随时间变化？ | → 非稳态（热传导方程） |

---

## 核心方程

### 一维非稳态热传导（80% 竞赛题的起点）

```
ρc · ∂T/∂t = k · ∂²T/∂x² + q̇(x,t)

其中:
  T     — 温度 (°C)         [状态变量]
  t     — 时间 (s)          [自变量]
  x     — 位置 (m)          [自变量]
  ρ     — 密度 (kg/m³)      [物性参数]
  c     — 比热容 (J/kg·K)   [物性参数]
  k     — 导热系数 (W/m·K)  [物性参数]
  q̇    — 内热源 (W/m³)      [外部输入]
```

### 对流边界条件（最常见）

```
-k · ∂T/∂x|_边界 = h · (T_边界 - T_环境)

其中 h = 对流换热系数 (W/m²·K)，通常需要实验校准
```

---

## 数值求解（有限差分法）

```python
# 显式 Euler 格式（简单但受 CFL 条件限制）
import numpy as np

def solve_1d_heat(T0, dx, dt, alpha, n_steps, boundary_func):
    """alpha = k/(ρc), 需满足 α·dt/dx² < 0.5"""
    nx = len(T0)
    T = T0.copy()
    for _ in range(n_steps):
        T_new = T.copy()
        T_new[1:-1] = T[1:-1] + alpha*dt/dx**2 * (T[2:] - 2*T[1:-1] + T[:-2])
        T_new[0], T_new[-1] = boundary_func(T_new)  # 边界条件
        T = T_new
    return T
```

## 不适用

| 场景 | 原因 | 替代 |
|------|------|------|
| 系统均匀温度（Bi<0.1） | 集总参数法更简单 | `lumped_capacitance` |
| 2D/3D 效应不可忽略 | 一维假设失效 | 有限元（COMSOL/ANSYS）或数值2D |
| 仅需稳态 | 不需要时间项 | 直接解 Laplace 方程 |

---

## 必须验证

- [ ] **CFL 条件**: α·Δt/Δx² < 0.5（显式格式稳定性）
- [ ] **网格独立性**: 加密网格后温度变化 <1°C
- [ ] **能量守恒**: 输入能量 = 存储能量 + 输出能量（误差 <5%）
- [ ] **边界合理性**: T_边界 在物理合理范围内

## 论文表达

```
本文基于一维非稳态热传导方程建立炉温模型。方程中 k 为导热系数，
h 为对流换热系数——h 通过 Q2 的最小二乘拟合实验数据确定（非经验取值）。
显式有限差分格式的 CFL=0.43 满足稳定性条件。
```
