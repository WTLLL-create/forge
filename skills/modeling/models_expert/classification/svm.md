# SVM — 专家知识卡

> **一句话定位**：小样本 + 高维 + 分类的利器。但不适合大数据和强噪声场景。
> **决策入口**：分类问题 + N<500 + p 可能是 N 的几十倍

---

## 1. 专家判断速查

| 条件 | 能否用 | 替代 |
|------|:---:|------|
| N<500 + p>N/2 + 分类 | ✅ SVM 的甜区 | — |
| N>10000 | ❌ 训练 O(N²) | RF / Logistic |
| 强噪声 | ⚠️ 软间隔 SVM(C小) | 或用 Robust 损失 |
| 需要概率输出 | ⚠️ Platt Scaling | Logistic/NB 天然输出概率 |
| 线性可分 | ✅ 线性SVM（最简单） | 精确度高+完全可解释 |

---

## 2. 核函数选择决策

| 条件 | 核函数 | 理由 |
|------|:---:|------|
| 数据近似线性可分 | Linear | 最简单，可解释 |
| 非线性 + p较小 | RBF | 最通用，默认选择 |
| 文本/序列数据 | Linear（线性SVM在文本上出奇好） | 高维稀疏数据 |
| 超大数据 | Linear + SGD | 近似快速训练 |

---

```

根据数据 [线性可分/非线性] 的特性，选择 [Linear/RBF] 核函数。
通过网格搜索确定超参数 C=[X], γ=[Y]。
SVM在测试集上准确率达到 [X]%，混淆矩阵见 表X。
```
