# Random Forest — 专家知识卡

> **一句话定位**：表格数据 + 非线性的首选模型。不是因为它"精度高"，而是因为它在不调参的情况下也相当可靠，且有内置的特征重要性。
> **决策入口**：表格数据 + 关系非线性 + N>200 + 无需外推

---

## 1. 决策入口

| 触发条件 | 判定方法 | 阈值 |
|----------|----------|:---:|
| 特征-目标非线性 | Spearman \|ρ\|max < 0.5 | ✓ 适合 RF |
| 样本量足够 | N 直接统计 | N ≥ 200 |
| 不需要外推 | 题目是否要求预测训练范围外 | ❌ 外推 → 不用 RF |
| 需要特征重要性分析 | 题目要求"分析影响因素" | ✓ RF 天然支持 |

---

## 2. 专家判断速查

| 条件 | RF 能否用 | 替代方案 |
|------|:---:|------|
| 表格数据 + 非线性 + N>200 | ✅ 首选 | — |
| N<100 | ⚠️ 慎用 | SVR / GPR |
| 需要外推 | ❌ 绝对不用 | 机理模型 / 线性回归 |
| 需要高解释性 | ✅ RF+SHAP | GAM（更可解释但精度可能更低） |
| 特征数>样本量/3 | ⚠️ 需降维 | PCA+RF 或 正则化线性模型 |
| 时序数据但无 Lag 特征 | ❌ | 先构造Lag/滑动特征，再用RF |

---

## 3. 不适用场景

| 场景 | 为什么 | 论文表达 |
|------|--------|----------|
| 外推预测 | 树模型输出≤训练范围Max | "RF预测值被压缩在训练集范围内，图X显示外推区间的系统性偏差" |
| 强物理约束 | RF不保证输出满足物理定律 | "RF是纯数据驱动模型，无法内嵌物理约束" |
| 小样本 N<100 | Bootstrap 不稳定 | "N=[X]，每次Bootstrap采样差异大，OOB误差标准差=[Y]" |
| 强时间依赖 | RF 不建模时间结构 | "RF视数据为i.i.d.，忽略时序依赖——残差自相关ρ=[X]证实了这一点" |

---

## 4. 常见失败模式

| 症状 | 根因 | 修复 |
|------|------|------|
| 训练R²=0.98 测试R²=0.35 | max_depth=None → 过拟合 | max_depth=5~15 |
| 预测值不出训练范围 | 外推需求→RF天然不足 | 加物理约束 / 换可外推模型 |
| 特征重要性全是噪声 | 特征数过多 | VIF筛选 + 递归特征消除 |
| 高基数类别特征主导分裂 | RF对类别数敏感 | One-hot / Target Encoding |

---

## 5. 创新改进方向

| 改进 | 做法 | 论文表达 |
|------|------|----------|
| RF + 时间特征 | 构造 lag-1/2/3 + 滑动均值 | "将时间依赖显式注入特征空间，使RF'感知'时序结构" |
| RF + 物理约束 | 对不合理的预测施加惩罚 | "在MSE损失中加入物理约束惩罚项，保证输出在合理范围内" |
| RF + 分组建模 | K-means分群→每群独立RF | "工况差异意味着不同群的数据结构不同——分组建模优于全局建模" |
| RF + SHAP | 事后归因分析 | "SHAP分析揭示了[发现]——[X%]的预测方差来自[因素A]" |

## 6. 论文表达模板

```
Spearman相关性分析（表X）显示，[X/X]个特征与目标呈中度以上
线性相关（|ρ|>0.7），大量关系是非线性的。
这表明线性假设不成立，需要能自动捕捉非线性交互的模型。

随机森林的三个特性与本题高度匹配：
(1) 无需特征变换即可拟合非线性关系；
(2) 内置特征重要性评估，可量化各因素的贡献；
(3) 在类似表格数据上的可靠性经过大量验证。

为避免过拟合，通过交叉验证确定max_depth=[X]，
使得训练R²=[X]与测试R²=[Y]的差距控制在[Z]以内。
```

## 7. 与竞争模型的关系

| 对比 | RF | 场景切换 |
|------|-----|----------|
| vs XGBoost | 更稳定、无需调参 | N>500 + 需要精度上限 → XGBoost |
| vs 线性回归 | 非线性 + 交互 | 线性明显 → 用线性（更可解释） |
| vs SVR | 更快、支持高维 | N<200 + p>N/3 → SVR |
| vs LSTM | 表格数据之王 | 有时序结构 + Nt>1000 → LSTM |
