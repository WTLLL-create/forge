# XGBoost — 专家知识卡

> **一句话定位**：表格数据预测精度上限。RF 不调参也能用，XGBoost 调参后才能发挥——适合 N>500 且有调参时间的场景。
> **决策入口**：N>500 + RF 基线已达标 + 需要最后几个百分点的精度提升

---

## 1. 决策入口

| 触发条件 | 判定 | 阈值 |
|----------|:---:|:---:|
| N > 500 | ✓ | N<200 → 别用 XGBoost |
| RF 基线已建立 | ✓ | 必须先跑 RF 做对比 |
| 有调参时间 | ✓ | 竞赛中每天可以跑几轮 |
| 不需要外推 | ❌ | 树模型都不行 |

**关键判断**：RF 是"开箱即用"的推荐；XGBoost 是"RF达到瓶颈后"的升级选项。不能跳过 RF 直接上 XGBoost。

---

## 2. vs RF 的切换判断

| 维度 | 选 RF | 选 XGBoost |
|------|:---:|:---:|
| N | 200-500 | >500 |
| 噪声 | 高（RF Bagging 去噪） | 中/低 |
| 调参时间 | 无 | 有 |
| 精度需求 | 正常 | 极限 |
| 过拟合风险 | 低 | 中（需控制 max_depth+reg_lambda） |

---

## 3. 常见失败模式

| 症状 | 根因 | 修复 |
|------|------|------|
| 训练好测试差 | max_depth 太大 + N 不足 | max_depth=3~6, reg_lambda>0 |
| 训练很慢 | n_estimators 太多 + 无 early_stop | early_stopping_rounds=50 |
| 精度反而不如 RF | 过拟合 / 特征噪声大 | 先跑 RF 确定天花板，再调 XGBoost 看能否突破 |

---

## 4. 论文表达模板

```
在随机森林建立的基线（R²=[X]）之上，为进一步提升预测精度，
本文引入 XGBoost 进行对比优化。
通过贝叶斯优化确定超参数：max_depth=[X], learning_rate=[Y], n_estimators=[Z]。
为避免过拟合，采用早停策略（early_stopping_rounds=50）。

XGBoost 在测试集上达到 R²=[X']（vs RF=[X]），提升 [Y%]。
但更复杂的模型以更高的计算成本和调参时间为代价。
在竞赛场景下，这一精度-成本权衡需要根据实际需求判断。
```
