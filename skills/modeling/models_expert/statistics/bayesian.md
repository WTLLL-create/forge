# 贝叶斯方法 — 专家知识卡

> **一句话定位**：当你有先验知识或需要量化不确定性的利器。不适合"完全没有先验"的纯数据驱动场景。
> **决策入口**：存在先验信息 + 需要不确定性量化

---

## 1. 决策入口

| 触发条件 | 判定 |
|----------|:---:|
| 题目给出领域知识/物理约束可转化为先验分布？ | ✓ Bayesian |
| 需要输出的是"最可能的范围"而非"一个点估计"？ | ✓ Bayesian |
| 数据量极少（N<30）但有强先验？ | ✓ Bayesian |
| 完全无先验信息，纯靠数据？ | → 频率学派方法更简单 |

---

## 2. 贝叶斯在竞赛中的实际用法

| 用法 | 例子 | 效果 |
|------|------|------|
| 参数估计 + 不确定度 | "最优方案的95%后验区间" | 比点估计高级 |
| 小样本 + 强先验 | 物理定律 → 先验分布 | 解决小样本困境 |
| 模型比较 | Bayes Factor 比较两个假设 | 比 p 值有说服力 |
| 贝叶斯优化 | 自动调参 | XGBoost选参数 |

---

## 3. 论文表达

```
传统方法给出 [点估计 = X]，但无法量化这一估计的可靠性。
本文采用贝叶斯方法——将 [领域知识] 转化为先验分布，
结合数据得到后验分布 [分布形式]。

后验分布的 [均值/众数] 为 [X]，
95%最高密度区间为 [a, b]。
宽度 [b-a] 量化了认知的不确定性——
如果能获取更多数据在 [区域]，该区间预期可缩小 [Y]%。
```
