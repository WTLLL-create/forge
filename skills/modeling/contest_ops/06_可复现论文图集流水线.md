# 06 可复现论文图集流水线

> 解决的问题：论文图是"结论的视觉化"，也是最容易和正文脱节、无法重画、把构造示例当实验结果的环节。
> 实战中用一个 `build_figures.py` + 数据 CSV + 来源 + 图注核验说明，重绘了 11 张图（450dpi PNG + SVG），
> 并在重绘过程中纠正了多处过强结论。本文件是这套流水线的规范。

---

## 1. 一个图集包的标准结构

```
paper_figures/
├── build_figures.py        # 唯一作图入口：几何程序 + 控制器副本，一键重画全部图
├── 运行说明.md              # Python 版本、依赖、字体、一键命令、边界声明
├── data/                   # 每张图背后的数据 CSV（观测点、误差、重算值）
├── sources/                # 作图所依据的题目/控制器/数学程序/结果记录（只读副本）
├── packages/（可选）         # 离线依赖（numpy/scipy/matplotlib/Pillow），保证无网可复现
└── 新版论文图片/            # 产物：图NN_*.png（450dpi）+ 图NN_*.svg（矢量）+ 图注与数据核验说明.md
```

要点：

- 作图脚本**只调用几何函数/控制器副本，不连模拟器、不跑正式测试**。
- 复现包不含官方加密日志、队号、原论文文件、大型依赖目录；中文字体显式指定（如 Windows 微软雅黑 `msyh.ttc`）。
- 同时输出 PNG（450dpi，位图保险）与 SVG（矢量文字路径，可直接插 Word）。
- 依赖优先用包内 `packages/`，没有再用环境版本；脚本开头声明依赖与版本。
- **字节级复现注意（实测）**：matplotlib 的 PNG 两次构建可字节一致；但 SVG 默认每次写入
  `<dc:date>` 时间戳，并为 clip-path 生成随机 ID（如 `p0268330a93`），导致 SVG 字节哈希每次不同
  （几何内容完全一致，归一化后逐字节相同）。要做字节级复现，在脚本开头固定
  `plt.rcParams['svg.hashsalt'] = '<固定字符串>'`，并在比对时忽略/剥离 `<dc:date>`；
  否则复现校验应以 PNG 哈希 + SVG 归一化后比对为准。
- 包内 `packages/` 是特定 Python 版本的二进制（如 cp312），换解释器版本会加载失败；
  运行说明必须写明所需 Python 版本，或改用该版本的环境依赖。

## 2. 每张图必须标注证据类别

这是本流水线最重要的纪律。每张图在图注里明确属于哪一类：

| 类别 | 含义 | 图注必须声明 |
|---|---|---|
| **独立复算** | 本次用几何程序/数据重新计算 | 数据 CSV、口径、与旧稿差异 |
| **报告值重绘** | 论文/修改稿给的汇总值，找不到逐局原始记录 | "为论文报告值可视化，**非本次独立复现**" |
| **构造示例** | 为说明原理明确构造的受控几何场景 | "构造示例，不是随机对抗样本/正式轨迹" |
| **结果记录转述** | 来自用户结果记录，案例/源数不可控 | 只呈现案例性差异，不声称控制变量比较 |

实战裁决：
- 消融图（图8）只有汇总值、没有逐局原始日志 → 标"报告值重绘"，不得当成已复现。
- 定位收缩图（图5）是明确构造的几何示例 → 标"受控几何示例"，删除原稿"沿示向跟进 1/2/3/5 次"的旧数值。
- 跨策略图（图11）三次正式案例源数不同、第一次是有意跨策略对照 → 只作补充图，不声称因果优越性。

## 3. 图注与数据核验说明（必须随图交付）

一份 `图注与数据核验说明.md`，逐图写：

1. 子图 (a)(b)(c) 各画了什么、关键坐标/参数、真值如何标记；
2. 数据来源 CSV 与复算口径；
3. **必须同步更新的正文结论**（哪些旧表述过强、要删/改）；
4. 不能背书的内容（如"本图只解释正确的可见弧逻辑，不为现有生产代码的错误分支背书"）。

实战中被图注强制纠正的过强结论：
- 图9/图10 区分"标称观测集合"与"全部误差最坏情况"，删除"993m 环绕 + 名义示向对准 = 任意误差保证"；
- 图10 删除"两个约束共同证明 8 点骨架可直接清除"的推论——全域发现与源周局部定位是两个不同实验；
- 环绕点数曲线非单调不违反"累计观测使可行域收缩"，因为各 m 的测点重新均匀布点、并不嵌套。

## 4. 作图与正文的一致性检查

- [ ] 每张图的数值能在 `data/` 找到来源，且能由 `build_figures.py` 重算复现。
- [ ] 图、表、正文三处数字一致；旧稿数字与重算不一致时以当前脚本口径为准并显式说明。
- [ ] 图中布局与**实际程序**一致（实战：中环首点角度、骨架点数曾与旧图不符，按程序校正）。
- [ ] 几何示意图不暗示统计保证；统计图不把描述性合并写成性能保证。
- [ ] 不把"正式测试"的跨案例效率差异表述为严格因果；正式 jlog 不解密，数值依据结果记录。
- [ ] 图序号、图题在下、引用顺序、清晰度（≥300dpi，本规范取 450dpi）满足格式规范。
- [ ] 替换图片时**同步替换图注与正文**，只换图不换结论会造成新的不一致。

## 5. 与工作区表格规范的边界

- 图遵循本文件；**论文表格**统一遵循 `standards/academic_table_standard.md`（锁定 table_spec、精度、三线表、不自动加粗/星级），
  本文件不改变任何表格规格。
- 图中数据落盘成 CSV 后若进入论文表格，仍须走表格规范与冻结/核验流程。

## 6. 与其他手册的接口

- 图的证据类别直接对应事实表的证据分级（[02](02_证据边界与事实表.md)）。
- 对抗复核（[03](03_对抗性逻辑碰撞复核.md)）和阶段0审计（[04](04_阶段0现状审计与下界纪律.md)）发现的结论降级，
  必须反映到图注与正文（删图、改图、改类别）。
- 最终成稿与门禁（AI 声明、数字冻结、模板合规）走 `submission/` 与 `论文生成流程.md`。
