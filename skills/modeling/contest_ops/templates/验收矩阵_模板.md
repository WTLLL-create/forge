# 验收矩阵（模板）

> 配合 `../03_对抗性逻辑碰撞复核.md`、`../05_在线离线双世界与协议纪律.md` 使用。
> 每条必须可独立判定（有命令/证据/数值），不能有"基本正确"这类不可勾选项。未做的留空，不预先打勾。

## A 官方协议与计时
- [ ] 接口路径、请求格式、字段与官方一致，无多余项。
- [ ] 每个新动作新 request_id；传输重试完整复用原 payload 与 ID。
- [ ] 严格串行；同时检查 HTTP 状态与 `accepted`；被拒不更新状态。
- [ ] 各动作计时与官方公式一致（检测/切频道/成功清除/失败清除）；明确"清除不切频道"之类规则。
- [ ] 用 `/enter` 剩余现实时间与虚拟时间上限做截止门控。
- [ ] 只使用官方状态字符串；日志含请求/响应/ID/版本/最近已接受时刻/错误/摘要。

## B 几何/解析问题（对应 Q1/Q2 类）
- [ ] 区分外层逼近（如纯楔形交）与含圆弧/距离上界/内孔的完整物理可行域。
- [ ] 代表构型数值独立复算，并解释关键否定结论（如"远距两次交会不足以保证一次清除"）。
- [ ] 最小包围圆/直径/边界/退化/±误差碰撞通过。
- [ ] 极值检查覆盖角点与内部驻点，不遗漏内弧端点。
- [ ] "解析证明"与"数值全局证书"分开表述；概率结论写明误差分布。

## C 在线安全不变量（对应 Q3 类）
- [ ] 历史 trace 重新独立统计，有效局/空局数与旧报告一致或显式纠正。
- [ ] 覆盖骨架、清除门限、跟随兜底、失败重测等安全不变量通过独立碰撞。
- [ ] 协议缺陷（频道/计时/截止/版本标签）已在新副本修复。
- [ ] 对照实验缺失依赖已补齐或用等价独立模拟器替代，大样本可复现。
- [ ] 明确证明上一问的判空规则不能直接沿用到下一问。

## D 扩展情形安全与精度（对应 Q4 类）
- [ ] 无信号按"无源/超距/暗侧"析取处理；曾有正信号的频道不再被捷径判空。
- [ ] 任意位置/朝向/最小接收半径下的发现与判空有连续域证明。
- [ ] 边界朝外源可发现，必要时允许圆外探测点；覆盖角边界含等号且浮点有裕量。
- [ ] 暗侧恢复有终止证明与动作上界；清除点对整个保守可行域都在官方距离内。
- [ ] 未知 N 下全部频道闭环后才退出。

## E 效率指标
- [ ] 新架构不携带已被自身下界排除的固定巡检成本（写明受限下界）。
- [ ] 最难档的理论预算/受限下界仍低于目标，或明确给出"未被排除但极紧"。
- [ ] 逐局分别统计移动/测量/切频/清除/发现/定位/尾证耗时。
- [ ] 分档报告 mean/median/P90/P95/worst 与达标率，不只报合并均值。
- [ ] 单局门槛按"每局 T/cleared ≤ 目标"逐局判定后再统计达标比例。
- [ ] 优化与基线同布局、同误差场、同协议计时；失败样本不删除。

## F 碰撞与故障注入
- [ ] 重点档 ≥1000 局、其余档 ≥600 局（按题目调整），分层种子未参与调参。
- [ ] 类型/位置/方向/接收半径/误差边界全覆盖；含最小半径、贴边、聚集、共线、最差布局。
- [ ] 响应丢失/超时/典型错误码/accepted=false/冲突 ID/永久故障均有测试。
- [ ] 暂态故障恢复成功；永久故障或时间不足明确报告未完成，不计入成功局。
- [ ] 保存所有失败种子、最小反例与原始轨迹。

## G 全链路与交付
- [ ] 每个模块标注来源（沿用/修正/新增）与对应问题。
- [ ] 符号、单位、误差口径、时间口径、频道状态、结论在各问之间一致。
- [ ] 干净目录一键运行，依赖明确；真实队号不写死。
- [ ] 离线日志显著标 OFFLINE；官方日志保留原文件名；正式测试表不填假数据。
- [ ] 交付含源码、模拟器、测试、原始统计、模型报告、全链路核验、运行说明、SHA256 清单。
