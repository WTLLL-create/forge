# 交接包目录骨架与打包清单（模板）

> 用法：复制本模板，把 `<…>` 占位替换为实际内容。协议见 `../01_跨模型交接包协议.md`。
> 命名建议：`<项目>_<用途>_<YYYYMMDD>`，如 `B题跨模型交接包_20260911`。

## 目录骨架

```
<项目>_<用途>_<日期>/
├── 00_必读/
│   ├── 00_先读我.md
│   ├── 01_当前状态与证据边界.md      # 用 证据边界与事实表_模板
│   ├── 02_主任务指令.md
│   ├── 03_验收矩阵.md               # 用 验收矩阵_模板
│   └── 04_本次独立复核记录.md
├── 01_官方题目与协议/               # 原题、附件原件 + 同名 .txt 提取文本
├── 02_比赛规定/                     # 规则/格式/AI 规定/官网快照/下载来源.json
├── 03_<子问题A>/                    # 用户原稿（原样）+ 历史分析（标注状态）
├── 04_<子问题B>/                    # 最新代码、历史基线、模拟器、测试、原始结果
├── 05_官方演练记录/                 # 真实 trace（原文件名）+ 加密原件（不解密不改名）
├── 06_<未解子问题>/                 # 专门指令 + 历史基线（显式标"未达标/非严格下界"）
├── 07_模拟器与测试/                 # 接口与验收说明
├── 08_旧版输出_仅供追溯/（可选）
├── 09_后续日志投放区/（可选）
├── README_先读.md
├── 原件复制来源.json
├── 文件清单_SHA256.json
└── 交接自检.md
```

## 00_先读我.md 要点

- 本包用途：继续完成什么 / 不是什么（不是可直接提交的支撑材料、不是达标交付）。
- 上手三步：整包交给接手模型 → 要求先读 `02_主任务指令.md` 并视为唯一主指令 → 新日志投放到 `09_`。
- 红线：不自动启动正式测试；不读真值；不覆盖旧文件；旧版输出仅供追溯。
- 关键判断（一段话）：当前最硬的结论与最大的缺口。
- 口径定义：把用户口语目标（如"300 个/s"）明确翻译成可验收的数学口径（如 `virtual_time_s/cleared_count ≤ 300`），歧义先问人。

## 打包三动作（脚本化，原件只读）

1. collect：复制原件 → 计算 SHA-256 写 `原件复制来源.json`；目标已存在则断言字节一致，禁止异文件覆盖。
2. download（可选）：抓官网规则 → 校验文件魔数 → 记录 URL/日期/成败。
3. finish：生成 `文件清单_SHA256.json`（排除清单自身与 `__pycache__`）→ 打 ZIP → `testzip()` 校验。

## 原件复制来源.json 条目格式

```json
{ "source": "<原始绝对路径>", "copy": "<包内相对路径>", "sha256": "<64位哈希>" }
```

## 文件清单_SHA256.json 条目格式

```json
{ "path": "<包内相对路径>", "bytes": 0, "sha256": "<64位哈希>" }
```

## 打包清单（交付前逐项勾）

- [ ] 陌生模型仅凭本包即可建立事实表，无必需文件缺失。
- [ ] 每个子问题"最新入口"唯一且明确，历史基线标注清楚。
- [ ] 离线 / 演练 / 正式三类成绩明确区分。
- [ ] 未达标项、未证明项、缺失证据、版本冲突全部显式列出。
- [ ] 原件只读、哈希登记；整包清单与 ZIP 校验通过。
- [ ] 写明红线（不自动正式测试、不读真值、不覆盖旧文件）。
- [ ] 含 AI 使用记录与待人工复核模板。
- [ ] 敏感信息（队号/路径/日志）提示"内部使用、勿公开"。
