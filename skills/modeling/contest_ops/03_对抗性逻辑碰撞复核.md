# 03 对抗性逻辑碰撞复核

> 解决的问题：自己写的方案自己审，倾向于"证明自己对"；让两个模型互相看，容易变成互相赞同。
> 实战中强制引入"设计者 / 挑错者 / 裁决者"三方对抗，用独立算法、反例搜索、退化攻击和不变量碰撞，
> 把"严格终版"里的硬伤在提交前逼出来。本文件是操作规程。

---

## 1. 三方对抗流程（逻辑对抗）

对每一个关键结论，依次走三轮，**不得只让两个模型互相赞同**：

1. **正方（设计者）**：给出完整证明 / 算法，明确量词、前提、适用域、复杂度。
2. **反方（挑错者）**：用独立推导和反例搜索，专门攻击
   - 量词（"任意/存在"是否被偷换）、边界（±、含不含等号、0°/360° 跨角）、
   - 先验（误差分布是否被无中生有）、退化（空集/无界/射线/线段/单点/近平行/共线/重合）、
   - 复杂度、全局最优（数值搜索 ≠ 全局证明）、统计外推（样本 → 任意布局）。
3. **裁决方**：逐项裁决，给出"通过 / 降级 / 否决 + 修复"，并把未证明结论降级为猜想或数值发现。

平台支持多模型时，可让不同模型分别扮演设计者/挑错者/裁决者；**单模型则分轮进行，并注明这是非独立复核**。
队伍要的是"能由人检查的证据"，不要求输出私有思维链。

---

## 2. 结论级复核矩阵

对用户原稿/历史方案"先评审再修正、保留原文"，逐条建立六元组：

```
结论 — 假设 — 证明 — 反例 — 修复 — 测试
```

- 任何一格站不住，结论就不能以原强度保留。
- 修复必须配可运行的单元测试/对抗测试，不能只改文字。
- 明确禁止：只把文字润色一遍就称为"完美解决"。

## 3. 四类必备攻击手段

### 3.1 独立算法交叉验证
用**原理不同**的第二条算法路径复算，而不是同方法换参数。
- 实战：半平面交用"逐次裁剪"实现，复核用"所有边界直线两两求交 + 逐半平面验算"，6000 组随机构型比对顶点集（不一致数 0）与 Hausdorff 误差。
- 几何最优点用解析构造（两圆交点）+ 多层网格搜索 + SLSQP/差分进化三条路径互相印证。

### 3.2 退化输入攻击（Degeneracy Attack）
枚举所有退化构型喂给程序：单条示向度（无界楔形）、0° 与 180° 交成一点、近平行、空集、共线三点、重合顶点。
- 实战中据此发现：零面积交集触发除零崩溃、交集退化为点时返回 4 个重复顶点——据此否决"权威几何核可直接交付"。
- 要求实现显式区分 `EMPTY / UNBOUNDED / POINT / SEGMENT / POLYGON`，并做重复点/共线点合并。

### 3.3 大样本随机 + 边界压力
- 随机覆盖整个物理范围（距离比、交会角、误差），统计"反例事件"的出现频率与极值；
- 专门打边界：误差恒取 ±1° 极值、两位小数量化边界（±1° 是舍入前还是响应后？保守按额外 0.005° 加裕量）、
  最小 1000m 半径、圆域边缘、聚集/分散/共线/近邻/最差布局、R=1000 与 R=1500、贴边朝外全定向。
- 偏离题设的压力样本另列，**不冒充题设内保证**。

### 3.4 不变量 / 逻辑碰撞测试（Logic Collision）
不依赖缺失的重型模拟器，直接打控制器的几何核、状态机、路径规划，内置最小题面口径模拟器端到端跑，
断言一组**安全不变量**。实战沉淀的不变量分组：

- **A 几何安全**：覆盖骨架对圆盘的最坏覆盖距离 < 最小接收半径；±1° 楔形 ∩ 距离上界必含真源（这是"清距<20"的根保证）；最小包围圆的最小性/覆盖性；跟随步长收敛阈值（如 9.9/(2cos1°)=4.95m < 5m）。
- **B 状态机**：判无源必须 N 个**不同**锚点全 no_signal（N−1 个不行、重复锚点不计数、收到过 direction 后永久禁用该捷径）；near 可清、清除失败后锁定必须重测才解锁；最小包围圆半径 > 门限拒清；同站重复观测去重。
- **C 路径优化**：2-opt/or-opt 只在严格缩短时接受；优化后任务集合逐对象不变、路程单调不增、可瞬时终止。
- **D 端到端**：分档 × 多分布 × 多误差模式跑数百上千局，断言零漏清、零扑空、零未终态、不超时限、最大清除距离 < 20m。

**关键纪律**：当报告声称的对照实验因缺基线模块跑不起来时，要明确报告"精确效率数字无法本地复核"，
并把"安全结论"（可用不依赖缺失模块的独立碰撞器证实）与"效率数字"（暂不可复现）分开。

## 4. 证明漏洞的典型清单（在线几何/策略题）

实战中反复出现、应作为默认检查项：

- 离散网格残余=0 只是数值证据，网格之间可能漏点 → 需要覆盖裕量下界或区间算术证书。
- 测试夹具自身写错：把"检测点距候选源 ≤7m"误当成整圆可见，忽略了定向半平面在退化距离下仍只覆盖一半朝向。
- 探针预算耗尽后放宽清除门限（19m → 40m），与官方 20m 保证矛盾 → 可构造反例，直接否决"0 扑空"。
- 一次无信号后生成完全相同坐标（原地重测），固定误差下无信息增益且违反硬约束。
- 步长文档写"每步固定 9.9m"，代码实现为 9.9/19.8/29.7 递增，可能跨过有效区域，证明失效。
- "N 步上限"因计数器重置而可累计到 3N 步，终止性与最坏资源界失真。
- 命题"沿示向度推进永不进暗侧"为假 → 必须给出精确反例，改为"两点至少一处可见"的恢复定理。
- 四角点极值法在一般构型下漏了角向内部驻点（虽然在特定可行域内结论成立）→ 证明要补适用域前提，通用函数仍需检查内部驻点。

## 5. 复核报告的写法

固定结构：

1. **总体结论**：哪些主错误已修复、当前版本能否称"严格终版"（多数情况下是"暂不建议"）。
2. **独立测试结果**：每项给样本量、独立算法、容差、通过/失败数值。
3. **退化攻击表**：输入 / 程序表现 / 判定。
4. **尚存问题**：按高/中优先级列，每条给后果与修复方向。
5. **最终判定**：对每条主线分别给"通过 / 不通过 / 未完成"，**不打总分式的笼统通过**。

判定措辞示例（实战）：
- 数学主线通过、一般随机实现通过、退化鲁棒性不通过（必须修）；
- 规范场景数值通过、"四角点"证明在特定可行域内通过但全局表述需修订、任意首测点推广尚未完成；
- "严格终版"称谓：暂不建议使用。
