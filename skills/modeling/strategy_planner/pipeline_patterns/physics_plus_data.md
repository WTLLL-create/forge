# Pattern: Physics Model + Data Correction — 物理模型+数据校正管线

> 适用: 有已知物理/经验公式 + 有实测数据可用来校正
> 例: 2019A无线传播, 经验公式(Okumura-Hata) + AI残差校正

## 管线结构

```
Step 1: 建立物理/经验模型
  模型: 领域经验公式或物理方程
  输出: 物理模型的预测值
  验证: 与已知规律的一致性

Step 2: 计算残差
  残差 = 实测值 - 物理模型预测值
  分析: 残差是否有系统模式(说明物理模型遗漏了某些因素)

Step 3: 残差建模(AI校正)
  模型: 用ML(如RF/XGBoost)预测残差
  输入: 影响残差的特征(补充物理模型忽略的因素)
  输出: 残差预测值

Step 4: 组合预测
  最终预测 = 物理模型预测 + AI残差预测
  验证: 组合模型 vs 纯物理模型 vs 纯AI模型 三方对比
```

## 可复用的模式

- **先物理后数据**: 物理担纲主体, AI补充残差
- **三方对比**: 证明混合模型优于任一纯方案
