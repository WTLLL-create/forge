# Pattern: Surrogate + Optimization — 代理模型+优化管线

> 来源: A题 电除尘器优化（已验证2次）
> 适用: 目标函数无解析形式 + 有充足历史数据 + 需多目标权衡

## 管线结构

```
Step 1: 数据审计
  模型: 缺失值/异常值/时间连续性/目标分布检查
  输出: 数据质量报告
  关键发现: A题发现C_out 54.7%数据==50 → 右删失

Step 2: 工况聚类
  模型: K-means (肘部法+K=4, 轮廓系数验证)
  输出: 聚类标签 + PCA可视化
  目的: 将复杂工况分组，降���建模复杂度

Step 3: 代理模型
  模型: RandomForest 拟合目标函数(排放/功率)
  输入: 控制变量(电压/振打频率等) + 工况特征
  输出: 能快速预测任意控制组合效果的代理
  风险: 右删失数据 → RF预测有地板效应, 论文中讨论

Step 4: 多目标优化
  模型: NSGA-II (pymoo)
  输入: RF代理模型作为适应度函数
  输出: Pareto前沿 + 最优控制参数
  配置: Q2单目标+约束(C_out≤10), Q4双目标(功率+排放)
  风险: pymoo 0.6.2 Result.F为None, 需用Result.pop.get("F")

Step 5: 可视化与验证
  图表: 聚类图, 特征重要性, 收敛曲线, Pareto前沿, 参数对比
  验证: 收敛性 + 与基准方案对比
```

## 可复用的模式

- **先代理后优化**: 当目标函数计算昂贵时, 先用ML建立廉价代理
- **聚类降维**: 复杂工况→先分组再建模
- **右删失诊断**: 检查目标变量分布, 如存在截断→在论文中讨论外推限制
