# Pattern: Sensor Fusion + Task Optimization — 多源融合+优化管线

> 来源: B题 多传感器融合定位（已验证）
> 适用: 多源异构数据→先融合统一→再基于融合结果做优化

## 管线结构

```
Step 1: 时间对齐
  模型: 插值+时间偏差估计
  输出: 对齐后的两路传感器数据
  验证: 对齐前后RMSE对比

Step 2: 噪声估计与偏差校正
  模型: 计算重叠段偏差 + 噪声方差估计
  输出: 校正后的数据
  验证: 残差分析

Step 3: 数据融合
  模型: Kalman滤波 + Savitzky-Golay滤波 双重对比
  输出: 10Hz融合轨迹
  验证: RMSE对比(简单平均 vs Kalman vs SG)
  决策: 附件2 SG略优(+5.8%), 附件3 SG显著优(+33.3%)

Step 4: 任务优化
  模型: 路径规划 + 约束满足(射击/拍照)
  输入: Step 3的融合轨迹 + 目标任务点
  输出: 任务完成方案(result.xlsx)
  验证: 约束满足检查
```

## 可复用的模式

- **双重方法对比验证**: 不确定该用哪种方法时, 两种都跑, RMSE说话
- **先融合后优化**: 融合是优化的数据基础, 不能跳过
- **渐进式复杂度**: 附件1(无噪)→附件2(含噪)→附件3(实测), 复杂度递进
