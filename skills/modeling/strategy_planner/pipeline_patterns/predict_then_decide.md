# Pattern: Regression + Multi-Objective — 回归+多目标混合管线

> 适用: 需要先预测再评价/优化的两步问题

## 管线结构

```
Step 1: 预测/回归
  模型: 根据数据特征选择(时序→ARIMA/LSTM, 多维→RF/XGBoost)
  输入: 历史数据
  输出: 未来预测值 + 置信区间
  验证: MAE/RMSE + 与基线对比

Step 2: 基于预测的决策
  模型: 优化/评价(取决于问题)
  输入: Step 1的预测结果
  输出: 最优决策/评价排名
  风险: 预测误差会传播到决策阶段
```

## 可复用的模式

- **预测→决策的两阶段结构**
- **预测不确定性的传递**: 如果Step 1给出置信区间, Step 2可以据此做鲁棒决策
