# Pattern: MIP + System Dynamics — 运筹+系统动力学混合管线

> 来源: C题 氦气产业链优化（已验证）
> 适用: 短期决策优化(MIP) + 长期策略分析(SD)

## 管线结构

```
Step 1: 数据探索与趋势分析
  模型: 供需缺口趋势, GPR走势, 价格预测
  输出: 现状诊断报告 + 趋势图表
  图表: 缺口趋势, GPR走势, 价格预测, 进口结构对比

Step 2: 短期进口策略优化 (MIP)
  模型: 混合整数规划
  输入: 成本+风险+供应约束
  风险量化: Sigmoid函数将GPR指数映射为供应链中断概率
  输出: 最优采购组合(各国采购比例)
  验证: 不同风险情景下的鲁棒性

Step 3: 长期策略分析 (System Dynamics)
  模型: 系统动力学(四大支柱:勘探+合作+储备+回收)
  输入: Step 2的进口依赖度→影响投资分配
  输出: 三阶段策略路线图(短期/中期/长期)
  验证: 不同政策情景下的对比模拟

Step 4: 综合可视化
  图表: Pareto前沿, 供应链网络图, 四大支柱雷达图, 路线图
```

## 可复用的模式

- **先短后长**: MIP解短期最优策略→策略输出作为SD的初始条件
- **Sigmoid风险量化**: 将连续风险指数映射为[0,1]中断概率, 融入MIP约束
- **多场景对比**: 不同风险情景(R₀=1.5/3.0/5.0)的差异化策略对比
