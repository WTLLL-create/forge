# Assumption Breaking — 假设突破模式

> 识别题目中的隐含假设，挑战其中不合理的部分。

## 常见可挑战的假设

| 隐含假设 | 为什么可能不合理 | 突破方向 |
|------|------|------|
| "数据服从正态分布" | 真实数据常是偏态 | 使用非参数方法/稳健估计 |
| "变量间是线性关系" | 物理系统常是非线性 | 检查散点图后再定 |
| "所有约束同等重要" | 某些约束可放松 | 敏感性分析确定哪些约束是瓶颈 |
| "独立性假设" | 时空数据常有相关性 | 引入空间/时间相关性建模 |
| "测量无误差" | 实际数据都有噪声 | 引入误差模型/不确定性量化 |

## 假设审查清单

```
□ 题目中哪些是"给定"约束，哪些是"隐含"假设？
□ 每个假设——如果去掉会怎样？模型还能用吗？
□ 是否有数据的分布特征与假设矛盾？
□ 假设简化掉的是次要因素还是核心因素？
```
