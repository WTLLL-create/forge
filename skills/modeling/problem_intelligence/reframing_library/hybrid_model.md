# Hybrid Model — 混合模型模式

> 不追求"一个模型解决所有问题"，而是设计多模型协同。

## 常见混合架构

### 1. 串行混合：先A后B

```
模型A输出 → 模型B输入
例：先聚类分组 → 再分组预测
例：先时间对齐 → 再融合估计
```

### 2. 并行对比：A vs B vs C

```
同时运行多个模型 → 比较 → 选择/组合
例：线性回归 vs 随机森林 vs ARIMA → 各有优劣 → 展示对比
```

### 3. 嵌套混合：B建立在A之上

```
模型A建立基础框架 → 模型B在框架上优化
例：先建立神经元ODE → 再在ODE上优化DBS参数（2021C）
例：先RF代理模型 → 再NSGA-II在代理上优化（A题）
```

### 4. 分而治之：子问题独立建模

```
问题拆解为独立子问题 → 每子问题独立选模型 → 结果汇总
例：3个时间窗口×6个污染物 = 18个独立模型（2021B）
```

## 混合设计清单

```
□ 问题可以自然分解为独立子问题吗？
□ 多个模型能互补吗（一个擅长A，另一个擅长B）？
□ 有"先验模型"可用作基础框架吗？
□ 对比是否有意义（不只报告一个模型的结果）？
```
