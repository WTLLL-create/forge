## 新增模式（Stage 20.2）

### 模式 7: 高维冗余 → 低维本质

**识别**：特征数远超样本数（如2020B汽油辛烷值：2300+特征/367样本）

**迁移**：不是直接做回归，而是先找低维表示（PCA/PLS/特征选择），再在低维空间建模

**数学形式**：
```
高维原始数据 X(n, p) where p >> n
     ↓ PCA 保留85%方差
低维表示 Z(n, k) where k << p
     ↓ 回归
预测模型 y = f(Z)
```

### 模式 8: 经验模型 + AI残差

**识别**：存在领域经验公式，但精度不足（如2019A无线传播）

**迁移**：不是放弃经验公式或用纯AI替代，而是"经验公式预测主体 + AI预测残差"

**数学形式**：
```
y_true = f_empirical(x) + residual(x)
         ↑ 经验公式        ↑ AI模型预测残差
```
