# Problem Analysis Protocol — 问题分析协议

> Stage 20.2 核心文档。
>
> 定位：Agent 拿到题目后，固定执行的 4 步分析框架。
> 不是教 Agent "选什么模型"，而是教 Agent "怎么理解问题"。
>
> 输入：原始题目文本
> 输出：结构化问题理解 → 供 Knowledge Router 消费

---

## 核心洞察

数学建模题目有三个层次的理解深度：

```
Level 1: 表面关键词      → "预测""优化""评价"      → Router v1 已做
Level 2: 数学结构        → "这是个动力系统问题"      → 本文档解决
Level 3: 创新空间        → "可以重构为图论问题"      → reframing_library/ 解决
```

**Router v1 的 70% 瓶颈在 Level 1→2 的断层。本文档建立 Level 2 的标准流程。**

---

## Step 1: 识别研究对象

### 问题
这个东西到底是什么？在什么空间里运动/变化？

### 分析维度

| 维度 | 分析内容 | 示例 |
|------|----------|------|
| **对象** | 研究的主体是什么？ | 车辆、污染物、神经元、电磁波 |
| **空间** | 在什么空间中存在？ | 物理空间、抽象指标空间、网络空间 |
| **时间** | 是否有时间维度？是连续还是离散？ | 秒级连续 / 年度离散 / 无时间 |
| **粒度** | 个体还是群体？微观还是宏观？ | 单车辆 vs 车流 / 单神经元 vs 脑区 |

### 输出格式

```
【研究对象】
- 对象：XXX
- 空间：XXX（物理/抽象/网络）
- 时间：连续/离散/无
- 粒度：微观个体/宏观统计
```

## Step 2: 分析变量与关系

### 问题
什么在影响什么？变量之间的关系是什么？

### 关系分类

```
变量之间的关系
│
├── 时间演变关系    → 同一个东西随时间变化
│   例：温度逐年上升、股价分秒波动
│   数学形式：y(t), dy/dt
│
├── 因果/影响关系   → 一个东西变化导致另一个变化
│   例：施肥量 → 牧草产量、电刺激 → 神经元放电
│   数学形式：y = f(x₁, x₂, ...)
│
├── 空间分布关系    → 同一个东西在不同位置的值不同
│   例：各城市的PM2.5浓度、不同节点的电压
│   数学形式：u(x, y, z)
│
├── 网络/拓扑关系    → 东西之间通过连接影响彼此
│   例：供应链上下游、神经元突触连接
│   数学形式：G = (V, E), A[i][j]
│
├── 约束/限制关系    → 变量取值受到物理/逻辑约束
│   例：载重≤15吨、误差≤阈值、资金≤预算
│   数学形式：g(x) ≤ 0
│
└── 竞争/权衡关系    → 多个目标互相冲突
│   例：成本 vs 排放、产量 vs 可持续
│   数学形式：多目标优化
```

### 输出格式

```
【变量关系】
- 核心关系类型：[时间演变 / 因果影响 / 空间分布 / 网络拓扑 / 约束限制 / 竞争权衡]
- 关键变量：
  - XXX：[类型：自变量/因变量/控制变量]，[取值范围]
  - YYY：[类型]，[范围]
- 关系数学描述：[文字描述→可能的数学形式]
```

## Step 3: 判定数学本质

### 问题
这个问题的数学本质是什么？

### 本质映射表（6大类 + 跨类信号）

| 表象特征 | 数学本质 | 判定信号 | 反例（容易误判） |
|------|------|------|------|
| 根据过去推未来 | **时间序列预测** | 有历史数据+时间戳 | ❌ "预测污染物扩散"→本质是PDE |
| 找最优方案 | **优化** | 有目标+约束+决策变量 | ❌ "最优参数"→可能是拟合/估计 |
| 比较多对象排序打分 | **综合评价** | 多对象+多指标+需要排名 | ✅ 一般不会误判 |
| 存在已知物理/化学/生物定律 | **机理建模(ODE/PDE)** | 题目引用了具体定律 | ❌ 没引用但隐含定律（如扩散） |
| 变化过程由内在机制驱动 | **动力系统** | 描述"过程""演化""变化规律" | ❌ 同样的话也可以是时序预测 |
| 对象之间存在连接关系 | **网络/图模型** | 有节点+边+流量/路径 | ✅ 一般不会误判 |
| 变量存在随机扰动 | **概率/统计模型** | 提到"噪声""随机""概率" | ❌ 加了噪声的确定性模型 |
| 数据有高维特征需筛选 | **降维+回归** | 特征数>>样本数 | ❌ 同样可以是分类 |

### 关键区分规则

**Rule 1: "预测"其实可能是"机理"**

```
判断：题目引用了物理/化学/生物定律？
├─ 是 → 本质是机理建模（用定律推演未来，不是用数据外推未来）
│  例：基于扩散方程预测污染物分布 → 机理
└─ 否 → 判断：只有历史数据没有定律？
    ├─ 是 → 本质是数据驱动的预测
    └─ 否 → 继续往下判断
```

**Rule 2: "优化"其实可能是"参数估计"**

```
判断：目标函数是"拟合误差最小化"？
├─ 是 → 本质是参数估计/回归（不是运筹优化）
│  例：最小化预测值与真实值的差距 → 回归
└─ 否 → 目标是"成本/效率/收益"等运营指标？
    ├─ 是 → 本质是运筹优化
    └─ 否 → 继续往下判断
```

**Rule 3: "建模"一词不代表"机理建模"**

```
⚠️ 数学建模中几乎每道题都说"建立模型"
"建立XX模型" ≠ 机理建模

判断：是建立"描述物理过程的方程"还是"描述数据关系的模型"？
├─ 物理过程方程 → 机理建模
└─ 数据关系模型 → 统计/ML模型
```

### 输出格式

```
【数学本质】
- 本质类型：[时间序列预测 / 优化 / 综合评价 / 机理建模 / 网络模型 / 概率统计 / 混合]
- 混合说明（如果是混合型）：子问题1=XXX, 子问题2=YYY
- 判定依据：
  1. [关键信号1]
  2. [关键信号2]
- 排除的类型及原因：
  - 不是XXX，因为[原因]
```

## Step 4: 确定候选模型空间

### 问题
不是选一个模型，而是确定一个"候选空间"——哪些类型的模型可能适用？

### 候选空间生成规则

```
数学本质 → 候选模型空间

时间序列预测 →
  [统计时序: ARIMA/SARIMA, 灰色预测: GM(1,1), ML: XGBoost/LSTM]

优化 →
  [精确: LP/IP, 启发式: GA/NSGA-II, 图论: Dijkstra/Floyd]

综合评价 →
  [主观权重: AHP, 客观权重: 熵权法, 排序: TOPSIS/RSR, 模糊: 模糊综合评价]

机理建模 →
  [ODE: 常微分方程, PDE: 偏微分方程, 系统动力学: SD, 经验公式+AI校正]

网络模型 →
  [最短路径, 最大流, 匹配, 网络设计]

混合型 →
  [分而治之: 子问题分别选型, 嵌套: 一个模型的输出是另一个的输入]
```

### 输出格式

```
【候选模型空间】
- 候选类别：[列出2-3个适合的模型大类]
- 每个类别的适用条件：
  - XXX类：适用于[条件]
  - YYY类：适用于[条件]
- 选择决策留待 Knowledge Router 和具体数据探索
```

## Agent 使用方式

```
Agent 收到题目
    │
    ▼
Step 1: 识别研究对象 ──→ 对象/空间/时间/粒度
    │
    ▼
Step 2: 分析变量关系 ──→ 时间演变/因果/空间/网络/约束/权衡
    │
    ▼
Step 3: 判定数学本质 ──→ 6大类之一（含3条关键区分规则）
    │
    ▼
Step 4: 候选模型空间 ──→ 2-3个候选大类 + 适用条件
    │
    ▼
输出 ProblemUnderstanding → 传入 Knowledge Router
```

## 与 Knowledge Router 的接口

```
Problem Intelligence 输出              Knowledge Router 输入
─────────────────────────────────────────────────────────
数学本质 + 候选模型空间              → problem_type (精炼后)
变量关系类型                         → 数据特征 (extra_features)
研究对象特征                         → 数据规模/离散性/线性判断
区分规则排除的类型                   → 降低误判概率
```
