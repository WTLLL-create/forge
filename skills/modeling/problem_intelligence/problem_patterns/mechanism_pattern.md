# Mechanism Pattern — 机理建模类问题模式

> ⚠️ 这是 Router v1 20.1.5 benchmark 暴露的最大盲区（0/3 识别正确）。
> 本文档是 Stage 20.2 最重要的问题模式。

---

## 识别特征

机理建模的核心信号：**题目中存在已知的物理/化学/生物/工程定律**。

但问题在于——这些定律常常不直接出现。需要从"间接信号"推断。

## 直接信号（高置信度）

| 信号 | 示例 | 置信度 |
|------|------|:---:|
| 引用了具体定律名称 | "根据菲克扩散定律""基于麦克斯韦方程" | 确定 |
| 引用了方程名称 | "Hodgkin-Huxley方程""Navier-Stokes方程" | 确定 |
| 使用了微分/导数符号 | "浓度对时间的导数""变化率" | 高 |
| 描述了物理过程参数 | "扩散系数""电导率""衰减常数" | 高 |
| 引用了经验公式 | "Okumura-Hata模型""Colebrook公式" | 高 |

## 间接信号（需要推断）

| 信号 | 为什么是机理 | 容易误判为 |
|------|------------|-----------|
| "过程""演化""动态" | 暗示连续变化过程 | 时间序列预测 |
| "传播""扩散""传导" | 物理传播机制 | 空间统计 |
| "反应""转化""生成" | 化学/生化过程 | 分类/回归 |
| "激励""响应""反馈" | 控制系统/信号处理 | 因果分析 |
| "衰减""放大""共振" | 物理特性参数 | 相关性分析 |
| "流""通量""梯度" | 连续介质/场 | 回归 |

## 关键区分：何时是"机理"而非"预测"

```
问题：题目说"建立模型预测XX的变化"

判断链：
│
├─ 有已知物理定律可用？
│   ├─ 是 → 机理建模（用定律推演，不是用数据外推）
│   │   例：用扩散方程预测污染物分布
│   │
│   └─ 否 → 只有历史数据？
│       ├─ 是 → 数据驱动的预测
│       │   例：用ARIMA预测股价
│       │
│       └─ 数据+经验公式混合？
│           └─ 混合型：先机理后数据校正
│               例：Okumura-Hata经验公式 + AI残差校正 → 2019A
```

## 关键区分：何时是"混合型"

```
问题：题目涉及物理定律，但也需要优化/预测

判断：
├─ 第一步需要建立物理方程 → 本质含机理
│   └─ 后续步骤是什么？
│       ├─ 优化参数 → 机理+优化（如2021C帕金森DBS）
│       ├─ 用方程预测 → 机理+预测（如2019E气候）
│       └─ 与数据比较验证 → 纯机理+验证
│
└─ 物理定律只作为背景知识，实际建模用纯数据方法
    └─ 不算机理，算纯数据驱动
```

## 子类型

| 子类型 | 识别信号 | 数学工具 |
|------|------|------|
| ODE系统 | "常微分方程""动力学""变化率" | Runge-Kutta, solve_ivp |
| PDE系统 | "偏微分""空间分布""扩散" | 有限差分/有限元 |
| 经验公式 | "XX公式""经验模型""半经验" | 公式+参数估计+AI校正 |
| 传递函数 | "传递函数""频率响应""控制系统" | 拉普拉斯变换 |
| 化学反应 | "反应""转化率""催化剂" | 反应速率方程 |
| 电/磁/电路 | "电路""电磁场""阻抗" | 基尔霍夫/麦克斯韦 |

## Router v1 20.1.5 失败案例分析

| 题目 | Router输出 | 根本原因 | Protocol修正 |
|------|------|------|------|
| 2021C 帕金森DBS | 优化(资源分配) | "优化DBS参数"触发优化关键词，忽略了Hodgkin-Huxley ODE前提 | Step2识别到"电刺激→神经元放电"的因果链→标记为机理基础 |
| 2019A 无线传播 | 预测(路径规划) | "传播""路径"触发预测+路径，忽略了电磁波物理定律 | Step3识别到经验公式Okumura-Hata→标记为机理骨架 |
| 2019E 全球气候 | 预测(中等时序) | "预测"压倒"动力学"，忽略了9大因素的因果系统 | Step2识别到多因素因果关系+物理机制→标记为混合型 |

**教训**：这三个失败案例的共同模式是——**题目中"预测"或"优化"的表层任务掩盖了物理定律驱动的底层结构**。

## 自查清单

面对一道题目时，问自己：
```
□ 题目是否引用/暗示了任何物理/化学/生物/工程定律？
□ 变量变化是否由内在机制驱动（而非纯数据模式）？
□ 描述中是否出现"过程""演化""动态""传播""扩散"等词？
□ 如果"预测"未来——是用定律推演还是用数据外推？
□ 如果"优化"参数——优化对象是需要先建模的系统还是直接可算的？
```

3 个以上"Yes" → 本质含机理建模。
