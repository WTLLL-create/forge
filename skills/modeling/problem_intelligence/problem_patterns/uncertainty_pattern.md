# Uncertainty Pattern — 不确定性/概率模型问题模式

## 识别特征

不确定性问题的核心：**变量取值不是确定的，而是随机/概率的**。

## 子类型

| 场景 | 数学形式 | 方向 |
|------|------|------|
| 已知分布推断参数 | 参数估计 | MLE/贝叶斯 |
| 小样本+先验知识 | 贝叶斯推断 | MCMC |
| 随机过程模拟 | 蒙特卡洛 | 随机采样+统计 |
| 噪声+测量误差 | 滤波/估计 | Kalman/粒子滤波 |
| 概率风险评估 | 风险量化 | 概率模型+TVaR |

## 识别信号

- "随机""概率""噪声""误差"
- "不确定性""波动""方差"
- "蒙特卡洛""仿真""模拟"
- "先验""后验""贝叶斯"

## 与机理的区别

- 机理：有确定性定律 → 方程描述
- 不确定性：有随机因素 → 概率描述
- 混合：确定性定律 + 噪声 → 随机微分方程/状态空间模型
