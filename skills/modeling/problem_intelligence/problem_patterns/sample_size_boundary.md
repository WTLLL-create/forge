# 评价对象样本规模边界定义

> 目的：防止"少量评价对象 <10"被机械套用，忽略真实样本展开计算。
> 修复来源：v7.8 Application Calibration — 2026 D题发现 3品种×7时间点=19 被误判为<10。

---

## 评价样本规模分档

```
very_small（极少）:
  n < 10
  → 几乎不可能进行统计推断
  → 仅适合定性排序或专家判断

small（少量）:
  10 ≤ n < 30
  → 统计检验可执行，但功效有限
  → 适合熵权法/TOPSIS/AHP
  → 参数检验需谨慎（Shapiro-Wilk功效不足）

medium（中等）:
  30 ≤ n < 100
  → 参数检验可靠
  → 所有评价方法可用

large（大量）:
  n ≥ 100
  → 所有方法可用
  → 适合秩和比法(RSR)自动分档
```

---

## 样本计数规则

**评价对象数量 ≠ 时间点数量。**

必须按实际展开：

```
n = 品种数 × 时间点数 × 重复数（如有）

示例：
  3品种 × 7时间点 = 21（无重复）
  3品种 × 6~7时间点 = 19（不等长设计）
  5品种 × 4时间点 = 20
```

**不等长时间设计处理**：
- 单独评价各品种时：按各品种自身时间点计数
- 跨品种联合评价时：取最小公共时间点截齐或分开处理

---

## 关联模型选择

| 样本规模 | 推荐评价模型 | 注意事项 |
|----------|-------------|----------|
| very_small (n<10) | 专家打分、AHP（需专家） | 不做统计检验 |
| small (10≤n<30) | 熵权法+TOPSIS、灰色关联 | 标注重信区间，参数检验功效果差 |
| medium (30≤n<100) | 以上全部 + 秩和比法(RSR) | 权重对比建议 ≥2种方法 |
| large (n≥100) | 以上全部 + 机器学习排序 | 分级可用自然断点/K-means/等距 |

## 训练案例

### Case 1: 2026 D题 核桃油品质评价

```
输入: 3品种 × 6~7时间点
展开: 香玲6 + 鲁光6 + 山核桃7 = 19
分档: small (10 ≤ 19 < 30)
结论: 熵权法+TOPSIS 可行；ANOVA需补充非参数替代
```

### Case 2: 5方案 × 4时间点

```
输入: 5方案 × 4时间点
展开: 5×4 = 20
分档: small (10 ≤ 20 < 30)
结论: 同上
```

### Case 3: 2品种 × 3时间点

```
输入: 2品种 × 3时间点
展开: 2×3 = 6
分档: very_small (6 < 10)
结论: 不做统计推断，仅做描述性对比
```
