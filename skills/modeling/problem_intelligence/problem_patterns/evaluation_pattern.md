# Evaluation Pattern — 评价类问题模式

## 识别特征

评价问题的核心三要素：**多个对象 + 多维度指标 + 需要排序/打分/分级**。

## 子类型

| 场景特征 | 子类型 | 方向 |
|------|------|------|
| 有专家可两两比较 | 主观评价 | AHP |
| 纯数据驱动 | 客观评价 | 熵权法+TOPSIS |
| 指标含模糊描述 | 模糊评价 | 模糊综合评价 |
| 大规模对象(>50) | 分级评价 | 秩和比法(RSR) |

## 关键提醒

- 指标体系是灵魂——每个指标必须有定义
- 权重必须讲理——不能直接给数字
- 正负向指标要区分
