# Optimization Pattern — 优化类问题模式

## 识别特征

优化问题的核心三要素：
```
目标函数 + 决策变量 + 约束条件
```

**缺一不可。** 只有"找最优方案"是优化。

## 本质

在可行域内搜索使目标函数极值化的决策变量取值。

## 子类型识别

### 通过问题结构判断

| 问题结构 | 子类型 | 信号 |
|------|------|------|
| 物品分配/资源配比 | 资源分配 | "分配""配比""产量计划" |
| 路线/路径/巡回 | 路径规划(VRP/TSP) | "路径""路线""配送""巡回" |
| 时间表/排班 | 调度 | "排班""调度""时间表""序列" |
| 仓库/设施位置 | 选址 | "选址""布局""建在" |
| 物品装入容器 | 装箱/背包 | "装入""背包""容器""容量" |

### 通过数学形式判断

| 数学形式 | 解法方向 | 信号 |
|------|------|------|
| 线性目标+线性约束 | LP/单纯形法 | 关系都成比例 |
| 含整数/0-1变量 | IP/MILP | "选或不选""整数个" |
| 非线性非凸 | 启发式/GA | "复杂非线性""多极值" |
| 多目标冲突 | 多目标优化 | "同时优化A和B""权衡" |

## 常见误判

| 表象 | 容易误判为 | 其实是 |
|------|-----------|------|
| "优化参数使拟合误差最小" | 优化 | 参数估计/回归 |
| "寻找最佳策略" | 优化 | 可能是评价（多方案排序） |
| "最大化预测精度" | 优化 | 模型选择/调参 |

## 与 Router v1 20.1.5 失败案例关联

20.1.5 中 2021C(帕金森DBS)被Router识别为"优化"，但实际是机理+优化混合：
- "优化DBS参数"触发了优化关键词
- 但参数优化的前提是建立Hodgkin-Huxley神经元ODE模型
- 这里是"先机理建模、再参数优化"的嵌套结构

**教训**：当"优化"的对象是需要先建模的系统时，本质是混合型。
