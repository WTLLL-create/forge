# Network Pattern — 网络/图模型问题模式

## 识别特征

网络问题的核心：**对象之间存在连接关系，通过连接传递/流动/影响**。

## 子类型

| 问题结构 | 数学形式 | 典型算法 |
|------|------|------|
| 节点间最短距离 | 最短路径 | Dijkstra/Floyd/A* |
| 网络中最大流量 | 最大流 | Ford-Fulkerson |
| 节点最优配对 | 匹配 | 匈牙利算法 |
| 网络结构设计 | 网络设计 | Steiner树/生成树 |
| 传播/级联效应 | 扩散模型 | SIR/级联模型 |

## 识别信号

- "节点""边""连接""网络"
- "从A到B的最短路径"
- "供应链""交通网""通信网""社交网络"
- "上游""下游""相邻"

## 常见误判

| 表象 | 容易误判为 | 其实是 |
|------|-----------|------|
| "配送路径优化" | 优化 | 本质是图论VRP |
| "供应链风险评估" | 评价 | 可能是网络流+评价 |

## 关键洞察

当"优化"问题中的约束和变量可以自然地表达为节点+边时，本质是图论问题——用图论建模会比纯数学规划更简洁。
