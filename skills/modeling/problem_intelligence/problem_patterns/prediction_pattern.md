# Prediction Pattern — 预测类问题模式

## 识别特征

纯预测问题的核心：**有历史数据，需要推断未知值，没有已知物理定律可用**。

（如果存在已知物理定律 → 本质是机理，见 mechanism_pattern.md）

## 与机理的区分线

```
有历史数据 + 需要推断未来
    │
    ├─ 有物理定律引导推断？→ 机理建模
    │   例：用扩散方程预测浓度分布
    │
    └─ 只有数据驱动推断？→ 纯预测
        例：用ARIMA预测GDP
```

## 子类型

| 数据特征 | 子类型 | 首选方向 |
|------|------|------|
| 极少数据(<30) | 小样本预测 | GM(1,1) |
| 有明显季节周期 | 季节时序 | SARIMA |
| 多变量+非线性 | 多维预测 | XGBoost/RF |
| 需要解释变量影响 | 可解释预测 | 线性回归 |
| 特征数>>样本数 | 高维预测 | PCA+回归 |

## 常见误判

| 表象 | 容易误判为 | 其实是 |
|------|-----------|------|
| "预测污染物扩散" | 预测 | 机理(PDE) |
| "预测神经元放电" | 预测 | 机理(ODE)+预测 |
| "预报""估计"等词 | 预测 | 可能是评价/分类 |
