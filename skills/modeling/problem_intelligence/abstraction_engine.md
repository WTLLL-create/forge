## 核心映射表

### 时间演变 → 数学范畴

| 描述特征 | 数学范畴 | 判定条件 |
|------|------|------|
| "随时间变化" + 有物理定律 | 动力系统(ODE/PDE) | protocol Step 2 识别到因果链 |
| "随时间变化" + 只有数据 | 时间序列 | 无已知物理定律 |
| "周期性变化" + 无定律 | 季节时序 | 有月度/季度周期 |
| "随时间变化" + 随机扰动 | 随机过程 | 提到噪声/随机 |

### 因果关系 → 数学范畴

| 描述特征 | 数学范畴 | 判定条件 |
|------|------|------|
| A变化导致B变化 + 有公式 | 机理(方程) | 公式来自物理/化学/生物 |
| A变化导致B变化 + 无公式 | 回归/因果推断 | 需要从数据学习关系 |
| 多个因素影响一个结果 | 多元回归/ML | 因素>3个 |

### 空间分布 → 数学范畴

| 描述特征 | 数学范畴 | 判定条件 |
|------|------|------|
| 不同位置浓度/温度不同 | 场(PDE) | 有扩散/传导机制 |
| 不同城市数值不同 | 空间统计 | 无物理机制 |
| 节点间有连接关系 | 图/网络 | 有显式连接关系 |

## 混合型判定规则

```
是否存在多种数学范畴的显著特征？

├─ 时间演变 + 因果关系 → 动力系统(机理)
│   例：2021C帕金森DBS — 神经元膜电位随时间演变 + 电刺激因果关系
│
├─ 网络拓扑 + 优化 → 网络优化
│   例：物流配送 — 节点(城市)+边(道路)+目标(最短路径)
│
├─ 机理骨架 + 数据校正 → 混合型(机理+预测)
│   例：2019A无线传播 — 经验公式(机理)+AI残差(数据)
│
├─ 时间演变 + 多因素 → 可能是预测也可能是机理
│   → 用 mechanism_pattern.md 的关键区分规则判断
│
└─ 子问题类型不同 → 分而治之
    例：2022E草原 — Q1评价+Q2优化+Q3系统动力学
```

## 从 Router v1 失败案例提取的抽象规则

### Rule A: "建模"≠"机理建模"（最重要）

```
触发词："建立XX模型"

判断：
├─ 模型中包含物理定律？→ 机理
│   证据：引用了具体定律名/方程名/物理参数
└─ 模型只描述数据关系？→ 统计/ML
    证据：使用"回归""分类""拟合"等词
```

### Rule B: "预测"可能是"用机理推演"

```
触发词："预测"

判断：
├─ 预测基于什么？
│   ├─ 基于物理定律推演 → 机理
│   │   例：用PDE预测浓度 → 机理
│   └─ 基于历史数据外推 → 预测
│       例：用ARIMA预测GDP → 预测
└─ 如果不确定 → 检查题目是否引用了具体定律
```

### Rule C: "优化参数"≠"运筹优化"

```
触发词："优化"

判断：
├─ 优化对象是什么？
│   ├─ 物理系统的参数 → 参数估计/校准
│   │   例：优化DBS参数使神经元响应最佳
│   │   需要先建立物理系统的模型(机理)
│   └─ 运营系统的决策 → 运筹优化
│       例：优化调度策略使总时间最短
└─ 如果不确定 → 检查"优化"是否发生在已建立的物理模型之上
```

## 使用方式

Agent 执行完 protocol Step 1-2 后，用本文档的映射表进行 Step 3 的判定：

```
1. 取出 Step 1 的"对象/空间/时间"特征
2. 取出 Step 2 的"关系类型"和"关键变量"
3. 查本文档的映射表 → 得到候选数学范畴
4. 应用混合型判定规则 → 确定最终本质类型
5. 输出 Step 3 的"数学本质判定"
```
