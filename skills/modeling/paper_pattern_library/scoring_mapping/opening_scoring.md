# 开篇写法评分映射（Opening-Scoring Mapping）

> 论文开头（摘要+问题重述+问题分析前两段）决定评委的第一印象。
> 本文件展示：不同写法 → 不同评分。

---

## 一、摘要段落的评分映射

### 写法 A：任务清单型（40-50 分档）

```
"本文使用 K-means 聚类对数据分组，
然后用随机森林建立预测模型，
最后用 NSGA-II 进行优化。"
```

| 评分维度 | 得分 | 说明 |
|----------|:---:|------|
| 问题理解 | 5/15 | 没有展示对问题本质的理解 |
| 创新性 | 3/15 | 零创新，纯工具罗列 |
| 模型合理性 | 10/25 | 模型选了但没说为什么 |

**为什么扣分**：读起来像 todo list，不像研究成果。

### 写法 B：方法导向型（50-60 分档）

```
"本文建立了基于数据驱动的预测优化模型。
通过特征工程提取关键因子，利用集成学习提升预测精度，
采用多目标优化算法搜索最优方案。"
```

| 评分维度 | 得分 | 说明 |
|----------|:---:|------|
| 问题理解 | 7/15 | 有方法描述但缺问题本质 |
| 创新性 | 5/15 | 换了个说法但仍是标准方法 |
| 模型合理性 | 12/25 | 有了大方向的论证 |

**为什么扣分**：换了个包装，本质上还是"用了三个模型"。

### 写法 C：矛盾驱动型（75-85 分档）

```
"水泥烧成系统电除尘器面临排放-功率-成本三重约束的不可兼得。
标准优化方法受限于两个挑战：54.7%的排放数据右删失
使代理模型失效；工况异质性导致单一全局优化陷入局部最优。
本文提出一种工况自适应的分层代理优化框架：
通过右删失诊断重构排放分布（解决挑战一），
利用工况聚类建立差异化的局部代理模型（解决挑战二），
在 Pareto 前沿上定量揭示排放-功率的权衡关系。"
```

| 评分维度 | 得分 | 说明 |
|----------|:---:|------|
| 问题理解 | 13/15 | 识别了核心矛盾和具体的建模挑战 |
| 创新性 | 12/15 | 框架是针对问题特征设计的，有改进 |
| 模型合理性 | 22/25 | 每个方法选择绑定了具体的问题特征 |

**为什么加分**：
- "不可兼得"→ 识别了矛盾的数学本质
- "54.7%右删失"→ 定量数据支撑
- "分层代理"→ 不是随机堆砌，而是问题驱动的架构设计

## 二、问题重述段落的评分映射

### 写法 A：复制题大型（30-40 分档）

```
"2026 年全国大学生数学建模竞赛 A 题要求研究
水泥烧成系统电除尘器的协同优化控制问题。
题目提供了 Cement_ESP_Data.csv 数据文件，包含..."
```

→ 评委反应：你在复述题目，没有分析。

### 写法 B：描述+概括型（50-60 分档）

```
"水泥生产过程中，电除尘器是关键的环保设备。
其核心挑战在于如何在满足排放标准的前提下
最大化经济效益和运行稳定性。
本题要求建立数学模型来解决这一问题。"
```

→ 差不多，但没有深度。

### 写法 C：矛盾定位型（75-85 分档）

```
"水泥烧成系统电除尘器的控制本质上是一个
约束耦合的优化问题：
排放受环保标准上限约束，功率受设备老化成本约束，
而两者之间存在复杂的非线性耦合——
降低排放需要增加功率，增加功率加速设备老化。
此外，实际监测数据中大量排放值低于检测下限（右删失），
使得真实的排放分布被系统性掩盖。

这些特征使得标准的数据驱动优化方法面临两个根本挑战：
(1) 如何在被删失的数据上建立可靠的代理模型？
(2) 如何在不同工况下找到统一的优化策略？
本文正是围绕这两个挑战展开。"
```

| 分段 | 功能 | 评分影响 |
|------|------|:---:|
| "约束耦合的优化问题" | 一句话定位问题的数学本质 | 问题理解 ↑ |
| "降低排放需要增加功率..." | 量化矛盾 | 问题分析 ↑ |
| "右删失""被系统性掩盖" | 发现数据中的隐藏问题 | 创新性 ↑ |
| "两个根本挑战" | 研究问题清晰聚焦 | 模型合理性 ↑ |

## 三、常见的开篇失误与对应的评分损失

| 失误 | 评分损失 | 评委潜台词 |
|------|:---:|------|
| 开头就是"本文使用XX模型" | -3~5 问题分析 | "你还没分析问题就在选方法，凭什么？" |
| 全文无一个具体数字的开篇 | -2~3 问题分析 | "定性描述谁都会，定量分析才见功力" |
| 没有点出"为什么这个问题难" | -3~5 创新性 | "如果问题不难，为什么需要建模？" |
| 开头和结尾毫无呼应 | -2~3 整体 | "开头提出的问题，结尾解决了吗？" |

## 四、开篇写作的自检清单

- [ ] 前 200 字内是否出现了"矛盾""权衡""冲突""不可兼得"中的至少一个词？
- [ ] 是否有至少一个定量数据（百分比/相关系统/样本数）？
- [ ] 是否提到了"为什么标准方法不适用"？
- [ ] 是否把题目复述转化为了"研究问题"？
- [ ] 摘要中的核心矛盾是否在正文开头再次出现？
