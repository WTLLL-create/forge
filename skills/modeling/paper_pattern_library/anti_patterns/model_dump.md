# 反例 1：模型堆砌（Model Dump）

> 最常见的中低分论文模式：罗列了一堆模型，但不解释为什么用、为什么组合、每个模型解决了什么问题。

---

## 一、反例特征

**一句话描述**：论文读起来像模型目录，而不是研究过程。

**典型表现**：

```
"本文使用了以下模型：
1. K-means 聚类对数据进行分组
2. 随机森林建立预测模型
3. NSGA-II 进行多目标优化
4. AHP 确定权重
5. TOPSIS 进行综合评价"
```

**核心问题**：读者（评委）读完后的反应是"所以呢？"

---

## 二、为什么这是低分模式

| 评分维度 | 扣分原因 |
|----------|----------|
| 问题分析 | 没有解释"为什么这个问题需要这些模型"——缺分析深度 |
| 模型合理性 | 模型选择没有论证，看起来是随机组合——缺理论依据 |
| 创新性 | 所有模型都是标准模型的直接应用——零创新 |
| 论文规范 | 没有逻辑主线，读起来像拼接——缺叙事结构 |

---

## 三、模型堆砌 vs 研究论证的对比

### 模型堆砌写法（低分）

```
"问题需要将数据分为不同类别，因此本文使用 K-means 聚类算法。
聚类后，对每一类数据，本文使用随机森林建立预测模型。
最后，本文使用 NSGA-II 算法进行多目标优化。"

→ 评委感受：堆砌了三个标准方法，没有任何思考。
```

### 研究论证写法（高分）

```
"审计数据显示，不同工况下的排放-功率关系差异显著：
高负荷工况下两者几乎不相关（ρ=0.12），而低负荷工况下
呈中度负相关（ρ=-0.53）。这一发现意味着：
一个全局模型无法刻画所有工况的行为。

为解决这一异质性问题，本文采用 K-means 聚类——
不是因为'需要聚类'，而是因为工况差异驱动了分群策略的必要性。
聚类数 K=4 的选择基于肘部法和轮廓系数的双重验证（图X）。

对每个工况群，本文独立训练随机森林代理模型。
选择 RF 的理由是它能自动捕捉排放-功率之间的非线性关系，
而无需显式假设函数形式——这对不同工况下关系形态各异的数据
尤为重要（线性模型在工况2的 R² 仅 0.34）。

三阶段的递进关系是：聚类解构异质性→代理模型压缩搜索空间→优化在压缩空间中搜索。
每阶段的选择由前一阶段的分析结果驱动，而非随意堆砌。"

→ 评委感受：每一步都有数据支撑的论证，模型组合是问题驱动的。
```

## 四、如何从"模型堆砌"修复为"研究论证"

### 修复步骤

```
Step 1: 对每个模型，问"为什么"
  不只是"为什么用这个模型"，更重要的是"为什么不用别的"
  → 找出驱动模型选择的问题特征

Step 2: 建立模型之间的因果链
  A → B 不只是"先后使用"，而是"因为A的发现，所以需要B"
  → 写出"A的结论→B的动机"

Step 3: 找出模型的"不当选择"
  每个模型至少有一个"如果不用这个模型会怎样"的对照
  → 验证模型选择的必要性

Step 4: 用问题特征重新组织论述
  不以"第X节 模型X"为结构
  而以"问题特征X → 需要能力X → 选择模型X"为逻辑
```

### 修复对照模板

```
❌ 修复前（堆砌）:
  "本章介绍本文使用的三个模型。"

✅ 修复后（论证）:
  "本章首先分析数据中 [特征A] 和 [特征B] 对建模的约束（§X.1）。
   基于此分析，§X.2 建立 [模型A] 以解决 [问题A]。
   [模型A] 的输出揭示 [发现C]，这一发现驱动了
   §X.3 中 [模型B] 的设计——[发现C]意味着需要 [能力C]。
   最后，§X.4 用 [模型C] 整合前两个模型的输出，实现了 [目标]。"
```

## 五、紧急自检

如果你发现自己写了以下任何一句话，立即停下来检查是否在堆砌：

- [ ] "本文使用了以下模型..."
- [ ] "此外，本文还使用了..."
- [ ] "最后，我们采用..."
- [ ] "本节介绍XX模型的原理"（除非你提出了模型改进，否则不需要介绍标准模型的原理）
- [ ] 连续 3 节以上以模型名称为标题
- [ ] 模型之间的过渡句只有"接下来""此外""最后"
