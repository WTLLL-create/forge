# 反例 2：没有研究问题的论文（Model Without Question）

> 论文做了很多事，但从头到尾说不清「这篇论文到底在研究什么问题」。

---

## 一、反例特征

**一句话描述**：论文是一系列操作的流水账，没有一个驱动全文的研究问题。

**典型表现**：

```
"本文首先对数据进行了预处理。
然后使用K-means进行聚类分析。
接着建立随机森林预测模型。
最后使用NSGA-II进行优化。"
```

**核心问题**：这些操作是串联起来了，但串联它们的逻辑是什么？读者不知道"为什么要做这些"。

---

## 二、为什么这是低分模式

| 评分维度 | 扣分原因 |
|----------|----------|
| 问题理解（15分） | 没有研究问题，说明没有真正理解题目在问什么 |
| 创新性（15分） | 没有研究问题就没有创新方向，操作都是标准流程 |
| 论文规范（10分） | 论文没有主线，读起来像实验报告 |

---

## 三、修复方法：给论文注入一个研究问题

### Step 1: 从题目中提炼研究问题

```
题目："建立模型优化水泥窑电除尘器控制参数"

❌ 错误理解："我要用K-means+RF+NSGA-II解这道题"

✅ 正确理解（研究问题）：
"如何在数据大量右删失的条件下，
为不同工况下的电除尘器设计可靠的优化控制策略？"
```

### Step 2: 用研究问题重新组织论文

```
修正后的论文开头：

"本文研究的问题是：
如何在数据大量右删失的条件下，
为不同工况下的电除尘器设计可靠的优化控制策略？

这一问题之所以困难，是因为：
(1) 54.7%的排放数据右删失使得标准代理建模失效；
(2) 不同工况下排放-控制参数的关系显著不同，
    单一全局模型无法准确描述。

本文的解决策略是：
(1) 建立Tobit模型处理右删失；
(2) 按工况分层建立独立的代理模型；
(3) 在各层代理模型上进行多目标Pareto优化。

全文围绕这两个挑战和三个解决步骤展开。"
```

### Step 3: 每章结尾回到研究问题

```
§X 结尾：
"本节建立的Tobit代理模型解决了研究问题中的第一个挑战——
右删失条件下标准回归失效。
模型R²从-0.26提升至0.71，验证了该解决方案的有效性。
下一步将解决第二个挑战——工况异质性。"
```

## 四、自检问题

- [ ] 论文的第一段（摘要之后）是否包含一个明确的问句？
- [ ] 这个问句是否能在全文的每一章中找到回答？
- [ ] 如果读者只读每章的第一段和最后一段，能否理解论文的研究逻辑？
