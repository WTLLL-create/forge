# 模式 D：机理优先型（Mechanism-First）

> 适用：问题有明确物理/化学/生物规律，但规律不足以完全描述系统。
> 核心结构：物理方程定骨架 → 数据校正补细节 → 混合模型兼顾合理性与精度

---

## 一、模式骨架

```
§1 问题背景与物理规律梳理
    罗列所有已知的物理/化学/生物定律
    → 哪些可以直接用？哪些需要简化？哪些完全未知？

§2 机理模型建立（骨架）
    从第一性原理出发推导核心方程
    → 方程简化（明确标注哪些项被忽略，忽略的理由）
    → 待定参数（哪些参数需要从数据中估计）

§3 数据校正（血肉）
    机理模型的残差分析（机理能解释多少？不能解释多少？）
    → 数据模型补偿残差
    → 耦合机制（机理输出 + 数据校正 = 最终输出）

§4 模型验证
    纯机理 vs 纯数据 vs 机理+数据混合 的三方对比
    → 混合模型在哪些方面优于纯方案

§5 物理洞察
    混合模型揭示了什么物理上已知但数据中隐含的规律？
```

---

## 二、标志性特征

- 题目中有已知方程（如传热方程、反应动力学方程）
- 数据量可能不足以纯数据驱动
- 需要外推（纯数据模型做不到）
- 需要物理可解释性

---

## 三、论文核心段落示例

```
（机理建立段）

根据傅里叶传热定律和能量守恒，作业服内部的温度分布
满足一维非稳态热传导方程：
[方程]

该方程的边界条件为：
- 内层（皮肤侧）：T(0,t) = T_body = 37°C
- 外层（环境侧）：[对流换热边界条件]

注意到，服装材料的导热系数k和比热容c在题目中未直接给出，
但实验数据提供了不同厚度下内外温差。
这使得k和c成为待定参数——通过最小化模型预测与实验数据
的差异来确定。

（数据校正段）

纯机理模型在稳态阶段的预测误差 < 3%（图X），
但在瞬态阶段（t < 10min）误差高达 12%（图Y）。
误差分析表明，瞬态阶段的偏差来源于：
忽略了服装内部空气层的热容效应。

由于从第一性原理精确建模空气层的对流过于复杂，
本文采用数据驱动的方式校正这一偏差：
在机理模型的残差上训练一个轻量级神经网络，
专门捕捉瞬态阶段的非线性动态。
```
