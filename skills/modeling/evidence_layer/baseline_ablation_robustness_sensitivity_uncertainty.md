# 基线设计 / 消融 / 鲁棒性 / 敏感性 / 不确定性

> 证据层的五个核心实验范式。每一项对应论文中的一个"证明"：基线证明"比谁好"，消融证明"哪部分好"，鲁棒性证明"不是偶然好"，敏感性证明"哪里最关键"，不确定性证明"好的范围是多少"。

## 一、基线设计（Baseline Design）

### 为什么基线不是随便选的

```
错误的基线选择：
  选一个明显很弱的方法 → 你的方法"看起来"很强
  → 评委："你故意选弱的比"

正确的基线选择：
  选一个简单但合理的方法（下界）+
  选一个公认的标准方法（对标）+
  选一个可能更强的方法（上界挑战）
  → 评委："这个对比是公平且有深度的"
```

### 三级基线体系

| 级别 | 基线类型 | 示例（预测类） | 作用 |
|:---:|------|------|------|
| L1 | 简单基线 | 均值预测 / 多数类预测 | 证明"你的模型至少比瞎猜好" |
| L2 | 标准基线 | 线性回归 / ARIMA / OLS | 证明"你的模型比标准方法好" |
| L3 | 强基线 | RF / XGBoost / LSTM | 证明"你的模型比公认强方法好或至少不差" |

**规则**：至少包含 L1+L2。如果声称"优于现有方法"，必须包含 L3。如果只在 L1+L2 上对比，不能说"优于现有方法"，只能说"优于经典方法"。

### 各题型的推荐基线

| 题型 | L1 简单 | L2 标准 | L3 强基线 |
|------|---------|---------|----------|
| 预测(回归) | 均值预测 | 线性回归 | RF / XGBoost |
| 预测(时序) | 朴素预测(yt=yt-1) | ARIMA | LSTM(Nt>500) |
| 分类 | 多数类 | Logistic回归 | RF / XGBoost |
| 优化(线性) | — | LP（就是标准答案） | — |
| 优化(非线性) | 随机搜索 | GA | PSO / 差分进化 |
| 评价 | 等权 | 熵权+TOPSIS | AHP+TOPSIS |

## 二、消融实验设计（Ablation Design）

### 核心问题

```
你的模型 = A + B + C（三个改进组件）

如果只说"完整的A+B+C比基线好"：
  → 评委："你怎么知道是A起作用了，不是B或C？"
  → 你无法回答 → 创新声明不成立

消融实验回答：
  去掉A后 → 性能退化ΔA（证明A的贡献）
  去掉B后 → 性能退化ΔB（证明B的贡献）
  去掉C后 → 性能退化ΔC（证明C的贡献）
```

### 标准消融表结构

| 配置 | R² | RMSE | 退化率 | 结论 |
|------|----|------|:---:|------|
| **完整模型(A+B+C)** | **0.85** | **2.1** | — | — |
| 去掉A（仅B+C） | 0.72 | 3.4 | 15.3% | A不可或缺 |
| 去掉B（仅A+C） | 0.80 | 2.5 | 5.9% | B有贡献但非关键 |
| 去掉C（仅A+B） | 0.65 | 4.1 | 23.5% | C最关键 |
| 基线(无任何改进) | 0.45 | 6.8 | 47.1% | 整体框架价值 |

### 消融的论文表达

```
消融实验（表X）量化了每个改进组件的贡献：
- 去除 [组件C] 后性能退化最大（23.5%），验证了 [C的核心作用]；
- 去除 [组件A] 后退化15.3%，其价值在于 [A解决的具体问题]；
- 去除 [组件B] 后退化最小（5.9%），但其 [非性能价值]
  （如可解释性/计算效率）仍使其值得保留。
```

## 三、鲁棒性验证（Robustness Analysis）

### 五个维度的鲁棒性

| 维度 | 扰动方式 | 论文表达 |
|------|----------|----------|
| 数据鲁棒 | 加入5%/10%随机噪声 | "在5%噪声下RMSE仅增加3.2%，表明对数据质量不敏感" |
| 参数鲁棒 | 关键参数 ±20% | "参数±20%变化时排名变动<2位" |
| 初始化鲁棒 | 多次运行(≥5次)不同随机种子 | "5次运行均值±std: 0.85±0.03，变异系数仅3.5%" |
| 样本鲁棒 | 随机去掉10%/20%样本 | "去掉20%样本后R²仅下降0.04" |
| 方法鲁棒 | 换一个近似方法重算 | "LP松弛解与启发式解差距<3%，验证了近似质量" |

### 鲁棒性的论文表达

```
为验证 [结论] 的可靠性，进行了 [N] 项鲁棒性检验：
(1) 数据鲁棒：加入10%噪声，[指标] 仅 [退化量]；
(2) 参数鲁棒：[参数]±20%，[指标] 波动范围 [a,b]；
(3) 初始化鲁棒：5次独立运行，[指标] 变异系数=[X]%。
三项检验结果表明，[结论] 对 [扰动因素] 具有稳健性。
```

### 单因素敏感性（龙卷风图）

```
对每个参数/因素单独 ±10%，按影响力降序排列：

V2(二电场电压): 目标值变化 ±8.1%   ████████     ★★ 中敏感
R_rap(振打频率): 目标值变化 ±2.3%   ██           ★ 低敏感
```

### 双因素交互敏感性（热力图）

```
V1 × V2 组合的敏感性热力图：
                    V2
            -10%    0%    +10%
V1  -10%   0.82   0.85   0.81
      0%   0.87   0.88   0.85
    +10%   0.83   0.84   0.79
```

### 敏感性分析的论文表达

```
敏感性分析（图X）揭示了各参数的相对重要性：
[参数A] 贡献了 [X%] 的总方差，是最关键的控制变量，
建议在实际工程中优先精确控制；
[参数C] 的贡献<3%，对结果几乎无影响，
可以放宽控制精度以降低成本。
```

## 五、不确定性量化（Uncertainty Analysis）

### 为什么不确定性是加分项

```
普通论文：
  "最优排放浓度 = 6.8 mg/Nm³"（一个确定的数）
  → 评委："你哪来的自信？"

高分论文：
  "最优排放浓度的95%置信区间为 [5.9, 7.6] mg/Nm³"
  → 评委："你知道自己不确定到什么程度——这叫实事求是"
```

### 三类不确定性

| 类型 | 来源 | 量化方法 | 论文表达 |
|------|------|----------|----------|
| 参数不确定 | 模型参数估计不精确 | Bootstrap CI | "参数的95% CI为[a,b]" |
| 数据不确定 | 测量误差/采样偏差 | Monte Carlo 模拟 | "考虑数据噪声后的均值±σ" |
| 模型不确定 | 模型结构选择的主观性 | 多模型对比 | "三个合理模型下的结论一致性" |

### 不确定性量化的论文表达

```
传统方法给出 [一个点估计 = X]。
本文通过 [方法] 量化了该估计的不确定性：
95%置信区间为 [a, b]，宽度 [b-a] 反映了 [不确定性来源]。
这一区间意味着，[实际值] 有95%的概率落在 [a,b] 内——
这是一个比单一点估计更诚实的结论。
```
