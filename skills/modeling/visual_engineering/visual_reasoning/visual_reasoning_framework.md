# 视觉推理框架（Visual Reasoning Framework）

> Stage 28 的总入口。不是"美化论文"，而是"把复杂推理压缩成评委几秒可理解的信息结构"。
>
> 核心命题：**论文中每一张图、每一个表，都必须回答一个具体的研究问题。**

---

## 一、视觉表达的四个层级

```
Level 0: 无图 — 纯文字描述（信息密度最低）
Level 1: 有图但仅装饰 — 图与论点无直接关联
Level 2: 有图且展示数据 — 图展示了结果但无解释引导
Level 3: 有图且论证 — 图本身就是论据，标题=结论（信息密度最高）
```

| 层级 | 示例 | 评委感受 | 得分影响 |
|:---:|------|------|:---:|
| 0 | 全篇文字 | "不直观，信息获取成本高" | -3~5 |
| 1 | 配了流程图但没解释 | "知道你在做什么，但不知道你为什么选这个流程" | 基准 |
| 2 | 数据图+简单标题 | "你展示了结果" | +2 |
| 3 | 图标题=结论 | "你的图本身在讲一个故事" | +3~5 |

## 二、内容→表达形式映射（核心）

| 论文内容类型 | 信息特征 | 推荐表达形式 | 论文中位置 |
|-------------|----------|-------------|-----------|
| 研究整体流程 | 线性/分层/有分支 | 技术路线图 | §1 问题分析末尾 |
| 问题机制/因果关系 | 有向/多因素/反馈 | 机制框架图 | §2 问题分析 |
| 模型内部结构 | 分层/模块化/数据流 | 模型架构图 | §3 模型建立 |
| 算法步骤 | 顺序/条件分支/循环 | 算法流程图 | §3 模型求解 |
| 模型预测效果 | 连续值×时间/样本 | 预测vs真实曲线+残差 | §4 结果分析 |
| 多模型对比 | 多方法×多指标 | 分组柱状图/雷达图 | §4 结果分析 |
| 优化结果 | 目标空间中的解集 | Pareto前沿图 | §4 结果分析 |
| 参数敏感度 | 参数×输出的变化 | 龙卷风图/热力图 | §4 敏感性分析 |
| 消融实验 | 完整vs消融的对比 | 分组柱状退化图 | §4 消融分析 |
| 误差分析 | 残差的空间/时序/分布特征 | 残差图+ACF+QQ图 | §4 结果分析 |
| 评价排序 | 多对象×综合得分 | 排序柱状图 | §4 结果分析 |
| 权重分布 | 多维度的占比 | 饼图/环图/雷达图 | §3 模型建立 |
| 空间分布 | 位置×指标值 | 空间热力图/等值线 | §2/§4 |
| 收敛过程 | 迭代×指标值 | 收敛曲线 | §3 模型求解 |

## 三、每个图/表的五问自检

生成每个图表前，必须回答：

```
1. 这张图在回答什么问题？
   （不是"展示结果"，而是"证明XX是正确的"或"解释YY为什么发生"）

2. 如果删掉这张图，论证链条会断裂吗？
   （如果不会 → 这张图是冗余的，考虑删除或合并到文字中）

3. 读者只看这张图和标题，能理解核心结论吗？
   （如果必须读正文才能理解 → 标题写得太弱，升级为"标题=结论"）

4. 这张图和正文的关系是什么？
   （正文应该解释图"为什么是这个样子的"，而非复述图上的数字）

5. 这张图的最佳表达形式是什么？
   （折线/柱状/散点/热力/Pareto... 选择是否正确？）
```

## 四、图标题的三级标准

```
Level 1（弱）: "图3 模型结果"
   → 不知道是什么结果，不知道好还是坏

Level 2（中）: "图3 不同模型的RMSE对比"
   → 知道在比什么，但不知道结论

Level 3（强）: "图3 随机森林在排放预测中RMSE最低(1.85)，
              相比OLS回归(5.23)降低64.6%"
   → 标题本身就是一个完整的发现。评委只看图和标题就能理解。
```

**原则**：图标题应该是一个完整的句子，包含"什么方法/条件 + 什么结果 + 意味着什么"。

## 五、论文中的图表密度

| 论文部分 | 最少图表数 | 推荐图表数 | 说明 |
|----------|:---:|:---:|------|
| 问题分析 | 1 | 1-2 | 技术路线图/机制框架图（必选其一） |
| 模型建立 | 1 | 2-3 | 模型架构图 + 算法流程图 + 符号表 |
| 模型求解 | 0 | 1 | 收敛曲线（优化类必选） |
| 结果分析 | 2 | 3-4 | 预测对比 + 残差分析 + 特征重要性 |
| 模型对比 | 1 | 1-2 | 多模型指标对比表 + 雷达图 |
| 消融实验 | 1 | 1 | 消融退化图/表 |
| 敏感性分析 | 1 | 1-2 | 龙卷风图 + 热力图 |
| 模型评价 | 0 | 1 | 模型优缺点对比表 |

**总数**：至少 6 张图 + 3 个表，推荐 8-12 张图 + 4-6 个表。

> 表格数量与列结构以 `standards/academic_table_standard.md` 和锁定的 `table_spec.json`
> 为准，无固定配额；此处仅作历史思路参考。

## 六、常见图表使用错误

| 错误 | 为什么错 | 正确做法 |
|------|----------|----------|
| 饼图表示模型对比 | 饼图适合占比，不适合多维度对比 | 分组柱状图/雷达图 |
| 3D柱状图 | 3D造成视觉扭曲，数量难以精确比较 | 2D分组柱状图 |
| 堆叠柱状图用于趋势对比 | 堆叠使中间段难以比较 | 分组柱状图/折线图 |
| 热力图用彩虹色 | 彩虹色非线性，人眼难以映射到数值 | 单色渐变 |
| 散点图无拟合线 | 看不出趋势 | 加趋势线 + R²标注 |
| 箱线图无样本量标注 | 不知道可靠性 | 标注 N 值 |
| 折线图点太密 | 信息过载 | 降采样或增加透明度 |
