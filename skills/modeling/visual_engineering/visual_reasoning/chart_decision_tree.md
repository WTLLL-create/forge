# 图表选择决策树（Chart Decision Tree）

> 从论文论点出发，逐层判断，最终定位到具体图表类型。
> 可以直接被代码化——输入"论点类型+数据特征"，输出"推荐图表+配置参数"。

---

## 一、主决策树

```
我要展示什么？

├─ 研究框架/流程
│   └─ 技术路线图（节点=阶段，箭头=流转，颜色=层）
│
├─ 变量/因素之间的因果关系
│   └─ 机制框架图（节点=因素，箭头=影响方向，标注=效应量）
│
├─ 算法/方法的执行步骤
│   └─ 流程图（矩形=操作，菱形=判断，箭头=流转）
│
├─ 模型的内部结构
│   └─ 模型架构图（分层/模块化，标注输入输出维度）
│
├─ 数值结果
│   ├─ 是预测值 vs 真实值吗？
│   │   ├─ 有时序 → 双线折线图（预测+真实叠加，不同颜色+线型）
│   │   └─ 无时序 → 散点图 + 1:1参考线 + R²标注
│   │
│   ├─ 是多个模型对比吗？
│   │   ├─ 对比单个指标 → 分组柱状图（标注数值+最优加粗）
│   │   └─ 对比多个维度 → 雷达图（维度≤8，否则选分组柱状图）
│   │
│   ├─ 是优化结果吗？
│   │   ├─ 1个目标 → 收敛曲线（代数×目标值）
│   │   ├─ 2个目标冲突 → Pareto散点图 + 膝盖点标注
│   │   └─ 3个目标 → 3D散点图 + 2D投影图
│   │
│   ├─ 是敏感性分析吗？
│   │   ├─ 单参数 → 龙卷风图（按影响大小降序）
│   │   └─ 双参数交互 → 热力图（颜色深浅=输出值）
│   │
│   ├─ 是消融实验吗？
│   │   └─ 分组柱状退化图（完整vs消融×指标，标注退化%）
│   │
│   ├─ 是误差分析吗？
│   │   ├─ 残差分布 → 直方图 + QQ图
│   │   ├─ 残差vs拟合值 → 散点图（检查异方差）
│   │   └─ 残差时序 → ACF图（检查自相关）
│   │
│   ├─ 是评价排序吗？
│   │   └─ 水平柱状图（降序，得分标注，前3高亮）
│   │
│   └─ 是空间分布吗？
│       └─ 空间热力图 / 等值线图
│
├─ 数据探索
│   ├─ 看分布 → 直方图 + 核密度曲线
│   ├─ 看相关 → 相关性热力图（标注数值，|ρ|>0.7高亮）
│   ├─ 看异常 → 箱线图 + 标注离群点
│   └─ 看趋势 → 时序折线图 + 趋势线
│
└─ 模型评价
    ├─ 优缺点对比 → 结构化对比表
    └─ 改进前后 → 并排对比图（Before/After）
```

## 二、子决策：柱状图类型选择

```
柱状图 → 选哪种？

├─ 对比单个指标的多组数据
│   └─ 标准柱状图（单色/按组着色）
│
├─ 对比多个指标的多组数据
│   └─ 分组柱状图（每组并排，颜色=指标，X轴=组）
│
├─ 展示各部分占总体的比例
│   └─ 堆叠柱状图（每柱总量=100%，颜色=部分）
│       ⚠️ 不推荐用于趋势对比（中间段难比较）
│
└─ 展示排序
    └─ 水平柱状图（Y轴=对象名，X轴=值，降序排列）
```

## 三、子决策：折线图类型选择

```
折线图 → 选哪种？

├─ 单一序列随时间变化
│   └─ 标准折线图
│
├─ 多个序列对比（≤5条）
│   └─ 多线折线图（不同颜色+线型，标注图例）
│
├─ 多个序列对比（>5条）
│   └─ 分面折线图（每个序列一个子图）
│      或 突出1-2条主序列，其余用浅灰色
│
├─ 预测值+真实值对比
│   └─ 双线折线图（不同颜色，真实=实线，预测=虚线）
│
├─ 有置信区间
│   └─ 折线图 + 误差带（半透明填充）
│
└─ 展示收敛过程
    └─ 折线图（X=迭代次数，Y=目标值，标注终止值）
```

## 四、子决策：散点图类型选择

```
散点图 → 选哪种？

├─ 检查两个连续变量的关系
│   └─ 标准散点图 + 趋势线 + R²标注
│
├─ 检查预测质量
│   └─ 散点图 + 1:1参考线 + R²和RMSE标注
│       （X轴=真实值，Y轴=预测值）
│
├─ 展示Pareto前沿
│   └─ 散点图（X=目标1，Y=目标2）+ 膝盖点高亮
│
├─ 检查残差异方差
│   └─ 散点图（X=拟合值，Y=残差）+ 水平参考线
│
├─ 高维数据降维可视化
│   └─ 散点图（PCA/t-SNE前2维，按类别着色）
│
└─ 点太多(N>10000)导致重叠
    └─ 二维直方图(hexbin)或半透明散点图(alpha=0.1)
```

## 五、论文图表编号规则

```
全文连续编号（国赛推荐）：
  图1, 图2, 图3...
  表1, 表2, 表3...

按章节编号（学术论文常见）：
  图2.1, 图2.2, 图2.3... (第2章的第1/2/3张图)
  表3.1, 表3.2...

当前默认：全文连续编号（python-docx实现最简单）
```
