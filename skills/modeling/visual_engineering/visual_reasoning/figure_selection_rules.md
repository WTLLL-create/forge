# 图表选择规则（Figure Selection Rules）

> 给定论文中的一个信息节点，输出最优的图表类型。
> 不做工具推荐（matplotlib/seaborn/plotly），只做"应该画什么图"的决策。

---

## 一、按论文阶段选择

### 问题分析阶段

| 你想展示什么 | 推荐图类型 | 为什么 |
|-------------|-----------|--------|
| 研究整体流程 | **技术路线图** | 让评委30秒内理解你的研究框架 |
| 变量之间的关系 | **机制框架图** | 展示因果/影响/反馈链条 |
| 数据的基本特征 | **分布直方图 + 箱线图** | 建立对数据的第一印象 |
| 数据的时间趋势 | **时序折线图** | 展示整体走势 |
| 变量间的相关性 | **相关性热力图** | 一眼看出哪些变量强相关 |
| 缺失/异常值 | **缺失矩阵图** | 展示数据质量问题 |

### 模型建立阶段

| 你想展示什么 | 推荐图类型 | 为什么 |
|-------------|-----------|--------|
| 模型的内部结构 | **模型架构图** | 分层/模块化展示 |
| 算法执行步骤 | **流程图** | 顺序+分支+循环 |
| 符号定义 | **符号表（三线表）** | 统一全局符号 |
| 模型假设 | **假设条件图** | 展示假设如何简化问题 |

### 结果分析阶段

| 你想展示什么 | 推荐图类型 | 为什么 |
|-------------|-----------|--------|
| 预测值 vs 真实值 | **散点图 + 1:1线 + R²标注** | 一眼看出预测质量 |
| 时序预测效果 | **折线图（预测+真实叠加）** | 展示时间维度上的追踪 |
| 预测误差分布 | **残差直方图 + QQ图** | 检查正态性假设 |
| 残差模式 | **残差 vs 拟合值散点图** | 检查异方差+非线性 |
| 多模型指标对比 | **分组柱状图** | 最直观的数值对比 |
| 多模型多维对比 | **雷达图** | 同时展示精度/速度/解释性等维度 |
| 优化Pareto前沿 | **散点图（Pareto前沿）+ 膝盖标注** | 展示目标间权衡 |
| 优化收敛过程 | **折线图（代数×目标值）** | 展示算法是否收敛 |
| 评价对象排序 | **水平柱状图（降序）** | 排名一目了然 |
| 指标权重 | **环图/雷达图/堆叠柱状图** | 展示权重分配 |
| 参数敏感性 | **龙卷风图** | 按影响大小排序展示 |
| 多参数交互敏感性 | **热力图** | 展示参数组合效应 |
| 消融实验结果 | **分组柱状退化图** | 突出"去掉X后恶化Y%" |
| 空间分布 | **空间热力图/等值线图** | 展示空间模式 |

### 模型评价阶段

| 你想展示什么 | 推荐图类型 | 为什么 |
|-------------|-----------|--------|
| 模型优缺点对比 | **对比表** | 结构化呈现 |
| 改进前后对比 | **并排对比图** | 视觉化"Before vs After" |

## 二、按数据类型选择

### 连续值数据

| 数据特征 | 推荐图 | 备选 |
|----------|--------|------|
| 少量点（<20）的对比 | 柱状图 | 点图 |
| 大量点的分布 | 直方图 + 核密度 | 箱线图 |
| 两组数据的分布对比 | 并排箱线图/小提琴图 | 重叠直方图 |
| 两个连续变量的关系 | 散点图 + 趋势线 | 六边形bin图(N大时) |
| 多变量关系矩阵 | 散点图矩阵 / 相关性热力图 | 平行坐标图 |

### 时间序列数据

| 数据特征 | 推荐图 | 备选 |
|----------|--------|------|
| 单一序列 | 折线图 | — |
| 多序列对比 | 多线折线图（≤5条线） | 分面折线图(>5条) |
| 预测+真实值对比 | 双线折线图（不同颜色+线型） | 误差带图(有CI时) |
| 周期模式 | 季节性分解图 | 频谱图 |
| 残差自相关 | ACF/PACF图 | — |

### 分类/分组数据

| 数据特征 | 推荐图 | 备选 |
|----------|--------|------|
| 各类计数/频率 | 柱状图 | — |
| 各类占比 | 环图（不推荐饼图） | 堆叠柱状图 |
| 多分类×数值 | 分组柱状图 | 箱线图(每类一个) |
| 分类结果的混淆 | 混淆矩阵热力图 | — |

## 三、常见选图错误

| 你想展示 | 错误选图 | 为什么错 | 正确选图 |
|----------|----------|----------|----------|
| 多模型精度对比 | 折线图 | 折线暗示连续性，模型之间没有连续关系 | 柱状图 |
| 分类占比 | 3D饼图 | 3D扭曲视觉比例 | 环图/堆叠柱状图 |
| 双变量关系 | 双Y轴折线图 | 两个Y轴容易被人为操纵以制造相关假象 | 散点图 |
| 优化前沿 | 柱状图 | 看不出二维权衡关系 | Pareto散点图 |
| 权重变化 | 表格 | 表格看不出分配结构 | 环图/雷达图 |
| 收敛过程 | 终值柱状图 | 看不到是否真的收敛了 | 折线图（代数×值） |
