# Pareto 优化图 / 反例库

---

## Pattern F-006：Pareto 前沿图

### 适用场景
多目标优化问题，尤其是目标之间存在冲突时。

### 想证明什么
"这两个目标确实存在不可兼得的权衡关系，我选的方案在这个权衡中是最优折中。"

### 结构设计

```
标准Pareto前沿图：
  X轴 = 目标1（如"排放浓度 mg/Nm³"）
  Y轴 = 目标2（如"功率 kW"）
  方向标注：箭头 ← 越小越好
  散点 = Pareto最优解集
  标记点 = 推荐的膝盖点（★）
  标注点 = 极端方案（纯A优化 / 纯B优化）

附加元素（可选）：
  阴影区 = 不可行域
  虚线框 = "推荐决策区间"
  文字标注 = "以5%功率换取30%排放改善"
```

### 设计要点

| 要点 | 规范 |
|------|------|
| 坐标轴方向 | 标注箭头和"越小越好"/"越大越好" |
| 膝盖点标记 | ★ 或大圆点 + 箭头 + 数值标注 |
| 权衡标注 | 在前沿上选两个点标注"从A到B：改善X%，代价Y%" |
| 收敛验证 | 如果空间允许，在一旁加小图显示其它代数的前沿对比 |
| 颜色 | 前沿散点单色，膝盖点用强调色 |

### 常见错误

| 错误 | 为什么错 | 修正 |
|------|----------|------|
| 只标一个最优点 | 失去了多目标分析的意义 | 必须展示整个前沿 |
| 没有膝盖点分析 | 缺少决策指导 | 标注膝盖点+解释 |
| 坐标轴无方向标注 | 不知道哪个方向是"好" | 箭头+文字 |
| 没有极端方案标注 | 看不到纯A/纯B优化的位置 | 标注两个极端 |
| 前沿退化但没说 | 退化是重要发现 | 如果退化→在图中标注+正文分析 |

### 论文解释模板

```
图X展示了 [目标A] 和 [目标B] 的Pareto前沿。
前沿的整体形状为 [凸/凹/线性]，表明 [权衡特征]。

一个显著的特征是：在 [区域1]，
[目标B] 的小幅牺牲（[X]%）换取 [目标A] 的大幅改善（[Y]%）；
但在 [区域2]（膝盖点之后），
[目标A] 的进一步改善需要 [目标B] 的巨大代价。

基于此分析，本文推荐膝盖点方案：[A]=[值], [B]=[值]。
该方案在排放改善 [X%] 的同时，功率仅增加 [Y%]，
权衡效率最高。
```

## 模式 F-009：反例库

### 反例 1：无意义的装饰图

**表现**：论文中放了一张与核心论证无关的图（如"算法示意图""数据获取来源图"），没有回答任何研究问题。

**评委感受**："这张图为什么在这里？"

**修复**：每张图必须通过五问自检（`visual_reasoning_framework.md`），通不过就删除。

### 反例 2：有图无结论

**表现**：图标题="图3 预测结果"，没有说明结果是什么。评委必须读正文才能理解。

**修复**：标题升级为"图3 RF预测排放的RMSE为1.85，相比OLS回归(5.23)降低64.6%"

### 反例 3：过度复杂的图表

**表现**：一张图塞了5条线+3个Y轴+大量标注，读者需要研究3分钟才能理解。

**修复**：拆成2-3张图，每张只回答一个问题。

### 反例 4：视觉误导

**表现**：Y轴不从0开始，让微小差异看起来很大；或者双Y轴被操纵以制造"相关"假象。

**修复**：柱状图Y轴从0开始；双Y轴加灰色背景警告"双轴独立"；使用散点图检查真实相关。

### 反例 5：表格当作图用

**表现**：数据表直接截图当图用，字体极小，无法阅读。

**修复**：数据放三线表；图表用柱状/折线/散点；表格和图的职责分离。
