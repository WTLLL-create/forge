# 预测效果图 / 模型比较图

> 结果分析阶段最核心的两类图。一张证明"我的模型预测得好"，一张证明"我的模型比别人好"。

---

## Pattern F-005：预测效果图

### 适用场景
任何预测类问题的结果展示。

### 想证明什么
"我的模型不仅拟合了数据，而且学到了真实的规律，没有过拟合也没有系统偏差。"

### 结构设计

预测类论文的标准三件套：

```
图A: 预测值 vs 真实值散点图
  X轴 = 真实值, Y轴 = 预测值
  散点 + 1:1参考线（虚线）+ 趋势线
  标注 R² 和 RMSE
  → 证明：整体拟合质量

图B: 预测值 vs 真实值时序叠加图（如果有时序）
  X轴 = 时间, Y轴 = 值
  真实值（实线，深色）+ 预测值（虚线，浅色）
  训练区 + 测试区用竖线分隔
  → 证明：时序追踪能力 + 测试集泛化

图C: 残差分析图
  左：残差直方图 + 正态曲线
  右：残差 vs 拟合值散点图 + 水平线
  标注残差均值和标准差
  → 证明：无系统性偏差
```

### 设计要点

| 要点 | 规范 |
|------|------|
| 1:1参考线 | 虚线+浅灰色，标注"y=x" |
| R²标注 | 直接标注在图内，字体清晰 |
| 训练/测试分区 | 竖虚线分隔，标注"训练区""测试区" |
| 颜色 | 真实=深色，预测=浅色，不互补色 |
| 残差散点 | 每点半透明，大量点时不遮挡 |
| 残差参考线 | y=0 处水平虚线 |

### 常见错误

| 错误 | 为什么错 | 修正 |
|------|----------|------|
| 只展示R²=0.95不提训练/测试 | 可能是过拟合 | 必须分开标注训练R²和测试R² |
| 预测和真实用同一颜色 | 无法区分 | 不同颜色+不同线型 |
| 没有1:1参考线 | 看不出系统性高估/低估 | 必须画1:1线 |
| 没有残差图 | 没有证据证明无系统偏差 | 预测类必须配残差图 |
| 测试区太小(<15%) | 测试不可靠 | 至少20%，时序按时间切分 |

### 论文解释模板

```
图X(a)展示了模型预测值与真实值的对比。
散点紧密分布在1:1参考线附近，R²=[X]，
RMSE=[Y]，表明模型整体拟合良好。

图X(b)展示了时间维度上的预测追踪。
在测试区（t > [X]），预测曲线准确跟踪了真实值的
[趋势/波动/拐点]，未出现明显的滞后或发散。

图X(c)的残差分析显示：残差均值接近0（[X]），
残差-拟合值散点图中无明显的模式（漏斗形/曲线形），
表明模型不存在系统性偏差。
```

## Pattern F-008：模型比较图

### 适用场景
多模型对比实验的结果展示。

### 想证明什么
"我选的模型不是随便选的，它在关键指标上确实优于其他候选方案。"

### 结构设计

```
方案A：分组柱状图（最常用）
  X轴 = 模型名
  Y轴 = 指标值
  每组 = 一个指标（颜色区分）
  → 适用：2-4个指标，3-6个模型

方案B：雷达图
  多轴 = 各维度（精度/速度/解释性/...）
  多边形 = 各模型
  → 适用：需要多维同时展示（≤8维）

方案C：双维度散点图
  X轴 = 精度（R²/RMSE）
  Y轴 = 复杂度（训练时间/参数数）
  每个点 = 一个模型
  → 适用：展示"精度-成本"权衡
```

### 设计要点

| 要点 | 规范 |
|------|------|
| 基线标注 | 必须有最简单的基线（均值预测/多数类） |
| 本文模型标注 | 用不同颜色或加★标记，高亮 |
| 数值标注 | 每根柱上标注数值（或只在本文模型上标注） |
| 提升百分比 | 标注"相比基线提升X%""相比次优提升Y%" |
| 显著性标注 | 如有统计检验，标注"* (p<0.05)""** (p<0.01)" |
| 坐标Y轴 | 不从0开始可能造成视觉误导，必须从0开始（除非是比率类指标） |

### 论文解释模板

```
图X对比了 [N] 个模型在 [M] 个指标上的表现。
[本文模型] 在 [关键指标A] 上达到 [值]，
相比基线（[基线名]，[值]）提升 [X%]，
相比次优模型（[次优名]，[值]）提升 [Y%]。

值得注意的是，[某模型] 在 [指标B] 上优于本文模型，
但它在 [指标A] 上的大幅退步（↓[Z%]）使得其整体不适用
——在本题场景中，[指标A] 的重要性高于 [指标B]，
因为 [理由]。
```
