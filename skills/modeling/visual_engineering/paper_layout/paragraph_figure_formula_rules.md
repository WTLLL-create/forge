## 一、段落工程

连接 Stage 26 `paragraph_reasoning.md` 的逻辑模板，追加可操作的排版规则。

### 标准段落长度

| 段落类型 | 推荐行数 | 说明 |
|----------|:---:|------|
| 问题分析段 | 4-6行 | 背景→困难→方法 |
| 模型建立段 | 5-8行 | 动机→假设→公式→解释 |
| 结果分析段 | 4-7行 | 陈述→解读→原因→对比 |
| 过渡段 | 1-2行 | 承上启下，≯2行 |

**信号**：一段超过10行→拆分。一段只有1句话→合并或扩展。

### 段落首句法则

```
每段的第一句话必须让读者知道：
  (a) 这一段在论证链条中的位置
  (b) 这一段要解决什么问题

✓ "上述分析揭示了右删失对标准回归的致命影响——
   54.7%数据不可靠导致R²=−0.26。本节建立Tobit模型解决这一问题。"
✗ "Tobit模型是一种处理删失数据的统计方法。"（教科书开头，不是论证开头）
```

### 段落结尾法则

```
每段最后一句必须是以下三者之一：
  (a) 本段的结论
  (b) 对下一段的预告
  (c) 回到论文主线的呼应

✗ "以上为模型建立的过程。"（废话）
✓ "综上，Tobit模型的R²=0.71，相比OLS回归(−0.26)验证了删失处理的必要性。
   接下来§X将基于此代理模型进行多目标优化。"
```

## 二、图表位置规则

### 图表出现位置的黄金法则

```
文字引导（1-2句）
    ↓
图/表
    ↓
文字解读（2-4句）
```

| 位置 | 缺了什么 | 后果 |
|------|----------|------|
| 只有图，无引导 | 读者不知道为什么这里突然有张图 | 图和正文脱节 |
| 只有图，无解读 | 读者看了图但不知道结论 | 图浪费了 |
| 只有引导+图，无解读 | 读者需要自己分析图 | 评委不会替你分析 |

### 引导句模板

```
✓ "图X展示了 [内容]。"
✓ "为验证 [论点]，本文对比了 [方案A] 和 [方案B]，结果见图X。"
✓ "[模型名] 的预测效果如图X所示。"
✗ "结果如下："（太弱）
✗ "如图："（太弱）
```

### 解读句模板

```
✓ "从图中可以看出，[发现1]。[证据]表明 [含义]。"
✓ "图X揭示了一个值得注意的特征：[特征]。这与 [预期/常识] [一致/不一致]，因为 [解释]。"
✗ "结果如图X所示。"（只有引导，没有解读）
✗ "图X展示了各模型的RMSE对比。"（只有陈述，没有解读）
```

### 图表引用规则

```
□ 每张图/表必须在正文中至少被引用一次
□ 引用方式："如图X所示""表Y列出了""（图X）"
□ 不能出现"下图""上表"（编号打印后才确定位置，可能对不上）
□ 图和表分开编号：图1,图2... / 表1,表2...
```

### 图表与正文的距离

```
□ 图表应放在第一次被引用的位置附近（同一页或下一页）
□ 不要把所有图堆在论文末尾（附录除外）
□ 小图（<半页）可以嵌入文字中
□ 大图（>半页）独占一页
```

## 三、公式陈述规则

### 公式前的引导

```
每条公式必须有"为什么建立这个公式"的前导句：

✓ "为描述 [变量A] 和 [变量B] 之间的关系，建立如下回归模型："
✓ "约束条件(2)表示 [物理/经济含义]："
✓ "目标函数(3)的含义是 [最大化/最小化] [具体目标]："
✗ "因此："（太弱）
✗ 直接甩公式，没有引导
```

### 公式后的解释

```
每条公式后必须有"这个公式意味着什么"的解释：

公式(3): max Σ c_i·x_i

✓ "目标函数(3)表示最大化总利润。其中c_i是第i种产品的单位利润，
   x_i是决策变量（日产量）。该目标函数是决策变量的线性函数——
   这是问题可以用LP精确求解的根本原因。"
✗ "其中c_i表示利润，x_i表示产量。"（只说变量含义，没说公式意义）
```

### 公式编号规则

```
□ 全文连续编号：(1),(2),(3)... 或按章：(3-1),(3-2)...
□ 编号右对齐
□ 正文引用时用括号："式(3)""由(5)可得"
□ 不编号的公式：中间推导的过渡公式可以不编号
```

### 公式字体规范

```
□ 变量：斜体 (x, y, α, β)
□ 向量/矩阵：粗斜体 (x, A)
□ 函数名：正体 (sin, cos, log, max, min)
□ 单位：正体 (kW, mg/Nm³)
□ 数字：正体
```

## 四、图/表/公式的三位一体检查

```
每提交一个"发现"之前，检查：

□ 这个发现是否有数据支撑？（表格 ✓）
□ 这个发现是否能被直观理解？（图表 ✓）
□ 这个发现是否有数学/物理依据？（公式 ✓）

三缺一 → 论证不完整。
三项都有 → 一张表+一张图+一个公式 = 完整的证据单元。
```

例：

```
发现："RF在排放预测中优于OLS"
  数据支撑：表X（RF R²=0.71 vs OLS R²=−0.26）
  直观理解：图Y（预测值vs真实值散点图）
  数学依据：公式(5)（Tobit似然函数解释了为什么OLS失效）
→ 完整的证据单元
```
