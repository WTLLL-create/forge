# 论文结构工程 + 章节论证规则

> 不是格式规范，而是"信息应该如何组织给评委看"的工程规则。
> 本文件覆盖：黄金九章结构 / 每章的信息任务 / 章节间的论证链接。

---

## 一、国赛论文黄金结构

| 章序 | 章节名 | 页数 | 核心任务 | 评委看什么 |
|:---:|------|:---:|------|------|
| — | 摘要 | 1页 | 全篇浓缩：问题→方法→结果→创新 | 30秒决定是否继续读 |
| 1 | 问题重述 | 0.5-1页 | 用自己的话重新表述问题 | 是否真正理解了题目 |
| 2 | 问题分析 | 1-2页 | 现实→数学，提炼研究问题 | 有没有分析深度 |
| 3 | 模型假设 | 0.5页 | 列出假设+每条的理由 | 假设是否合理、是否必要 |
| 4 | 符号说明 | 0.5-1页 | 全局符号表 | 符号是否清晰统一 |
| 5 | 模型建立 | 2-4页 | 为什么+公式+解释 | 模型选择的理由+推导的严谨性 |
| 6 | 模型求解 | 1-2页 | 算法步骤+参数选择+收敛 | 求解方法是否合适 |
| 7 | 结果分析 | 3-5页 | 结果→解释→对比→洞察 | 数据支撑+分析深度 |
| 8 | 模型评价 | 0.5-1页 | 优点+缺点+改进方向 | 诚实+反思 |
| 9 | 参考文献 | 0.5页 | GB/T 7714格式 | 引用是否规范 |

## 二、每章的信息任务定义

### §1 问题重述

```
✗ 错误：复制题目原文
✓ 正确：用自己的语言重新组织，完成三层转化

三层转化：
  现实背景（1段）：这个问题在实际中的意义
    ↓
  问题陈述（1段）：从题目中提取的核心问题，不是复制
    ↓
  本文工作（1段）：一句话预告全文的研究内容
```

### §2 问题分析

```
核心任务：把评委从"知道题目在问什么"带到"理解你为什么这样研究"

必需元素：
  □ 核心矛盾的识别（来自 Stage 26 contradiction_finder）
  □ 数学本质的抽象（"这个问题本质上是一个XXX问题"）
  □ 传统方法的局限（"为什么不能直接用XXX？"）
  □ 本文的研究策略（"因此，本文从XXX出发，采用XXX策略"）

加分元素：
  □ 数据分析的初步发现（如右删失率、非线性证据）
  □ 研究路线的预告图（技术路线图 F-001）
```

### §3 模型假设

```
每条假设的标准格式：
  H1: [假设内容]
  理由：[为什么可以这样假设？简化了什么？]
  验证：[如果可能，用数据验证假设的合理性]
  影响：[如果放松这个假设，模型会怎样变化？]

✗ 错误："H1: 假设市场完全竞争"（没有理由和验证）
✓ 正确："H1: 忽略二阶非线性项。理由：在正常工况范围内，
        非线性项的量级（<0.5%）远小于线性项。验证见图X。"
```

### §4 符号说明

```
三线表格式：
  符号 | 含义 | 单位 | 类型（决策变量/参数/常数）

规则：
  □ 按类型分组，决策变量在前，参数在后
  □ 同一物理量全文使用同一符号
  □ 下标规则统一（i=对象, j=指标, t=时间）
```

### §5 模型建立

```
信息任务链：
  为什么需要这个模型（1段，来自 Stage 26 why_this_model）
    ↓
  模型假设（引用§3）
    ↓
  数学表达（公式组，来自 Stage 27 决策+知识卡）
    ↓
  每个公式的解释（"该约束的含义是..."）
    ↓
  模型的整体特征（"综上，该模型的XXX特征使得它适合处理XXX"）

✗ 错误：直接堆公式，没有解释
✗ 错误：每个公式后复制一句"其中x表示..."（符号在§4已有）
✓ 正确：公式+一句话解释公式的物理/数学意义+公式间的逻辑关系
```

### §6 模型求解

```
信息任务链：
  求解方法选择理由（为什么用这个算法？来自 Stage 27 竞争引擎）
    ↓
  算法流程图（F-004）
    ↓
  关键参数及选择依据（"pop_size=80，因为XXX"）
    ↓
  收敛性验证（优化类必选：收敛曲线）
```

### §7 结果分析

```
每项结果的标准四段式（来自 Stage 26 paragraph_reasoning）：
  结果陈述（"图X显示..."）
    ↓
  结果解读（"这意味着..."）
    ↓
  原因分析（"出现这一结果的原因是..."）
    ↓
  对比/推广（"相比基线...""这一发现说明了..."）

✗ 错误："表X展示了各模型的结果"（只有陈述，没有分析）
✓ 正确："表X显示，RF的RMSE(1.85)显著低于OLS(5.23)。
        这是因为RF能捕捉非线性关系（图Y中的SHAP分析证实）。
        值得注意的是，RF在右删失区域的R²降至0.38——
        这并非模型的缺陷，而是数据特性（右删失）的必然结果。"
```

### §8 模型评价

```
必须包含三项：
  优点（3-5条，每条对应一个具体的表现）
  缺点（2-3条，诚实承认，每条对应一个条件限制）
  改进方向（2-3条，每条对应一个缺点的解决方案）

✗ 错误："模型精度高，方法先进，结果可靠"（空话）
✓ 正确："优点：(1)在右删失数据上通过Tobit机制保持了R²=0.71；
        (2)三层架构使得每层可独立验证...
        缺点：(1)代理模型假设各工况独立，忽略了工况间的过渡态；
        (2)优化结果对RF的超参数敏感..."
```

## 三、章节间的论证链接

每章的结尾必须为下一章提供动机：

```
§2 结尾 → §3 动机：
  "基于以上分析，为建立可解的数学模型，本文提出以下假设。"

§5 结尾 → §6 动机：
  "模型(5)是一个NLP问题，变量数=[X]，约束数=[Y]。
   标准梯度方法在最优点附近存在收敛困难（图X），
   因此§6采用差分进化算法求解。"

§7 结尾 → §8 动机：
  "虽然本文方法在 [方面A] 取得了 [效果]，
   但在 [方面B] 仍存在 [局限]。
   §8 对此进行系统评价。"
```

**检查方法**：如果删除某章的结尾段，下一章的开头是否显得突兀？如果是→缺链接段。

## 四、论文章节长度检查

| 信号 | 含义 | 处理 |
|------|------|------|
| §5 < 1页 | 模型建立太简略，可能缺推导 | 补充推导链+解释 |
| §7 < 2页 | 结果分析不足，可能缺深层解读 | 每个结果加四段式分析 |
| §7 > 6页 | 图表过多，信息密度低 | 精简图表，合并相似分析 |
| §1 = 原题复制 | 零分析价值 | 用自己的话重写三层转化 |
