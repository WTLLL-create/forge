# 论文生成流程

> 能力定义：AI 自动生成数学建模竞赛论文的完整工作流。
> 不是论文模板——而是从零到完整论文的逻辑生成链。
> 每一步定义明确的输入、AI 操作指令、输出格式和质量标准。

---

## 总流程

```
题目输入 ──→ [1. 问题分析] ──→ [2. 模型设计] ──→ [3. 数学推导]
                                                    ↓
                                              [4. 算法实现]
                                                    ↓
                                              [5. 实验结果]
                                                    ↓
[8. 质量检查] ←── [7. 论文组织] ←──────────── [6. 图表生成]
      ↓
  最终论文
```

---

## 步骤 1：问题分析

### 输入
- 竞赛题目全文
- 附件数据文件

### AI 操作指令

1. **提取题意**：用 200 字概括题目背景和核心问题
2. **提取子问题**：逐条列出题目要求求解的子问题（保留原文编号）
3. **提取约束**：逐条列出题目给出的约束条件，每条写出数学转化为
4. **提取数据描述**：列出附件中的数据字段名和含义
5. **调用题型识别**：使用 `数学建模题型识别.md` 判定类型

### 输出格式
```
【问题分析输出】
背景概括：[200字]
子问题列表：
  Q1: [一句话描述]（题型：XXX）
  Q2: [一句话描述]（题型：XXX）
  ...
约束清单：
  C1: [自然语言描述] → [数学约束形式]
  C2: ...
数据字段：
  field_1: [含义]（数值型/分类型）
  field_2: ...
```

---

## 步骤 2：模型设计

### 输入
- 步骤 1 的输出（问题分析）
- 数据分析结果（如有）

### AI 操作指令

1. **逐子问题选择模型**：使用 `模型选择决策树.md` 对每个 Q 做出选择
2. **确定模型间关系**：标注子问题之间的数据依赖
3. **选择对比模型**：为每个核心模型选 1 个基线做对比实验
4. **记录选择理由**：对每个模型写出 3 条选择理由（按决策树逻辑）

### 输出格式
```
【模型设计输出】
Q1 模型方案：
  主模型：[名称]
  选择理由：1. ... 2. ... 3. ...
  对比模型：[名称]
  数据流：输入 ← [来源]；输出 → [去向]
Q2 模型方案：
  ...
```

---

## 步骤 3：数学推导

### 输入
- 模型设计输出
- 题目约束

### AI 操作指令

1. **生成模型假设**：5-10 条，每条含假设内容 + 简化理由
2. **定义符号表**：全部变量统一命名（使用 LaTeX 符号）
3. **推导目标函数**：从题目优化目标出发，写出数学表达式
4. **列出约束条件**：将约束清单转为数学不等式/等式
5. **推导求解方法**：写出算法核心步骤的数学描述
6. **关联子问题**：标注哪些公式在后续子问题中复用

### 输出格式
```
【数学推导输出】
假设清单：
  H1: [假设内容]（理由：[简化了什么]）
  H2: ...

符号表：
  $\alpha$ — [含义]（类型：[连续/离散]，范围：[a,b]）
  ...

Q1 数学模型：
  决策变量：$x_i$ = [定义]
  目标函数：$\max \sum ...$ → [中文解释]
  约束条件：
    s.t. (1) $A x \leq b$ → [中文解释]
         (2) ...

Q2 数学模型（在 Q1 基础上的修改）：
  变化部分：[列出与 Q1 的差异]
```

---

## 步骤 4：算法实现

### 输入
- 数学推导输出
- 清洗后的数据（阶段 3 输出）

### AI 操作指令

1. **选择编程语言和关键库**：Python + NumPy/SciPy/scikit-learn/networkx
2. **设计代码结构**：
   - `data_loader.py` — 数据加载
   - `preprocess.py` — 数据清洗和预处理
   - `model_q1.py` / `model_q2.py` ... — 各子问题求解
   - `evaluate.py` — 模型验证
   - `visualize.py` — 图表生成
3. **实现算法**：按数学推导输出，逐函数实现
4. **设置参数**：每个参数注明来源（题给/文献/网格搜索/经验值）
5. **记录运行结果**：关键数值保存为结构化数据（JSON/CSV）

### 输出格式
```
【算法实现输出】
运行环境：Python 3.x + [库列表]
参数设定：
  参数名  |  值  |  来源  |  理由
  -------|------|--------|------
  param1 | 0.5  | 题给   | 题目指定权重
  param2 | 100  | 网格搜索 | 交叉验证最优

求解结果：
  Q1 结果：[关键数字列表]
  Q2 结果：[关键数字列表]
  ...
```

---

## 步骤 5：实验结果

### 输入
- 算法实现输出（运行结果数据）
- 对比实验的基线模型结果

### AI 操作指令

1. **计算评价指标**：按预测/分类/优化/评价分别计算对应指标
2. **生成对比报告**：你的模型 vs 基线模型，用表格对比
3. **生成敏感性分析**：关键参数 ±10%，观察输出变化
4. **生成模型评价**：优点（3-5 条）+ 缺点（2-3 条）+ 改进方向（2-3 条）

### 输出格式
```
【实验结果输出】
准确性指标：
  指标   |  你的模型  |  基线模型  |  提升%
  -----|----------|----------|------
  MAE  | 0.23     | 0.45     | 48.9%
  RMSE | 0.31     | 0.58     | 46.6%

敏感性分析：
  参数    |  变化范围  |  输出变化  |  结论
  -------|----------|----------|------
  alpha  | 0.45-0.55| ±8%     | 稳健
  beta   | 0.18-0.22| ±35%    | 敏感（论文中需说明）

模型评价：
  优点：1. ... 2. ... 3. ...
  缺点：1. ... 2. ...
  改进方向：1. ... 2. ...
```

## 步骤 6：图表生成

### 输入
- 实验结果输出
- 中间数据

### AI 操作指令

对每个图表：

1. **确定图表类型**：折线图（时间序列）、散点图（相关性/聚类）、柱状图（对比）、热力图（相关性矩阵）、箱线图（分布对比）、流程图（算法结构）
2. **生成图表**：使用 matplotlib/seaborn/plotly
3. **设置图表格式**：
   - 中文字体（SimHei/黑体）
   - 分辨率 ≥ 300 dpi
   - 图例位置不遮挡数据
4. **编号和命名**：图 1-1、图 2-1... 格式统一

### 输出
```
【必须生成的图表清单】
□ 数据探索类：
  - 关键变量分布直方图（1-2 张）
  - 相关性热力图（1 张）
  - 有无异常值的箱线图（1 张）

□ 模型过程类：
  - 算法流程图（1 张）
  - 收敛曲线（优化类必选）
  - Pareto 前沿（多目标必选）

□ 结果展示类：
  - 预测值 vs 真实值对比图（预测类）
  - 排序得分柱状图（评价类）
  - 最优方案示意图（优化类）
  - 混淆矩阵热力图（分类类）

□ 对比分析类：
  - 你的模型 vs 基线模型指标对比图
  - 敏感性分析结果图
```

## 步骤 7：论文组织

### 输入
- 所有前序步骤的输出
- LaTeX/Word 论文模板

### AI 操作指令

按以下顺序逐模块生成论文内容：

**模块 A — 摘要（最后生成，但放论文最前面）**
- 从步骤 1-6 的输出中提取关键信息
- 按模板：[问题定位] + [Q1 方法+结果] + [Q2 方法+结果] + ... + [创新点]
- 每个子问题必须含具体数值

**模块 B — 问题重述**
- 使用步骤 1 的"背景概括"，扩展为 2-3 页
- 分成：1.1 问题背景、1.2 问题描述、1.3 本文需解决的问题

**模块 C — 模型假设与符号说明**
- 直接使用步骤 3 的"假设清单"和"符号表"
- 符号表用三线表格式

**模块 D — Q1 建模与求解**
- 问题分析（200 字）+ 模型建立（公式组）+ 算法设计（流程图 + 步骤描述）+ 结果分析（表格 + 图表 + 文字解读）

**模块 E-H — Q2/Q3/Q4**
- 同模块 D 格式
- Q2/Q3/Q4 的开头要注明"在问题一的基础上"或与前一问题的差异

**模块 I — 模型评价**
- 直接使用步骤 5 的"模型评价"

**模块 J — 参考文献**
- 10-15 篇，使用 GB/T 7714 格式
- 每篇文献在正文中必须被引用

**模块 K — 附录**
- 核心代码片段（代码太多则附 GitHub 链接）
- 中间数据表（大数据放云盘）

### 输出
- 完整的 .docx 或 .tex 文件

## 步骤 8：质量检查

### 输入
- 完整论文
- 全文源数据

### 检查维度

**维度 A — 数值一致性**
- [ ] 摘要中的数字 = 正文中的数字 = 图表中的数字
- [ ] 所有公式的计算结果可复现（用代码重算一遍）

**维度 B — 逻辑完整性**
- [ ] 每个子问题都有对应的模型、求解、结果、分析
- [ ] 子问题间的依赖关系在论文中明确标注
- [ ] 所有假设都有在正文中被引用

**维度 C — 图表质量**
- [ ] 每张图有编号、标题、坐标轴标签
- [ ] 每张表有编号、标题
- [ ] 图表在正文中被引用（"如图 X 所示"、"如表 Y 所示"）
- [ ] 图片清晰度 ≥ 300 dpi

**维度 D — 格式规范**
- [ ] 使用官方模板的页边距、字体、字号、行距
- [ ] 公式居中，编号右对齐
- [ ] 参考文献格式统一（GB/T 7714）
- [ ] 无错别字

**维度 E — 创新性**
- [ ] 摘要中列出了模型创新点
- [ ] 正文中有"针对本题特点做了 XXX 改进"的描述

## 论文模块与前置步骤映射表

| 论文模块 | 数据来源 | 生成方式 |
|----------|----------|----------|
| 摘要 | 步骤 1-6 所有输出 | 提取 + 压缩 + 数值填充 |
| 问题重述 | 步骤 1 输出 | 扩展 200 字→2-3 页 |
| 模型假设与符号 | 步骤 3 输出 | 直接移植 |
| Q1 建模与求解 | 步骤 3+4+5+6 输出 | 组装（公式+算法+结果+图） |
| Q2-Q4 | 同上 | 同上 + 标注与前一问题的差异 |
| 模型评价 | 步骤 5 输出 | 直接移植 |
| 参考文献 | 步骤 4 中的引用 | 格式化为 GB/T 7714 |
| 附录 | 步骤 4 代码 | 精选关键代码片段 |

---

## AI 生成论文的质量底线

以下情况下论文不应被输出：
- [ ] 任何一个子问题的结果只有图表没有数值（必须有数字）
- [ ] 摘要中缺少任何一个子问题的结果
- [ ] 模型选择没有写理由（只写了"用了 XXX 模型"）
- [ ] 对比实验缺失（没有和任何基线方案对比）
- [ ] 图表没有任何一张（至少要有数据探索图 + 模型结果图 + 对比图）
- [ ] 模型优缺点部分为空或全是空话
