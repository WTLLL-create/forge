# 数据分析流程

> 数学建模竞赛中的标准数据分析工作流。7 个部分覆盖从原始数据到模型输入的完整链路。
> 每个部分定义：输入、分析操作、输出、与模型的连接点。

---

## 第一部分：数据理解

### 操作步骤

```
原始数据
  ↓
1.1 识别数据来源 → 题目附件 / 公开数据集 / 爬取数据
1.2 确认数据规模 → 行数 × 列数，估算内存占用
1.3 分类数据类型 → 数值型 / 分类型 / 时间型 / 文本型
1.4 解读字段含义 → 每个字段写一句话说明
```

### 决策规则

| 数据类型 | 可做的分析 | 不可做的分析 |
|----------|-----------|-------------|
| 连续数值 | 均值/方差/分布/相关/回归 | 计数/比例（除非离散化） |
| 离散分类 | 频数/比例/卡方检验/编码 | 均值（无意义） |
| 时间戳 | 趋势/周期/间隔/滑动窗口 | 直接做回归（需先特征化） |
| 经纬度 | 空间分布/距离/聚类 | 直接做均值 |

### 输出

```
【数据说明文档】
文件1：[文件名]
  - 行数：[N]，列数：[M]
  - 字段清单：field_1([类型], [含义]), field_2(...), ...
  - 时间范围：[start] 至 [end]（如有）
  - 数据来源：[题给附件X]

文件2：...
```

## 第二部分：数据质量检查

### 缺失值

```
Step 1：计算每列缺失比例
Step 2：按比例分段决策

  缺失比例     →  处理方案
  ─────────────────────────
  0%           → 无处理
  <5%          → 中位数（数值）/ 众数（分类）填充
  5%-20%       → KNN 插值 / 拉格朗日插值
  20%-50%      → 多重插补（MICE），并标注"该列数据质量较低"
  >50%         → 删除该列，论文中说明原因

Step 3：对填充后的数据做分布对比（填充前后均值/方差变化 <5%）
```

### 异常值

```
Step 1：箱线图识别
  判据：x < (Q1 - 1.5*IQR) 或 x > (Q3 + 1.5*IQR)

Step 2：区分异常类型
  ├─ 输入错误（如年龄=200）→ 视为缺失值，按上述规则填充
  └─ 真实离群（如极端天气）→ 保留，论文中标注并分析

Step 3：业务合理性判断
  对照题目约束——如"分数范围0-100"，超出范围=输入错误
```

### 重复数据

```
检查：完全相同行的数量
处理：删除（保留首次出现）
记录：论文中写"删除 N 条重复记录"
```

### 输出

```
【数据质量报告】

文件1：
  ├─ 缺失值：field_A (X%/Y条), field_B (X%/Y条) → 已用[方法]填充
  ├─ 异常值：field_C (Z条), 其中输入错误 A 条（已修正），真实离群 B 条（保留）
  └─ 重复行：K 条（已删除）

文件2：...
```

## 第三部分：探索性数据分析 EDA

### 3.1 单变量分析

| 变量类型 | 分析内容 | 可视化 | 论文用途 |
|----------|----------|--------|----------|
| 连续数值 | 均值/标准差/min/max/四分位数/偏度/峰度 | 直方图+核密度 | 展示数据分布特征 |
| 离散分类 | 各类频数/占比 | 柱状图 | 展示类别分布 |
| 时间序列 | 趋势/季节性/周期性 | 折线图 | 展示时间演变规律 |

### 3.2 双变量分析

| 分析类型 | 适用变量组合 | 方法 | 可视化 |
|----------|-------------|------|--------|
| 相关性 | 数值 vs 数值 | Spearman / Pearson 相关系数 | 热力图 |
| 趋势 | 时间 vs 数值 | 滑动平均 / 线性趋势检验 | 折线图+趋势线 |
| 分组对比 | 分类 vs 数值 | 分组均值 + 方差分析 | 箱线图/小提琴图 |

### 3.3 多变量分析

| 分析类型 | 目的 | 方法 | 输出 |
|----------|------|------|------|
| 特征关系 | 发现变量间结构 | 散点图矩阵 / 平行坐标 | 特征交互模式 |
| 聚类结构 | 发现数据自然分组 | PCA → K-means / GMM → t-SNE 可视化 | 聚类标签+分布图 |
| 降维投影 | 高维数据可视化 | PCA（保留85%方差）/ t-SNE | 2D/3D 投影图 |

### 输出

```
【EDA 报告】

关键发现 1：[一句话发现] → 证据：[图表+统计量]
关键发现 2：[一句话发现] → 证据：[图表+统计量]
关键发现 3：[一句话发现] → 证据：[图表+统计量]

这些发现将用于：
  - [发现1] → 支持模型假设 [假设X]
  - [发现2] → 指导特征选择（[feature_A] 与目标高度相关）
  - [发现3] → 说明模型选择的必要性（非线性关系→放弃线性模型）
```

## 第四部分：特征工程

### 决策树：何时使用哪种操作

```
数据是表格型吗？
│
├─ 是 → 有缺失值？
│   ├─ 是 → 第二部分已处理
│   └─ 否 → 继续
│
├─ 特征中有不同量纲？（如年龄20-80 + 收入5000-50000）
│   └─ 是 → 标准化（z-score / min-max）
│         规则：距离型模型（SVM/KNN/PCA）→ 必须标准化
│               树模型（RF/XGBoost）→ 不需要
│
├─ 特征数量 > 样本量的 1/3？
│   └─ 是 → 降维
│         PCA：保留 85% 方差，用于去相关
│         特征选择：基于相关性/重要性，移除冗余
│
├─ 需要创建新特征？
│   ├─ 时间数据 → 提取：年/月/日/星期/小时/是否周末/是否节假日
│   ├─ 比率特征 → A/B, A/(A+B)
│   ├─ 滑动统计 → 前N天均值/方差（时序场景）
│   └─ 交互特征 → A×B（领域知识驱动）
│
└─ 类别变量？
    └─ 类别数 < 10 → One-Hot 编码
       类别数 > 10 → Label 编码 / 目标编码（Target Encoding）
```

### 标准化选择

| 方法 | 公式 | 使用场景 |
|------|------|----------|
| Z-score | (x-μ)/σ | 数据近似正态，后续用 PCA/SVM/KNN |
| Min-Max | (x-min)/(max-min) | 需要 [0,1] 范围，后续用神经网络 |
| Robust | (x-median)/IQR | 有异常值时（不被极端值影响） |

### 输出

```
【特征工程报告】

原始特征数：[K]
处理后特征数：[K']（新增 M 个，删除 N 个）

新增特征：
  feature_new_1 = [公式] → 目的：[一句话]
  feature_new_2 = [公式] → 目的：[一句话]

删除特征：
  feature_old_1 → 原因：[与目标相关性<0.1 / 缺失>50% / VIF>10]

标准化方式：[z-score / min-max / 无]
降维方式：[PCA(85%) / 无]
```

## 第五部分：不同题型的数据分析策略

### 预测类

```
核心问题：什么因素驱动了目标变量的变化？

必做分析：
  □ 时间趋势图（如果有时间维度）→ 判断平稳性
  □ 自相关图 ACF/PACF → 判断滞后阶数
  □ 特征-目标相关性排序 → 筛选重要特征
  □ 季节性分解（如果有周期）
  □ 训练/验证集时间切分（不可随机抽样！）

额外建议：
  □ 如果一次预报数据和实测数据同时存在 → 做残差分析
    残差 = 实测 - 一次预报，如果残差有模式 → 可建模
```

### 优化类

```
核心问题：约束条件在数据上是否可行？

必做分析：
  □ 决策变量的取值范围统计 → 确认上下界
  □ 约束条件的可行性检查 → 是否存在不可行解？
  □ 目标函数各子项的相关性 → 多目标是否冲突？
  □ 参数灵敏度预分析 → 哪些参数可能影响最大？

额外建议：
  □ 画"参数空间采样图"→ 确认搜索空间大小
```

### 评价类

```
核心问题：指标之间的关系是什么？

必做分析：
  □ 指标间相关性矩阵 → 是否有高度相关的冗余指标？
  □ 指标的方向性标注 → 正向（越大越好）vs 负向（越小越好）
  □ 指标的量纲差异 → 决定无量纲化方式
  □ 评价对象的分布 → 是否存在"一家独大"或"都差不多"？

额外建议：
  □ 画指标热力图 → 一眼看出哪个对象在哪项指标上有优势
```

### 分类类

```
核心问题：特征能否区分不同类别？

必做分析：
  □ 各类别的样本数量分布 → 是否不平衡？
  □ 每类在各特征上的分布对比 → 哪���特征区分度高？
  □ 特征间的多重共线性 → VIF > 10 删
  □ 样本-特征比 → 高维小样本需降维

额外建议：
  □ 如果不平衡比例 > 3:1 → 标注"需使用 SMOTE 或代价敏感学习"
```

## 第六部分：数据分析与模型连接

### 连接规则

| 数据分析发现 | 对模型选择的影响 | 对论文的影响 |
|-------------|-----------------|-------------|
| 特征与目标高度线性相关 | 首选线性模型，不需要上 XGBoost | 在模型选择理由中引用此发现 |
| 特征间存在强相关（>0.8） | 需要 PCA 降维，或删除冗余特征 | 在特征工程部分说明 |
| 数据有显著季节性 | 必须用时序模型（SARIMA 而非 ARIMA） | 在问题分析中标注 |
| 缺失>50%的列已删除 | N/A | 在模型假设中注明"假设剩余字段足够" |
| 评委评分存在均值偏移 | 模型必须是"先校准再排名" | 核心论点！贯穿全篇 |
| 样本极度不平衡（1:10） | 必须用 SMOTE 或 Focal Loss | 在结果分析中强调 F1 而非 Accuracy |

### 关键原则

> **数据分析不是独立环节，而是模型选择的决策输入。**
> 每一个数据发现，都应该能在论文中找到它的"归宿"——要么影响了模型选择，要么解释了模型行为。

## 第七部分：检查清单

```
数据分析完成前自检：

□ 数据理解
  □ 每个文件的字段含义都清楚了？
  □ 数据类型（数值/分类/时间）都确认了？

□ 数据质量
  □ 缺失值已处理（删/填）并记录了方法？
  □ 异常值已区分（输入错误 vs 真实离群）？
  □ 重复行已删除？

□ EDA
  □ 至少 1 张分布图（直方图/箱线图）？
  □ 至少 1 张相关性热力图？
  □ 至少 1 个"关键发现"被记录？

□ 特征工程
  □ 量纲不统一的特征已标准化（如果模型需要）？
  □ 高维数据已考虑降维？
  □ 创建了有物理意义的新特征？

□ 模型连接
  □ 每个关键发现都能说清楚"怎么影响模型选择"？
  □ 数据特征与模型假设一致（如正态性）？

□ 论文准备
  □ 至少有 3 张 EDA 图可用于论文？
  □ 数据清洗过程有记录（可写入论文的数据预处理部分）？
  □ 特征工程有记录（可写入论文的模型建立部分）？
```
