# 数学建模题型识别

> 能力定义：给定一道数学建模竞赛题目，AI 能在 5 分钟内完成题型判定并锁定建模方向。
> 本文件是建模能力链的第一环，输出结果直接驱动「模型选择决策树」。

---

## 识别流��

```
读题
  ↓
提取关键词 + 判断题目核心诉求
  ↓
匹配下方 6 大题型特征
  ↓
确定主类型（可能有 1-2 个子类型交叉）
  ↓
输出：类型标签 + 推荐建模方向 + 建模注意事项
```

## 题型 1：预测类问题

### 典型特征

| 维度 | 判定标准 |
|------|----------|
| 核心诉求 | 根据已知数据推断未知状态 |
| 数据特征 | 有时间维度（历史→未来）或空间维度（已知点→未知点） |
| 输出形式 | 未来某时刻的数值、趋势曲线、概率分布 |

### 关键词

`预测` `趋势` `未来` `变化规律` `时序` `估计` `预报` `外推`

### 子类型与模型匹配

| 子类型 | 何时使用 | 首选模型 | 备选模型 |
|--------|----------|----------|----------|
| **少量时序数据**（<30 点） | 数据稀缺，无法训练复杂模型 | GM(1,1) 灰色预测 | 指数平滑 |
| **中等时序数据**（30-200 点） | 有明显季节性或趋势 | ARIMA / SARIMA | Prophet、Holt-Winters |
| **大量多维数据**（>1000 条） | 特征丰富、非线性关系强 | XGBoost / 随机森林 / LSTM | GBDT、SVR |
| **有物理机理背景** | 存在已知的动力学/物理方程 | 先机理模型，残差用数据模型校正 | 多变量线性回归 |
| **空间插值预测** | 已知采样点，推断未采样点 | Kriging 插值 | 反距离加权、样条插值 |

### 建模注意事项
- 必须先做平稳性检验（ADF），不平稳则差分直到平稳
- 必须划分训练集/验证集（时序问题用时间切分，不可随机抽样）
- 必须对比至少一种基线模型（如简单移动平均），证明你的模型有提升
- 论文中要给出误差指标：MAE、RMSE、MAPE（至少两个）
- 避免"过拟合历史数据但对未来预测失效"：验证集结果才是论文的核心数字

## 题型 2：评价类问题

### 典型特征

| 维度 | 判定标准 |
|------|----------|
| 核心诉求 | 对多个对象进行排序、打分、分级 |
| 数据特征 | 多维指标，指标间量纲和重要性不同 |
| 输出形式 | 排名表、综合得分、等级标签 |

### 关键词

`评价` `排序` `指标` `权重` `优劣` `综合` `评分` `等级` `分级`

### 子类型与模型匹配

| 子类型 | 何时使用 | 首选模型 | 备选模型 |
|--------|----------|----------|----------|
| **指标少且有专家经验** | 可以请专家两两比较重要性 | AHP 层次分析法 | — |
| **有客观数据但不知权重** | 指标值可计算，需要客观权重 | 熵权法 + TOPSIS | CRITIC 法 |
| **指标含模糊/定性描述** | 存在"较好""一般"等模糊评价 | 模糊综合评价 | 灰色关联分析 |
| **多对象多指标综合比较** | 排名类竞赛题 | 熵权-TOPSIS 组合 | 秩和比法(RSR) |
| **需要动态权重** | 指标重要性随时间/场景变化 | 变权综合评价 | — |

### 模型选择依据

| 模型 | 优势 | 局限 | 使用前提 |
|------|------|------|----------|
| AHP | 有理论支撑，结果稳健 | 主观性强，一致性检验可能不通过 | 专家判断矩阵能通过 CR<0.1 |
| 熵权法 | 完全客观，不受人为主观影响 | 权重可能不符合实际重要性 | 指标变异程度能反映信息量 |
| TOPSIS | 几何直观，计算简单 | 不处理指标相关性 | 需要先确定权重（配合熵权/AHP） |
| 模糊综合评价 | 处理定性指标 | 隶属函数选择主观 | 存在模糊性评价 |
| 灰色关联 | 数据少时也能用 | 只考虑序列曲线相似性 | 样本量小且指标关系不明 |

### 建模注意事项
- **指标体系是灵魂**：先建立层级指标树（目标层→准则层→指标层），每个指标必须有定义和计算公式
- **权重必须讲理**：不能直接给"权重=0.3"，必须写清楚是通过 AHP 判断矩阵还是熵权法计算得出
- **正负向指标要区分**：正向（越大越好）和负向（越小越好）在 TOPSIS 中处理方式不同
- **无量纲化不能漏**：不同量纲的指标必须先归一化（min-max 或 z-score）
- 论文中必须给出权重表 + 得分排序表 + 至少一个敏感性分析（微调权重看排名是否稳定）

## 题型 3：优化类问题

### 典型特征

| 维度 | 判定标准 |
|------|----------|
| 核心诉求 | 在约束条件下找到最优方案 |
| 数据特征 | 有明确的决策变量、目标函数、约束条件 |
| 输出形式 | 最优解的值 + 对应的决策变量取值 |

### 关键词

`优化` `最大` `最小` `最优` `调度` `路径` `成本` `效率` `分配` `排班` `选址` `装箱` `规划`

### 第一步：判定问题复杂度

```
决策变量是连续的还是离散的？
│
├─ 连续 → 能否写成线性形式？
│   ├─ 是 → 线性规划（LP）
│   └─ 否 → 非线性规划（NLP）
│
└─ 离散 → 变量取值范围多大？
    ├─ 小（可枚举） → 整数规划（IP）/ 0-1 规划 / 动态规划
    └─ 大（不可枚举） → 问题是否 NP-hard？
        ├─ 无法证明 → 先用启发式求上界，再判断
        └─ 已知 NP-hard → 元启发式算法
```

### 模型选择矩阵

| 问题规模 | 变量性质 | 推荐算法 | 典型场景 |
|----------|----------|----------|----------|
| 小规模 | 线性连续 | 单纯形法 | 资源分配、配料 |
| 小规模 | 线性离散 | 分支定界 | 选址、指派 |
| 小规模 | 非线性 | 拉格朗日乘子法 / KKT | 参数优化 |
| 中等规模 | 离散组合 | 动态规划 | 背包问题、阶段决策 |
| 大规模 | 离散/NP-hard | 遗传算法 / 蚁群 / 粒子群 | 调度、路径规划 |
| 大规模 | 多目标 | NSGA-II / 加权转为单目标 | 多目标调度 |
| 任意规模 | 可转为图 | Dijkstra / Floyd / A* | 最短路径、网络流 |

### 模型优缺点速查

| 算法 | 优势 | 劣势 |
|------|------|------|
| 线性规划 | 有全局最优解保证 | 只能处理线性关系 |
| 整数规划 | 精确解 | 规模稍大即不可解 |
| 动态规划 | 最优子结构时极高效 | 要求问题可递推分解 |
| 遗传算法 | 适用面广，不易陷入局部最优 | 不能保证最优，调参困难 |
| 模拟退火 | 理论上有全局收敛性 | 收敛慢，参数敏感 |
| 蚁群算法 | 适合路径类问题 | 收敛速度不稳定 |
| 粒子群 | 参数少，收敛快 | 容易早熟 |

### 建模注意事项
- **必须先分析问题复杂度**：如果能用精确算法，就不要上元启发式。审稿人会问"为什么不用线性规划？"
- **必须有初始解和对照实验**：初始化策略的对比是加分项（如"随机初始化 vs 启发式种子"）
- **遗传算法三段式**：编码方式定义 + 交叉/变异策略设计 + 适应度函数设计，缺一不可
- **多目标处理的两种方式**：(a) 加权单目标（需给权重理由）；(b) Pareto 前沿（需画前沿图）
- 论文中画算法流程图 + 收敛曲线 + 结果对比表

## 题型 4：分类与判别问题

### 典型特征

| 维度 | 判定标准 |
|------|----------|
| 核心诉求 | 判断样本属于哪个类别 |
| 数据特征 | 有标签训练数据，需要对新样本归类 |
| 输出形式 | 类别标签或类别概率 |

### 关键词

`分类` `识别` `判别` `诊断` `检测` `鉴定` `归属`

### 子类型与模型匹配

| 子类型 | 何时使用 | 首选模型 |
|--------|----------|----------|
| 线性可分 | 特征空间可分，需要解释原因 | LDA 线性判别 / Logistic 回归 |
| 非线性可分 | 决策边界复杂 | SVM（RBF 核）/ 随机森林 |
| 小样本高维 | 样本数 << 特征数 | SVM + PCA 降维 |
| 多类别 | >2 个类别 | 随机森林 / XGBoost / softmax |
| 需要概率输出 | 不是简单0/1，要置信度 | Logistic 回归 / 朴素贝叶斯 |
| 不平衡数据 | 某些类别样本极少 | SMOTE 过采样 + 代价敏感学习 |

### 建模注意事项
- 必须划分训练集/测试集，并报告混淆矩阵
- 评价指标不能用单一的 accuracy（在不平衡数据下无意义），至少要有 Precision/Recall/F1
- 论文中写清楚分类边界是如何确定的

## 题型 5：机理分析问题

### 典型特征

| 维度 | 判定标准 |
|------|----------|
| 核心诉求 | 建立物理/化学/生物过程的数学模型 |
| 数据特征 | 题目给出物理定律或已知方程，需要联立推导 |
| 输出形式 | 微分方程/方程组、传递函数、状态方程 |

### 关键词

`机理` `物理模型` `动力学` `方程` `定律` `过程` `传递` `扩散` `反应` `电路`

### 建模路线

```
题目中有明确的物理/化学定律？
│
├─ 是 → 联立方程 → 方程简化（忽略次要项）→ 求解
│   ├─ 可解析解 → 直接推导解析表达式
│   └─ 无解析解 → 离散化数值求解（差分法/有限元/Runge-Kutta）
│
└─ 否 → 先查文献找领域公认方程 → 补充参数 → 数值求解
```

### 常用工具
- 常微分方程：Runge-Kutta 法（ode45）
- 偏微分方程：有限差分法、有限元法
- 传递函数/控制系统：拉普拉斯变换、状态空间模型

### 建模注意事项
- **方程来源必须标注**：是题给、是常识（如F=ma）、还是文献引用
- **简化必须有理由**：不能直接丢掉一项，要说明"在 XX 条件下此项可忽略"
- **数值求解必须验证**：改变步长看结果是否收敛，确认数值稳定性
- 论文中写清楚方程的物理含义（不只看数学形式）

## 题型 6：综合型问题

### 典型特征

一个题目包含多个不同类型子问题，常见组合：
- 预测 + 评价（先预测未来，再评价方案）
- 优化 + 评价（先求最优方案，再评估效果）
- 机理 + 数据（先用机理建骨架，再用数据校参数）
- 分类 + 预测（先分类识别场景，再分场景预测）

### 处理策略

```
1. 用本文档对每个子问题独立判定类型
2. 识别子问题间的依赖关系（哪个在先、哪个在后）
3. 先解决数据预处理类的子问题（如问题一通常是 AQI 计算/数据处理）
4. 再解决核心建模子问题
5. 子问题之间的约束条件和假设要一致
```

### 注意事项
- 论文中要明确标注"问题一的结果作为问题二的输入"
- 不要为每个子问题建立完全独立的模型体系（显得割裂）
- 尽量让后面的子问题在前面的模型基础上"增量修改"

每次完成题型识别后，AI 应输出以下结构化结果：

```
【题型识别结果】
主类型：XXX
子类型：XXX（如果有）
交叉类型：XXX（如果有）
解法层级：经典方法 / 现代算法（参考 zhanwen/MathModel 的分类体系）

【判断依据】
- 核心关键词：XXX, XXX, XXX
- 决策特征1：XXX
- 决策特征2：XXX

【推荐建模方向】
首选方案：XXX
备选方案：XXX（Failover 降级方案，见 模型选择决策树.md 的 Failover 机制）
关键决策点：XXX

【风险提示】
- 容易犯的错误：XXX
- 数据方面的陷阱：XXX
- 需要特别注意的约束：XXX
```
