# 权衡分析器（Tradeoff Analyzer）

> 矛盾发现之后的第一步深化：将定性矛盾转化为定量权衡分析。
>
> 本文件回答：识别出矛盾后，如何用数学语言精确刻画这个权衡？

---

## 一、从定性到定量的转化

`contradiction_finder.md` 输出的矛盾声明是**定性**的。要让它成为论文的核心论点，必须转化为**定量**的权衡分析。

```
定性矛盾                       定量权衡
────────                       ────────
"精度和效率不可兼得"      →   精度每提升1%，计算时间增加约40%
"排放和成本相互制约"      →   排放降低到X以下时，成本呈指数增长
"小样本导致过拟合"        →   样本量100时R²=0.95(训练) vs R²=0.35(测试)
```

## 二、三种权衡分析框架

### 2.1 Pareto 权衡分析（目标冲突型矛盾）

**适用场景**：两个或多个目标之间存在不可兼得的关系

**操作步骤**：

```
Step 1: 定义目标函数
  f₁(x) = [目标1的数学表达式]
  f₂(x) = [目标2的数学表达式]
  （如果是冲突的，通常 f₁↑ → f₂↓）

Step 2: 求解 Pareto 前沿
  min [f₁(x), f₂(x)]
  s.t. [约束条件]
  → 得到一组 Pareto 最优解

Step 3: 量化权衡强度
  在 Pareto 前沿上选取两个点 A 和 B：
  从 A 到 B：f₂ 改善 Δf₂，代价是 f₁ 恶化 Δf₁
  权衡比 = |Δf₁ / Δf₂|
  
Step 4: 识别"膝盖点"（Knee Point）
  Pareto 前沿上边际权衡变化最大的点
  → 这是"投入产出比最优"的区域
```

**论文表达模板**：

```
图 X 展示了 f₁ 和 f₂ 的 Pareto 前沿。
前沿的形状揭示了一个重要特征：
在 [区域A]，f₂ 的小幅改善只需 f₁ 的微小牺牲（权衡比 ≈ X）。
但在 [区域B]，f₂ 的进一步改善需要 f₁ 的极大幅度牺牲（权衡比 ≈ Y）。
这意味着 [实际意义]。
本文选择 [膝盖点附近] 作为推荐方案，此时 [具体数值]。
```

### 2.2 约束松弛分析（方法局限型矛盾）

**适用场景**：标准方法的假设与问题特征冲突

**操作步骤**：

```
Step 1: 列出标准方法的假设
  假设1: [线性/正态/独立/平稳/...]
  假设2: [...]

Step 2: 检验每条假设在本题数据上是否成立
  检验方法: [统计检验/可视化/理论分析]
  结果: 假设X不成立 (p<0.05 / 理论矛盾)

Step 3: 量化假设违反的严重程度
  违反程度 = [定量度量]
  例如："ADF检验 p=0.34 → 时序非平稳，ARIMA的基础假设不成立"

Step 4: 估计假设违反的后果
  如果强行使用标准方法 → [预测的偏误方向和量级]
  例如："使用ARIMA对非平稳时序建模，预测区间将随时间发散"
```

**论文表达模板**：

```
标准模型 A 的建立基于 [假设1, 假设2, ...]。
然而，本题的数据特征与这些假设存在显著冲突：
[假设X违反的定量证据]。

如果强行使用模型 A，将导致 [具体的失效模式]。
为解决这一矛盾，本文 [松弛/替换/补充] 了假设 X，
具体做法是 [改进方法]。
```

### 2.3 敏感度预判（数据困境型矛盾）

**适用场景**：数据质量限制了可用的模型复杂度和可达到的精度

**操作步骤**：

```
Step 1: 量化数据限制
  样本量: N
  特征数: p
  缺失率: r
  噪声水平: σ²

Step 2: 估算模型复杂度的上限
  经验规则: 需要估计的参数数 ≤ N/10（防止过拟合）
  线性模型参数数: p+1
  RF参数数: ~N_trees × max_depth
  NN参数数: 层间连接数之和

Step 3: 对比候选模型的复杂度 vs 数据支撑能力
  模型A: [参数数] ≤ N/10？→ ✅ / ❌
  模型B: [参数数] ≤ N/10？→ ✅ / ❌

Step 4: 预测"复杂度-精度"的权衡曲线
  过于简单的模型 → 高偏差（欠拟合）
  过于复杂的模型 → 高方差（过拟合）
  最优复杂度 ≈ [基于N/p/σ²的估计]
```

**论文表达模板**：

```
本题的数据规模（N=[X]）对模型复杂度构成了天然约束。
维度分析表明：
- 线性模型参数数 = p+1 = [X]，远低于 N/10 = [Y]，存在欠拟合风险
- 深度学习模型参数数可达 [X]，远超 N/10 = [Y]，存在严重过拟合风险

基于此分析，本文选择 [中等复杂度模型]，
并通过 [正则化/交叉验证/早停] 进一步控制过拟合。
```

## 三、权衡分析的论文价值

| 权衡分析层次 | 论文得分影响 | 对应评分维度 |
|-------------|:---:|------|
| 无权衡分析，直接选模型 | 基准分 | — |
| 定性描述权衡 | +1-2 分 | 问题分析 |
| 定量刻画权衡（有数值） | +2-3 分 | 问题分析 + 模型合理性 |
| Pareto前沿 + 膝盖点分析 | +3-5 分 | 问题分析 + 模型合理性 + 创新性 |
| 权衡分析→驱动模型改进设计 | +5-7 分 | 全部维度 |

## 四、与 paradox_resolution 的衔接

```
tradeoff_analyzer（本文件）
    ↓ 输出：权衡的定量描述 + 论文表达
paradox_resolution（下一步）
    ↓ 输出：如何在数学上解决这个权衡？
    ↓       - 分层策略：不同层用不同方法
    ↓       - 松弛策略：硬约束→软约束
    ↓       - 混合策略：多方法互补
```
