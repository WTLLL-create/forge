# 与已有方法的差异化（Contribution vs. Related Work）

> 创新不是自说自话。必须有"已有工作是什么→不足是什么→本文做了什么"的完整链条。
>
> 本文件建立标准的差异化论证框架。

---

## 一、核心论证结构

```
已有工作 A：
  做了什么 → [简述]
  不足 → [具体缺陷，有证据]
  ↓
已有工作 B：
  做了什么 → [简述]
  不足 → [具体缺陷，有证据]
  ↓
Gap（空白）：
  已有工作共同缺失 → [A和B都没解决的问题]
  ↓
本文贡献：
  针对Gap做了什么 → [本文方法的简要描述]
  为什么能填补Gap → [机制解释]
```

**关键原则**：对已有工作的批评必须是具体的和可验证的。不能说"A不够好"，而要说"A在X条件下Y指标退化Z%"。

---

## 二、四种差异化策略

### 策略 1：精度/性能差异化（最常用）

**适用**：本文方法在关键指标上优于已有方法

**论证模板**：

```
已有方法在 [数据集/场景] 上的表现为 [指标]=[值]（来源：[引用]）。
但该方法在 [特定条件] 下存在 [退化现象]（证据：[定量]）。

本文方法针对 [退化原因] 做了 [改进]，
在相同条件下 [指标] 达到 [值]，
相比已有方法提升 [X%]。
```

**注意事项**：
- 必须用相同的评价标准对比（不能A用RMSE，B用MAE，然后说B更好）
- 必须说明数据/实验条件是否一致（不一致则对比不公平）
- 不能选择性报告有利的结果

### 策略 2：能力/功能差异化

**适用**：本文方法能做到已有方法做不到的事

**论证模板**：

```
已有方法能够 [能力A]，但无法 [能力B]。
这是因为 [技术原因]。

本文方法通过 [机制] 获得了 [能力B]。
其关键创新在于 [创新描述]。
这使得本文方法能够处理 [已有方法处理不了的场景]。
```

**示例**：

```
标准随机森林能够进行准确的插值预测，
但无法进行外推——预测值永远不会超出训练数据的范围。
这是因为树模型基于训练数据的特征空间划分。

本文通过在损失函数中加入物理约束惩罚项，
使模型在训练范围外的行为受物理定律的引导，
从而获得了有限的外推能力。
这使得本文方法能够在 [排放标准变化时] 提供有意义的预测。
```

### 策略 3：效率/成本差异化

**适用**：本文方法在保持相近精度的前提下大幅提升效率

**论证模板**：

```
已有方法 [A] 的精度为 [值]（来源：[引用]），
但计算复杂度为 O([复杂度])，在 [数据规模] 下需要 [时间]。

本文方法通过 [简化/近似/加速] 机制，
将复杂度降至 O([新复杂度])，计算时间减少至 [值]，
而精度仅从 [旧值] 降至 [新值]（↓[Y%]）。

这一精度损失在 [应用场景] 中是可接受的，
因为 [理由]（如：实时性要求/成本约束/数据噪声水平本身限制了精度上限）。
```

**注意事项**：
- 不能只比较时间不比较精度（那是在"偷工减料"）
- 精度损失必须被论证为"可接受的"

### 策略 4：假设/适用范围差异化

**适用**：本文方法放宽了已有方法的严格假设

**论证模板**：

```
已有方法 [A] 的前提假设包括：[假设1], [假设2], ...。
但在许多实际场景中，[假设X] 不成立。
例如，[具体场景] 中，[假设X违反的证据]。

本文方法通过 [机制] 放松了 [假设X] 的限制，
使方法在 [更广泛的条件] 下仍然有效。
代价是 [代价描述]，
但在 [失效场景] 中，本文方法的 [指标] 从 [旧值] 改善至 [新值]。
```

**示例**：

```
标准TOPSIS方法假设各评价指标相互独立。
但在城市宜居性评价中，经济指标与环境指标高度相关（ρ=0.82），
独立假设不成立会导致重复计算。

本文在主成分空间中进行TOPSIS评价，
PCA自动去相关化处理解决了指标冗余问题。
评价结果表明，考虑相关性后排名变化达 [X]%，
尤其在 [某类城市] 的排名变动最大，
验证了相关性处理的重要性。
```

## 三、对比表格的设计规范

### 好的对比表格

| 方法 | 数据需求 | 外推能力 | 物理约束 | 计算复杂度 | 本题适用性 |
|------|:---:|:---:|:---:|:---:|:---:|
| 线性回归 | 低 | ✅ | ❌ | O(p³) | 非线性关系→不适用 |
| 随机森林 | 中 | ❌ | ❌ | O(N·p·log N) | 无外推需求→适用 |
| LSTM | 高 | 部分 | ❌ | O(epochs·N·p²) | 样本不足→过拟合 |
| **本文方法（RF+约束）** | 中 | 部分 | ✅ | O(N·p·log N) | **最优匹配** |

**好的对比表格的特征**：
- 行=方法（含本文方法），列=关键维度
- 每个单元格不是简单的 ✅/❌，而是解释为什么
- 最后一列明确给出"本题适用性"的判断
- 本文方法不是在所有维度都是最优，但在总体匹配度上最高

### 差的对比表格

| 方法 | 精度 | 速度 | 可解释性 |
|------|:---:|:---:|:---:|
| 方法A | 低 | 快 | 高 |
| 方法B | 中 | 中 | 中 |
| 本文方法 | 高 | 快 | 高 |

→ 问题：本文方法在所有维度都是最优？这不诚实，评委会识破。

## 四、论文表达中的诚实边界

### 诚实做法

```
"本文方法在 [条件X] 下，[指标A] 优于已有方法 [B] 和 [C]。
但在 [条件Y] 下，[指标B] 不如方法 [D]。
这意味着本文方法的适用场景是 [明确范围]，而非所有情况。"
```

### 过度声称（避免）

```
"本文方法在所有指标上均优于已有方法"
"本文方法具有普遍适用性"
"本文方法是最优的"
```

**原则**：每一条"优于"的断言，后面要跟一句"但不如"或"但限于"的约束。

## 五、Related Work 段落的论文表达模板

### 竞赛论文版（精简，1-2段）

```
在 [问题领域] 的研究中，已有工作主要分为两类。
第一类 [类别A名称]，代表方法包括 [方法1] 和 [方法2]。
这类方法的优势是 [优势]，但局限在于 [局限]——
具体而言，[本问题中的表现]（表X）。

第二类 [类别B名称]，代表方法包括 [方法3] 和 [方法4]。
其优势是 [优势]，但局限在于 [局限]——
[本问题中的表现]（表X）。

综上，现有方法共同缺失的能力是 [Gap]。
本文正是针对这一Gap，提出了 [本文方法]，
其核心设计是 [简要机制]，预期能够 [填补Gap的方式]。
```

### 学术版本（详细，独立章节）

包含：系统性文献回顾 + 方法分类 + 逐个对比 + Gap分析 + 本文定位

## 六、自检清单

- [ ] 是否分类了已有方法（而非罗列）？
- [ ] 对每个已有方法的"不足"是否有具体证据（而非"不够好"）？
- [ ] Gap是否明确——是已有方法共同缺失的能力？
- [ ] 本文方法是否针对Gap设计（而非在做不同的事）？
- [ ] 对比表格的每个单元格是否有解释（而非纯 ✅/❌）？
- [ ] 是否承认了本文方法的局限（而非全维度优于已有方法）？
- [ ] 比较是否公平（相同的评价标准、相似的数据条件）？
