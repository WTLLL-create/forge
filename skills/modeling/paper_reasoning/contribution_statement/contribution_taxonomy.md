# 贡献分类体系（Contribution Taxonomy）

> 大多数学生做了实质工作但说不清创新在哪里。原因不是没创新，而是不知道创新属于哪一类。
>
> 本文件建立 L1-L5 五级贡献体系，让系统能自动判断：这个工作属于什么级别的创新？应该在论文中如何表达？

---

## 一、五级贡献分类

### L1：方法应用创新（「首次将X用于Y场景」）

**定义**：将已有方法应用到新场景，发现该方法在新场景下有效。

**特征**：
- 方法本身是标准的（没有改进）
- 创新在于发现了方法在新场景的适用性
- 通常伴随着"为什么这个方法适合这个场景"的论证

**示例**：

| 工作 | 创新陈述 |
|------|----------|
| 首次将 RF 用于水泥窑排放预测 | "本文将随机森林首次应用于工业窑炉排放预测，发现在此场景下RF对非线性耦合关系的捕捉优于传统统计方法" |
| 首次将 TOPSIS 用于某城市宜居性评价 | "本文首次将TOPSIS方法应用于XX城市的多维度宜居性评价，建立了包含N个指标的评价体系" |

**论文表达模板**：

```
[方法X] 在 [领域A] 中已被广泛验证，但尚未应用于 [本题领域B]。
[领域B] 的特点——[具体特点]——与 [方法X] 的优势——[具体优势]——高度匹配。
本文首次将 [方法X] 引入 [领域B]，并验证了其有效性。
```

**升级空间**：L1 → L2（如果在应用中发现了方法的不足并做了针对性调整）

---

### L2：模型融合/组合创新（「将A和B组合起来解决了一个A和B单独解决不了的问题」）

**定义**：将多个已有方法按新的方式组合，组合后的整体具有单一方法所不具备的能力。

**特征**：
- 每个组件都是已有的
- 创新在于组合方式和组合产生的协同效应
- 必须论证"为什么需要组合"和"组合为什么有效"

**示例**：

| 工作 | 创新陈述 |
|------|----------|
| K-means + RF + NSGA-II 分层代理优化 | "本文将聚类、代理建模和多目标优化组合为分层框架，实现了从工况识别到最优决策的端到端自动化" |
| 熵权 + TOPSIS + 灰色关联 | "本文提出熵权-TOPSIS-灰色关联的三层评价体系，熵权确定客观权重→TOPSIS计算距离→灰色关联验证结果一致性" |
| ARIMA + LSTM 残差融合 | "本文设计了趋势-残差双层预测框架：ARIMA提取线性趋势，LSTM对残差中的非线性模式进行二次建模" |

**论文表达模板**：

```
单一方法 [A] 在 [任务X] 上有效但在 [任务Y] 上失效，
单一方法 [B] 在 [任务Y] 上有效但在 [任务X] 上失效。
两者恰好互补：[A的强项] + [B的强项] = [任务X+Y]。

本文的关键创新不在于A或B本身，而在于发现 [A和B的互补关系]，
并设计 [融合机制] 使两者协同工作。
消融实验证实：去除任一组件 → [性能退化]，
验证了组合的必要性。
```

**升级空间**：L2 → L3（如果发现了问题的本质，从而重新定义了组合方式）

---

### L3：问题重构/视角创新（「这个问题不应该这样看，应该那样看」）

**定义**：重新定义问题的数学本质，从一个新的视角看待问题，从而打开了新的求解空间。

**特征**：
- 核心创新在对"问题是什么"的重新理解
- 不是改进解法，而是改变问题表述
- 通常带有"反直觉"或"跳出框架"的特征

**示例**：

| 工作 | 创新陈述 |
|------|----------|
| 将空气监测网络视为图结构 | "传统方法将各监测站视为独立时间序列。本文发现，站点间存在空间耦合——邻近站点的污染水平相互影响。本文将监测网络建模为图（节点=站点，边=距离加权的信息通道），引入GNN进行空间聚合" |
| 将参数优化重新表述为分布估计 | "传统优化方法直接搜索最优参数。本文换一个视角：不确定条件下的最优参数不是一个点，而是一个分布。通过贝叶斯方法估计参数的后验分布，不仅给出最优估计，还量化了不确定性" |
| 将排班问题重新表述为网络流 | "表面上的排班问题，本质上是时间-人员二分图上的最大流问题。这一重新表述将NP-hard的排班问题转化为多项式可解的网络流问题" |

**论文表达模板**：

```
传统上将 [问题] 视为 [传统视角]。
在传统视角下，[困难] 是内生的、难以消除的。

本文发现，该问题本质上可以重新表述为 [新视角]。
这一重新表述基于 [关键观察/数据证据/理论推导]。
在新视角下，原本的 [困难] 自然消解，因为 [原因]。

重新表述后的 [新问题形式] 具有 [优势]：
[优势1], [优势2], [优势3]。
```

**升级空间**：L3 → L4（如果这种重构揭示了普遍规律）

---

### L4：机制发现/规律揭示（「发现了数据中隐藏的一般规律」）

**定义**：在数据分析和建模过程中，发现了一个具有一般性的规律或机制，该发现本身就是核心贡献。

**特征**：
- 核心产出是"一个在此之前未被注意/未被量化的规律"
- 通常伴随着反直觉或违反常识的发现
- 发现具有推广价值（不同于仅适用于本题的特殊发现）

**示例**：

| 工作 | 创新陈述 |
|------|----------|
| 发现右删失数据中隐藏的"超标信号" | "54.7%数据被检测下限截断→但建模发现：通过右删失模式的统计分析，可以逆向推断实际排放的超标频率——这是数据缺陷本身蕴含的诊断信息" |
| 发现排放约束的边际成本非线性增长 | "Pareto前沿揭示：排放从10降到7 mg/Nm³仅需功率增加5%，但从7降到5 mg/Nm³需要功率增加40%。这一非线性关系意味着排放标准存在'最优区间'——边际收紧的一个临界点" |
| 发现某因素在特定条件下反转其影响方向 | "在低风速下，温度与PM2.5正相关（促进光化学反应）；但在高风速下，相关性不显著（扩散效应主导）。这种条件依赖的关系被传统全局相关性分析所掩盖" |

**论文表达模板**：

```
在 [数据/模型] 分析中，本文发现了一个反直觉的规律：
[规律的精确描述]。
这一发现与传统认知 [传统认知] 不一致，
因为它意味着 [含义]。

该发现的稳健性通过 [验证方式] 得到确认。
更重要的是，这一规律具有推广性：[可推广到哪些类似场景]。
本文是 [首次/较早] 在 [领域] 中发现并量化这一规律的工作。
```

**升级空间**：L4 → L5（如果从特殊规律中提炼出一般理论）

---

### L5：理论创新/一般性贡献（「提出的方法/发现具有跨越本题的一般价值」）

**定义**：论文提出的方法、模型或理论具有跨越具体题目的普遍适用性。

**特征**：
- 可推广性被明确论证（不只是声明）
- 通常包含"如果条件A成立，则方法X总是有效的"这类一般性断言
- 对其他类似问题有直接的指导意义

**示例**：

| 工作 | 创新陈述 |
|------|----------|
| 提出通用的右删失数据处理框架 | "本文不仅解决了本题的右删失问题，更建立了一个三步骤的右删失数据通用处理框架：（1）诊断→（2）建模→（3）信号提取。该框架适用于任何存在检测下限的环境监测数据" |
| 建立工业窑炉优化的通用代理建模范式 | "本文提出的'诊断-分层-代理-优化'四步范式，不仅是本题的求解方案，更为工业窑炉的数字化优化提供了一个可复用的方法学模板" |

**论文表达模板**：

```
虽然本文是在 [具体题目] 的背景下展开的，
但 [方法/发现] 的核心思想具有一般性：
只要满足条件 [条件1] 和 [条件2]，
[方法] 就可以直接应用或稍作调整后应用。

这是因为 [方法] 的数学基础 [数学基础] 不依赖于 [具体题目的特殊设定]，
而是源于 [一般规律]。

本文在 [推广场景1] 和 [推广场景2] 上验证了该方法的可迁移性，
结果与主实验一致。
```

## 二、创新等级判断决策树

```
你的工作中有以下哪些特征？

□ 方法本身是全新的（不是已有方法的组合/改进）
    → L5（理论创新）或 L4（如果新方法来自某个发现）

□ 发现了一个反直觉的、具有推广性的规律
    → L4（机制发现）

□ 重新定义了问题，打开了新的求解空间
    → L3（问题重构）

□ 将多个已有方法协同组合，形成新的流水线/框架
    → L2（模型融合）

□ 首次将已有方法成功应用于某个新场景
    → L1（方法应用）

如果多项同时满足，取最高等级。
```

## 三、不同等级的论文表达差异

| 维度 | L1 | L2 | L3 | L4 | L5 |
|------|:--|:--|:--|:--|:--|
| 创新陈述位置 | 仅摘要+模型评价 | 摘要+建模+模型评价 | 摘要+问题分析+建模 | 贯穿全文 | 贯穿全文+结论推广 |
| 关键词 | "首次应用于" | "设计了XX框架" | "重新表述" | "发现""揭示" | "建立了""提出了" |
| 对比对象 | 无对比（新场景） | 单独用A/单独用B | 传统视角下的解法 | 传统认知/常识 | 领域的标准方法 |
| 验证要求 | 有效性验证 | 消融实验 | 新旧视角对比 | 多数据集/多条件验证 | 跨题目验证 |

## 四、常见错误

| 错误 | 示例 | 修正 |
|------|------|------|
| **创新等级过高** | "本文方法具有普遍适用性"（但只在本题验证了） | L5需要跨题目验证，否则只能声称L2或L3 |
| **创新等级过低** | 明明重构了问题却说"本文使用了XX模型" | 按照决策树重新定位创新等级 |
| **创新伪陈述** | "本文首次使用Python求解此问题" | 工具选择不是学术创新 |
| **创新无证据** | "本文方法是创新的"但没说创新在哪 | 必须用贡献陈述的具体模板（contribution_formulation.md） |
