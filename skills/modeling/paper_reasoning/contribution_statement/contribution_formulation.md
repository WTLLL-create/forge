# 贡献提炼器（Contribution Formulation）

> 核心问题：很多队伍做了 KMeans + RF + NSGA-II 但说不清创新是什么。
>
> 本文件提供从"做了什么"到"贡献是什么"的完整转化规则。

---

## 一、核心转化原则

```
做了什么（操作层）          →    贡献是什么（价值层）
─────────────────                ─────────────────
使用了K个模型                    提出了一种XXX框架
对数据做了预处理                建立了XXX的数据诊断与校正流程
比较了多个模型                  揭示了XXX在YYY条件下的性能边界
改进了标准模型                  通过ZZZ机制解决了标准模型的WWW缺陷
```

**关键认知**：贡献不是"你做了什么"，而是"你的做法对解决这个问题意味着什么"。

---

## 二、十种常见转化模板

### 模板 1：多步骤流程 → 框架

**适用**：你做了一个多步骤的 pipeline（预处理→聚类→代理→优化）

```
❌ "本文使用了 K-means、随机森林和 NSGA-II 三个模型"

✅ "本文提出一种面向异质工况的分层代理优化框架：
    K-means 识别典型工况 → RF 建立工况-目标代理模型 → NSGA-II 在代理模型上搜索最优解。
    该框架的核心优势是：将原本不可解的复杂优化问题
    分解为'分类→学习→优化'三个阶段，每阶段使用最匹配的方法。"
```

### 模板 2：数据处理 → 诊断方法

**适用**：你发现了数据中的特殊问题并针对性处理

```
❌ "本文对数据进行了清洗和预处理"

✅ "本文建立了右删失数据的系统诊断与校正流程：
    (1)识别——通过分布分析发现 54.7% 排放数据右删失；
    (2)建模——建立考虑删失机制的 Tobit 模型；
    (3)利用——将右删失模式转化为诊断信号，指导优化方向。
    该流程可推广至任何存在检测下限的环境监测数据。"
```

### 模板 3：模型比较 → 性能边界发现

**适用**：你做了多个模型的对比实验

```
❌ "本文比较了多个模型的性能"

✅ "本文通过系统的模型对比实验，揭示了在 [具体条件下]：
    - RF 优势在于 [X]，但 [Y] 场景下退化 [Z%]
    - LSTM 优势在于 [X]，但受限于 [Y] 
    - ARIMA 在 [X] 条件下反而优于复杂模型
    这一发现为同类问题的模型选择提供了经验指导。"
```

### 模板 4：标准模型改进 → 针对性增强

**适用**：你对标准模型做了修改

```
❌ "本文改进了随机森林模型"

✅ "标准随机森林在处理本题数据时存在两个不足：
    (1)无法融入物理约束，可能产生物理上不可能的结果；
    (2)对时间依赖性不敏感。
    本文针对性提出两项改进：
    - 在损失函数中加入排放物理约束惩罚项
    - 构造滞后和滑动窗口特征显式注入时间信息
    消融实验表明（表X），两项改进分别提升 [X%] 和 [Y%]。"
```

### 模板 5：跨学科方法 → 方法迁移

**适用**：你从其他领域引入了一个方法

```
❌ "本文使用了图神经网络"

✅ "本文将空气质量监测站网络建模为空间图结构：
    节点 = 监测站，边 = 站间距离加权的信息传递通道。
    这一建模方式源自社交网络分析，本文首次将其迁移到
    环境监测领域，使模型能够利用'邻近站点的信息互补'。
    实验表明加入图结构后 RMSE 降低 [X%]，验证了空间信息的价值。"
```

### 模板 6：理论分析 → 理论洞察

**适用**：你通过推导发现了某种规律

```
❌ "本文推导了XX的数学公式"

✅ "本文从 [基本假设] 出发，推导出 [关键关系]：
    [公式]
    这一推导揭示了一个反直觉的结论：
    [具体结论]。
    该结论具有一般性，适用于 [推广范围]。"
```

### 模板 7：敏感性分析 → 决策指导

**适用**：你做了参数敏感性分析

```
❌ "本文分析了各参数的敏感性"

✅ "本文通过全局敏感性分析（Sobol方法）发现：
    [参数X] 贡献了总方差的 [Y%]，是最关键的控制变量。
    这意味着在实际工程中，应优先控制 [参数X]，
    而 [参数Z] 的调节对结果影响极小（<3%），可以放宽控制精度。
    这一发现为 [实际应用场景] 提供了明确的优先级指导。"
```

### 模板 8：消融实验 → 必要性证明

**适用**：你做了消融实验

```
❌ "消融实验显示各组件都有贡献"

✅ "消融实验验证了框架中每个组件的必要性：
    - 去除工况分类：优化目标恶化 [X%]（优化器陷入局部最优）
    - 去除代理模型：计算时间增加 [Y倍]（直接评估不可承受）
    - 去除多目标：无法揭示 [权衡关系]
    这表明该框架的每一层设计都是不可省略的。"
```

### 模板 9：矛盾解决 → 方法创新

**适用**：你识别并解决了一个核心矛盾

```
❌ "本文用多目标优化解决了权衡问题"

✅ "本文识别并解决了一个核心矛盾：
    [矛盾描述]。
    为解决该矛盾，本文设计了 [策略]，
    其关键创新在于 [具体机制]。
    结果表明，该策略在 [指标A] 和 [指标B] 上
    分别比传统方法提升 [X%] 和 [Y%]。"
```

### 模板 10：问题重构 → 新视角

**适用**：你从一个新的角度看待了问题

```
❌ "本文从XX角度分析了问题"

✅ "传统方法将 [问题] 视为 [传统视角]。
    本文发现，该问题本质上可以表述为 [新视角]。
    这一重新表述的关键优势是：
    [优势1], [优势2], [优势3]。
    在新表述下，原本 [困难] 变得 [可处理]。"
```

## 三、贡献提炼的操作流程

```
Step 1: 列出所有"做了什么"
  [做了什么A], [做了什么B], [做了什么C], ...

Step 2: 对每个"做了什么"提问
  → 它是解决了什么旧方法解决不了的问题？
  → 它的效果有什么特别之处？
  → 它是否可以推广到其他类似问题？
  → 有没有反直觉的发现？

Step 3: 寻找"做了什么"之间的联系
  → 这些步骤是否可以概括为一个更大的概念？
  → 是否存在"因为A所以B"的因果链条？

Step 4: 用模板转化为贡献陈述
  → 从10种模板中选择最匹配的
  → 填入具体数值和数据证据

Step 5: 自检
  → 贡献陈述中的每一个断言，是否有数据支撑？
  → 贡献是否与"做了什么"一一对应？（不能挂羊头卖狗肉）
```

## 四、贡献陈述的常见错误

| 错误类型 | 示例 | 修正 |
|----------|------|------|
| **过度声称** | "本文方法优于所有现有方法" | "在本题的数据条件下，本文方法在 [指标A] 上优于对比的 [3个] 基线模型" |
| **空泛修饰** | "本文提出了创新性的方法" | 必须说出具体创新在哪里，而非笼统的"创新性" |
| **贡献-操作混淆** | "本文的贡献是用RF建模" | RF是工具，贡献应该是RF使用中的独到之处（特征工程/物理约束/分群策略） |
| **贡献过小** | "本文的贡献是调参" | 调参不是学术贡献（除非你提出了一种新的调参方法） |
| **贡献过大** | "本文方法适用于所有预测问题" | 必须明确适用范围和边界 |

## 五、与摘要的关系

贡献提炼的输出是**摘要中"本文主要贡献"段落**的直接素材。

国奖摘要的标准结构：

```
1. [问题背景] 一句话
2. [核心矛盾] 一句话  
3. [本文方法] 一句话 ← 来自贡献提炼
4. [主要贡献] 1-2句话 ← 来自贡献提炼
5. [关键结果] 具体数值
6. [创新点] 一句话
```

## 六、与 contribution_taxonomy 和 contribution_vs_related 的衔接

```
contribution_formulation（本文件）
    ↓ 输出：贡献陈述
contribution_taxonomy
    ↓ 贡献类型分类（理论/方法/应用/验证）
contribution_vs_related
    ↓ 与已有方法的差异化表达
```
