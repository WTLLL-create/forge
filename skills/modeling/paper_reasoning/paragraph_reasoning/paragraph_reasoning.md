# 段落逻辑引擎（Paragraph Reasoning）

> Forge 能生成章节，但不能控制「每个段落为什么存在」。
>
> 本文件定义论文中三类核心段落的标准逻辑结构，确保每一段都有明确的存在理由。

---

## 零、核心原则

论文中每一个段落必须能回答以下三个问题：

```
1. 这一段在论证链条中的位置是什么？
   （不是"这是问题分析的第三段"，而是"这一段在从A到B的推理中做了什么"）

2. 这一段和上一段的逻辑关系是什么？
   （因果？递进？转折？例证？对比？）

3. 如果删除这一段，论证链条的哪一环会断裂？
   （如果无法回答，这段就是冗余的）
```

---

## 一、问题分析段（Problem Analysis Paragraph）

### 标准逻辑模板

```
句1: 现实背景（一句话建立问题的实际意义）
  → "XX问题是YY领域的核心挑战之一"

句2: 问题的数学本质（将实际问题抽象为数学问题）
  → "该问题本质上是一个[数学描述]"

句3: 核心困难（为什么这个问题不好解决）
  → "然而，[困难描述]使得[传统方法]难以直接应用"

句4: 本文策略（一句话预告本文的解决方案）
  → "本文从[视角]出发，通过[策略]来应对这一困难"
```

### 逻辑检查

| 句序 | 功能 | 如果缺失 |
|:---:|------|------|
| 句1 | 建立问题的重要性 | 读者不明白为什么要关心这个问题 |
| 句2 | 从实际到数学的抽象 | 读者不知道建模的起点是什么 |
| 句3 | 论证问题的难度 | 读者会问"为什么不直接用XXX？" |
| 句4 | 预告解决方案 | 读者没有阅读预期，不知道后面要证明什么 |

### 完整示例

```
大型工业窑炉的排放控制是环境工程和过程控制的交叉难题。
该问题本质上是一个部分可观测条件下的多目标约束优化问题：
决策者需要调节多个控制参数以同时最小化排放和能耗，
但排放的真实值受检测下限限制，超过半数数据被截断。

然而，数据的右删失特征使得标准的代理建模方法失效——
当54.7%的目标值被压缩在同一常数时，
任何回归模型都无法学习到真实的排放-控制参数关系。

本文从统计诊断的视角出发：
首先识别右删失的结构特征，
然后建立考虑删失机制的Tobit代理模型，
最后在代理模型上进行多目标优化。
这一"诊断-建模-优化"的分层策略，
将数据缺陷从障碍转化为诊断信号。
```

## 二、模型建立段（Model Establishment Paragraph）

### 标准逻辑模板

```
句1: 建模动机（承接上文的问题分析，解释为什么需要这个模型）
  → "基于上文对[矛盾]的分析，本节建立[模型名]以[目标]"

句2: 模型假设（2-3条核心假设，每条件简洁说明理由）
  → "为建立可解的数学模型，本文提出以下假设：[H1...H2...H3...]"

句3: 数学定义（将问题要素符号化）
  → "定义决策变量x_i为...目标函数为...约束条件为..."

句4: 模型形式（给出完整的数学模型）
  → "综上，[问题]可形式化为：[公式/模型描述]"

句5: 选择理由（一句话回到矛盾，解释为什么这个模型形式合适）
  → "该模型形式之所以适合，是因为[与矛盾的对应关系]"
```

### 逻辑检查

| 句序 | 功能 | 如果缺失 |
|:---:|------|------|
| 句1 | 建立动机→承上启下 | 读者不明白"为什么突然开始建模" |
| 句2 | 明确模型的适用范围 | 读者质疑"这个假设合理吗？" |
| 句3 | 从自然语言到数学符号 | 后续公式不知所云 |
| 句4 | 模型的核心内容 | 论文没有模型，只有描述 |
| 句5 | 回到矛盾，形成闭环 | 读者会问"为什么是这个形式而不是别的？" |

### 完整示例

```
基于§X中对右删失数据的诊断分析，本节建立考虑删失机制的
代理模型，以在不可靠的观测数据上学习可靠的排放-控制参数关系。

为建立可解的数学模型，本文提出两个核心假设：
H1：排放的真实值服从以控制参数为条件的Tobit分布；
H2：不同工况下，排放-控制参数的关系具有不同的函数形式，
    但均可通过相同结构的模型（不同参数）来刻画。

定义y_i^*为第i条记录的真实排放值（不可直接观测），
y_i为报告的排放值（max(50, y_i^*)），
x_i为控制参数向量。
模型的目标是从{(x_i, y_i)}中学习E[y^* | x]。

综上，代理模型的数学形式为Tobit回归：
[公式]。
参数通过极大似然估计获得，似然函数包含删失观测的贡献[公式]。

该模型形式之所以适合本题，是因为它不回避54.7%的右删失数据，
而是将删失机制本身纳入似然函数——
每一次"报告值=50"不再是模型的噪声，
而是提供了"真实值≥50"的信息。
这是标准OLS回归（R²=-0.26）与本文模型（R²=0.71）的根本区别。
```

## 三、结果分析段（Result Analysis Paragraph）

### 标准逻辑模板

```
句1: 结果陈述（客观报告数值）
  → "图X/表X显示，[定量结果]"

句2: 结果解读（解释数值的含义，不只是重复数字）
  → "这表明/意味着/揭示了[深层含义]"

句3: 原因分析（为什么会是这个结果？）
  → "出现这一结果的原因是[机制解释]"

句4: 对比/验证（与其他结果或预期对比）
  → "相比[基线/预期]，[差异]说明了[结论]"

句5: 局限或推广（可选，诚实标注）
  → "需要注意的是，[局限条件]下此结论可能不成立"
```

### 逻辑检查

| 句序 | 功能 | 如果缺失 |
|:---:|------|------|
| 句1 | 客观事实 | 没有证据，后面的分析都是空谈 |
| 句2 | 将数字转化为含义 | 读者不知道"RMSE=6.1是好是坏" |
| 句3 | 解释为什么 | "结果更好"是描述，"为什么更好"是研究 |
| 句4 | 建立参考系 | 没有对比就没有"好"的概念 |
| 句5 | 诚实边界 | 避免过度声称，增加可信度 |

### 完整示例（包含两个嵌套的结果分析段）

```
（段1：优化结果）
Pareto前沿（图X）显示，排放浓度从10降至7 mg/Nm³时，
功率仅需增加5.2%；但从7降至5 mg/Nm³时，
功率需大幅增加41.3%（表Y）。
这表明排放与功率的权衡关系高度非线性：
存在一个"边际成本"急剧上升的临界区间。

这一非线性特征的物理根源在于电除尘器的效率曲线——
在中等电场强度下，颗粒收集效率随电压线性增长；
但当电场强度接近击穿阈值时，进一步增加电压不仅效率递减，
还会引发电晕功率的指数级增长（[文献引用]）。

（段2：决策建议）
基于此发现，本文推荐将排放目标设定在约7 mg/Nm³——
该点在Pareto前沿上位于"膝盖"区域，
排放相比原始水平改善约50%，而功率增加仅5.2%。
作为对比，若将排放进一步压缩至5 mg/Nm³，
边际成本（功率增幅/排放降幅）将急剧上升至前者的8倍。

需要注意的是，这一推荐基于当前设备的特性曲线。
若设备经改造后击穿阈值提高，则Pareto前沿将整体左移，
"膝盖点"位置也会相应变化——这意味着本文的优化框架
（而非具体的数值推荐）对设备升级具有适应能力。
```

## 四、段落过渡规则

段落之间的逻辑连接不能只有"此外""另外""接下来"。每个过渡应该解释**为什么从A到B**。

| 关系类型 | 过渡句模板 |
|----------|-----------|
| 因果 | "上述分析揭示[现象]→这意味着需要[下一步行动]" |
| 递进 | "在建立了[基层]之后，一个自然的问题是[更深层的问题]" |
| 转折 | "[上述方法]的优势在于[X]，但它在[Y]条件下存在局限→本节解决这一局限" |
| 例证 | "以[具体场景]为例，上述规律的表现为[具体数据]" |
| 对比 | "为验证[方法]的有效性，本节以[基线方法]为参照" |
| 总结 | "综上，本节的三个核心发现是：[发现1][发现2][发现3]。它们共同指向[结论]" |

### 反例：弱过渡

```
❌ "接下来，本文使用NSGA-II进行优化。"
   → 为什么"接下来"？K-means和RF的结果驱动了这个选择吗？

✅ "代理模型将复杂的排放-功率关系压缩为一个可快速评估的函数。
   这使优化成为可能——代理模型每评估一次仅需O(1)时间，
   而真实系统评估（如果可行）需要数小时。
   因此，本节在代理模型的基础上，使用NSGA-II搜索Pareto最优解。"
```

## 五、段落冗余检测

以下信号表明一个段落可能是冗余的：

- [ ] 删掉这一段后，前后段落仍然逻辑连贯
- [ ] 这一段可以被一句话总结而不丢失信息
- [ ] 这一段的内容在论文的其他位置已经出现过
- [ ] 这一段的核心信息是"某模型是某领域常用的"（这是教科书内容，不是论文贡献）
- [ ] 这一段以"此外""另外""同时"开头且没有解释因果关系

**检测方法**：对每个段落问一句——"如果删掉这一段，读者对本文贡献的理解会打折扣吗？"
如果答案是"不会"，则删除或重写。
