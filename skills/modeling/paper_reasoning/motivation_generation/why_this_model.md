# 为什么选这个模型（Why This Model）

> 评委最常问的潜台词：「为什么选这个模型？」当前系统只说「预测问题→选RF」，但不会论证。
>
> 本文件定义**三层论证框架**：从问题特征出发 → 排除不合适的模型 → 论证选中模型的匹配性。

---

## 一、三层论证框架

```
第一层：问题特征分析
    ↓
第二层：传统方法为什么不适用（每个被排除的模型都有明确的排除理由）
    ↓
第三层：本文方法为什么合适（选择理由必须绑定问题特征）
```

### 为什么是三层而不是一层？

```
❌ 一层：预测问题 → 选 RF（没有论证）

✅ 三层：
  问题特征：非线性关系 + 多变量交互 + 样本量500+
  排除线性模型：线性假设不成立（特征-目标 Spearman ρ > 0.7 的特征仅 3/23）
  选择 RF：自动捕捉交互 + 非线性 + 特征重要性可解释 → 匹配问题特征
```

## 二、第一层：问题特征分析

在选模型前，先回答以下问题（映射到具体的数据特征）：

### 2.1 预测类问题的特征清单

| 特征维度 | 分析问题 | 如何回答 | 影响什么模型选择 |
|----------|----------|----------|:---:|
| 数据规模 | 样本量 N？ | N = [数值] | N<30 → 灰色/贝叶斯；N=30-200 → ARIMA；N>1000 → ML |
| 线性/非线性 | 特征-目标关系？ | Spearman ρ 分布 / 散点图 | 线性为主 → 线性回归；非线性为主 → RF/XGBoost |
| 时序特性 | 有时间维度？ | ADF 检验 p = [值] | 平稳 → ARIMA；非平稳 → 差分+ARIMA 或 LSTM |
| 季节/周期 | 有周期性模式？ | ACF/PACF 图 | 有 → SARIMA；无 → ARIMA/Holt-Winters |
| 噪声水平 | 信噪比？ | σ_noise/σ_signal = [值] | 高 → 移动平均+鲁棒模型；低 → 精细模型 |
| 特征维度 | 特征数 p？ | p = [值] | p>N/3 → PCA降维或正则化；p<<N → 任意模型 |
| 外推需求 | 需要超出训练范围？ | 题目是否要求预测未来 | 是 → 机理/线性为主；否 → 数据驱动自由选择 |
| 解释性需求 | 需解释预测原因？ | 论文是否需要特征贡献分析 | 是 → 线性/树模型+SHAP；否 → LSTM |

### 2.2 优化类问题的特征清单

| 特征维度 | 分析问题 | 影响什么方法选择 |
|----------|----------|:---:|
| 线性/非线性 | 目标函数和约束的数学形式？ | 线性 → LP；非线性 → NLP |
| 连续/离散 | 决策变量类型？ | 连续 → LP/NLP；离散 → IP/MIP |
| 问题规模 | 变量数？约束数？ | 小 → 精确算法；大 → 启发式 |
| 单/多目标 | 几个目标函数？ | 1 → 单目标优化；≥2 → Pareto/加权 |
| 凸性 | 目标函数是否凸？ | 凸 → 局部最优=全局最优；非凸 → 多起点 |
| 约束复杂度 | 约束数量和类型？ | 简单 → 标准求解器；复杂 → 元启发式 |

### 2.3 评价类问题的特征清单

| 特征维度 | 分析问题 | 影响什么方法选择 |
|----------|----------|:---:|
| 指标数量 | 几个评价指标？ | ≤5 → AHP可行；>10 → 熵权/CRITIC |
| 指标独立性 | 指标间相关性？ | 有强相关 → 先PCA再评价 |
| 主观/客观 | 有专家经验吗？ | 有 → AHP；无 → 熵权 |
| 量纲差异 | 指标单位一致吗？ | 不一致 → 必须无量纲化 |
| 方向性 | 哪些正向/负向？ | TOPSIS 需要明确标注 |

### 2.4 分类类问题的特征清单

| 特征维度 | 分析问题 | 影响什么方法选择 |
|----------|----------|:---:|
| 样本-特征比 | N vs p？ | p>N → 降维+SVM；p<<N → 任意 |
| 类别平衡 | 各类样本数比例？ | >3:1 → SMOTE+代价敏感 |
| 线性可分性 | 特征空间可分？ | 是 → LDA/Logistic；否 → SVM(RBF)/RF |
| 概率需求 | 需要输出概率？ | 是 → Logistic/NB；否 → 任意 |

## 三、第二层：传统方法为什么不适用

这一层是区分"会用模型"和"理解模型"的关键。

### 3.1 标准论证模板

```
候选模型A：[模型名称]
  适用条件：[A适用的标准场景]
  本题情况：[本题是否满足适用条件]
  排除原因：[如果不满足，具体是什么不满足？]
  如果强行使用：[预期会出现的失败模式]

候选模型B：[模型名称]
  适用条件：[B适用的标准场景]
  本题情况：[本题是否满足适用条件]
  排除原因：[如果不满足，具体是什么不满足？]
  如果强行使用：[预期会出现的失败模式]
```

### 3.2 常见排除理由库

| 被排除的模型 | 典型排除理由 | 数据证据要求 |
|-------------|-------------|-------------|
| 线性回归 | 特征-目标非线性（Spearman ρ < 0.3 for key features） | 散点图 + 相关系数表 |
| ARIMA | 时序非平稳（ADF p>0.05） | ADF检验结果 |
| LSTM | 样本量 < 1000（容易过拟合） | N的值 |
| RF | 需要外推（树模型不能外推） | 题目明确要求预测训练范围外的值 |
| SVM | 样本量 > 10000（训练时间不可接受） | N的值 |
| K-means | 聚类数未知且无先验知识 | 肘部图不清晰 |
| LP | 目标或约束非线性 | 数学形式检查 |
| AHP | 无专家可提供判断矩阵 | 竞赛环境中专家不可得 |

### 3.3 常见错误

| 错误 | 示例 | 修正 |
|------|------|------|
| **不排除任何模型** | 直接说"本文使用RF" | 必须论证至少2个为什么不用 |
| **假排除** | "ARIMA也可以用但本文没选" | 必须给出具体的、数据支撑的排除理由 |
| **万能排除** | "LSTM太复杂所以不用" | "太复杂"不是理由，要说清楚"本题样本量仅200，LSTM易过拟合" |
| **反向论证** | "神经网络精度高所以本文用它" | 精度高不是选择理由——可能过拟合。要论证为什么不会过拟合 |

## 四、第三层：本文方法为什么合适

### 4.1 论证模板（按模型类型）

#### 预测类

```
本文选择 [模型X] 的核心理由：

1. [问题特征A] 与 [模型X的天然优势] 匹配
   本题的 [特征描述]（定量证据：[数值]）。
   [模型X] 恰好 [如何处理这一特征]。

2. [模型X] 解决了传统方法 [Y] 的 [具体缺陷]
   传统方法 [Y] 无法处理 [缺陷]（定量证据：[数值]）。
   [模型X] 通过 [机制] 克服了这一限制。

3. [模型X] 在此类问题中有良好的文献支持
   [引用1-2篇文献] 在类似场景中验证了 [模型X] 的有效性。
```

#### 优化类

```
本文选择 [方法X] 的核心理由：

1. 问题特征→方法匹配
   目标函数 [线性/非线性]（数学形式：[公式]）
   → 选择 [LP/NLP/...] 方法

2. 规模适应性
   决策变量数 = [X]，约束数 = [Y]
   → [精确/启发式] 方法在此规模下 [可行/不可行]

3. 与标准的对比
   标准方法 [Y] 的局限：[具体局限]
   本文通过 [改进] 克服：[具体改进]
```

### 4.2 论文表达对照

| 层次 | ❌ 错误表达 | ✅ 正确表达 |
|------|-----------|-----------|
| 一层 | "本文使用随机森林进行预测" | — |
| 二层 | "线性模型不适用" | "Spearman相关性分析（表X）显示，23个特征中仅3个与目标呈线性相关（\|ρ\|>0.7），说明线性假设不成立。因此本文放弃线性回归，转向能捕捉非线性关系的模型。" |
| 三层 | "随机森林精度高" | "随机森林的三个特性与本题高度匹配：(1)无需特征变换即可捕捉非线性关系；(2)内置的特征重要性评估可揭示污染主控因子；(3)在此类表格数据上的表现经过大量文献验证。因此本文选择随机森林作为核心预测器。" |

## 六、自检问题

在完成模型选择论证后，用以下问题自检：

- [ ] 是否基于**本题的数据特征**选择模型，而非基于"这个模型流行"？
- [ ] 是否排除了至少 **2 个候选模型**，且每个都有数据支撑的排除理由？
- [ ] 选择理由是否绑定了**具体的问题特征**（而非"精度高""效果好"等空话）？
- [ ] 排除理由是否包含"如果强行使用会怎样"的预期失败模式？
- [ ] 论文中是否用了定量证据（数字/图表/统计量）而非定性描述？
