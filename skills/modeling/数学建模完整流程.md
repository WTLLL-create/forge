# 数学建模完整流程

> 能力定义：从拿到题目到提交最终文档的端到端工作流程，覆盖 10 个阶段。
> 每个阶段定义输入、处理步骤、输出和质量检查点。
> 本文件是 AI 执行数学建模任务的「操作手册」（教学视角）。
>
> ⚠️ **状态机映射**：本文档的阶段划分对应 `agent_system/state_machine.md` 的 S0→S8 标准状态。
> 本文档为详细的教学说明，状态机为调度层的唯一权威标准。
>
> 🧭 **竞赛实战操作层**：当赛题跨多个 AI 工具/会话、带官方在线模拟器（正式测试机会有限）、
> 或同时有"硬安全保证 + 效率目标"时，除本流程外必须加载 `contest_ops/`（beta，2026 真题 B 实证）：
> 跨模型交接包、证据边界与事实表、对抗性逻辑碰撞复核、阶段0现状审计与下界纪律、
> 在线/离线双世界协议、可复现论文图集。入口见 `contest_ops/README.md`。

## 阶段 1：审题分析

### 输入
- 竞赛题目 PDF 全文
- 附件数据文件（Excel/CSV/TXT）

### 处理步骤

**Step 1.1 — 全文通读**
- 逐字阅读题目，不做任何标记
- 建立题目的整体印象

**Step 1.2 — 逐段标注**
- 用高亮标注：背景信息（蓝）、约束条件（红）、问题要求（绿）、数据说明（黄）
- 对每个约束写出其数学含义

**Step 1.3 — 调用题型识别**
- 使用 `数学建模题型识别.md` 判定主类型和子类型
- 输出题型识别结果

**Step 1.4 — 评估难度**
- 根据约束条件数量、数据复杂度、子问题数量，评估整体难度
- 判断是否有明显不可行的子问题（如有，标记为简化/假设处理）

### 输出
```
【审题分析报告】
◆ 题目一句话概括：[20字以内]
◆ 题型分类：[主类型 + 子类型]
◆ 约束条件清单：[逐条编号，每条写出数学含义]
◆ 数据清单：[数据文件名 + 字段数 + 样本量 + 时间范围]
◆ 核心难点：[1-3 个]
◆ 初步建模方向：[给出方向，不做最终确定]
```

## 阶段 2：问题拆解

### 输入
- 审题分析报告
- 题目原文中的子问题列表

### 处理步骤

**Step 2.1 — 识别子问题**
- 从题目中提取每个需要求解的子问题（通常已编号为 1/2/3/4）
- 对每个子问题写一句话概括

**Step 2.2 — 分析依赖关系**
- 子问题之间是递进（1→2→3→4）还是并行（1，2→3）？
- 标注每个子问题需要哪些前置结果

**Step 2.3 — 建立问题链**
```
问题1（数据预处理/基础计算）
    ↓ 输出作为输入
问题2（探索性分析/聚类/关联）
    ↓ 输出作为特征
问题3（核心建模/预测/优化）
    ↓ 输出作为基准
问题4（模型增强/协同/对比）
```

**Step 2.4 — 分配角色**
- 哪个子问题是"凑数型"（套公式即可，不需要建模）→ 快速完成
- 哪个子问题是"核心型"（需要重点投入模型设计和算法实现）→ 重心在此
- 哪个子问题是"加分型"（不是必须但做了加分）→ 视时间决定

### 输出
```
【问题拆解图】
问题1：[类型] [一句话概括] ← 前置依赖：无
  ├─ 输出：XXX
  ↓
问题2：[类型] [一句话概括] ← 前置依赖：问题1 的 XXX
  ├─ 输出：YYY
  ↓
...

【投入分配建议】
问题N（核心）：投入 40% 时间
问题M（加分）：投入 20% 时间
...
```

## 阶段 3：数据分析

### 输入
- 问题拆解图
- 所有附件数据文件

### 处理步骤

**Step 3.1 — 数据加载**
- 读取所有数据文件，确认行列数符合预期
- 识别数据类型（数值/分类/时间/文本）

**Step 3.2 — 数据清洗**
- **缺失值**：识别缺失比例，判断删除/插值/中位数填充
  - 缺失 > 50%：删除该列
  - 缺失 < 10%：中位数（数值）/众数（分类）
  - 缺失 10-50%：拉格朗日插值或 KNN 插值
- **异常值**：箱线图识别（IQR > 1.5 倍），判断是真实离群还是录入错误
- **重复值**：完全重复的行直接删除

**Step 3.3 — 描述性统计**
- 数值变量：均值、标准差、min/max、四分位数
- 分类变量：各类频数、占比
- 时间变量：起止时间、时间跨度、采样频率

**Step 3.4 — 可视化探索（必须生成图片用于论文）**
- 分布图：直方图 + 核密度估计（每个关键变量）
- 时序图：折线图（有时间维度的变量）
- 相关性热力图：所有数值变量两两 Spearman 相关系数
- 箱线图：检测异常值和分布差异
- 空间分布图：散点图（有经纬度的数据）

**Step 3.5 — 数据预处理**
- 归一化/标准化：z-score（均值为0方差为1）或 min-max（缩放到 [0,1]）
- 特征工程：根据领域知识创建新特征（比率、差值、滑动窗口统计）
- 降维（如需）：PCA（保留 85% 方差）或 t-SNE（可视化用）

### 输出
```
【数据分析报告】
◆ 数据概览：[每个文件的列数、行数、缺失率]
◆ 关键发现：[1-3 个重要发现]
◆ 预处理方案：[每一步的处理方法及参数]
◆ 可视化图表清单：[图1: XXX, 图2: YYY, ...]
```

## 阶段 4：模型选择

### 输入
- 题型识别结果（阶段 1）
- 数据分析报告（阶段 3）
- 问题拆解图（阶段 2）

### 处理步骤

**Step 4.1 — 逐子问题选择模型**
- 对每个子问题，使用 `模型选择决策树.md`
- 沿决策树行进到叶子节点

**Step 4.2 — 模型组合设计**
- 确定子问题之间的模型关系：串行（下一问题用上一问题输出）还是并行
- 如果子问题间有模型复用（如问题 2/3/4 共用同一算法框架），在此统一设计

**Step 4.3 — 备选方案确定**
- 对核心子问题，至少准备 1 个备选模型（用于对比实验）

### 输出
```
【模型选择决策记录】（每个子问题一份）
见 模型选择决策树.md 的输出格式
```

---

## 阶段 5：模型建立

### 输入
- 模型选择决策记录
- 数据分析报告

### 处理步骤

**Step 5.1 — 模型假设**
- 列出所有为简化模型而做的假设
- 每条假设必须有理由（不能是"假设成立"这种空话）
- 假设类型：
  - 物理简化（忽略空气阻力、视为质点）
  - 数学简化（线性近似、无穷小忽略）
  - 边界限定（仅考虑理想情况）

**Step 5.2 — 符号定义**
- 用统一的符号表列出所有变量
- 符号规范：大写表示常量/矩阵，小写表示变量，希腊字母表示参数

**Step 5.3 — 数学模型数学表达**
- 目标函数的数学形式（如果是优化问题）
- 约束条件的数学表达
- 关键方程的推导过程
- 每个公式后面用中文解释其含义

### 输出
```
【模型数学表达】
◆ 模型假设清单：[编号 + 假设内容 + 理由]
◆ 符号表：[符号 | 含义 | 单位/类型]
◆ 目标函数：[LaTeX 公式] → 含义解释
◆ 约束条件：[LaTeX 公式 1..n] → 含义解释
◆ 关键推导步骤：
  从 [原始方程] 
  → [简化/替换/近似] 
  → [最终形式]
```

## 阶段 6：模型求解

### 输入
- 模型数学表达（阶段 5）
- 数据（阶段 3 清洗后）

### 处理步骤

**Step 6.1 — 算法落地**
- 将阶段 4 选定的算法转为可执行代码
- 语言选择：数值计算用 Python (NumPy/SciPy)，统计用 Python (statsmodels/scikit-learn)，图算法用 Python (networkx)
- 优化类用 Gurobi/COPT（如有学术许可）或 scipy.optimize/scikit-opt

**Step 6.2 — 参数设定**
- 对每个算法，确定参数值
- 参数来源优先级：题目给定 > 文献推荐 > 经验值 > 网格搜索最优值
- 记录每个关键参数的取值和理由

**Step 6.3 — 代码实现**
- 每个子问题一个独立的 Python 脚本
- 代码结构：数据加载 → 数据清洗 → 模型拟合 → 结果输出 → 图表生成
- 关键中间结果保存为 CSV，便于论文引用

**Step 6.4 — 结果记录**
- 将模型输出整理为结构化表格
- 保留中间结果（trace、log）以便后续分析

### 输出
```
【求解报告】（每个子问题一份）
◆ 算法：XXX
◆ 关键参数：[参数名 = 值（理由）]
◆ 运行时间：XXX 秒
◆ 结果摘要：[关键数字]
◆ 收敛性：收敛曲线平稳？是/否
```

## 阶段 7：模型验证

### 输入
- 求解结果（阶段 6）
- 原始数据

### 处理步骤

**Step 7.1 — 准确性验证**
- 预测类：计算 MAE、RMSE、MAPE、R²
- 分类类：计算准确率、精确率、召回率、F1、AUC
- 优化类：计算最优目标函数值、与基准方案对比
- 评价类：排序结果与常识/文献对比

**Step 7.2 — 对比实验**
- 与至少一个基线模型或简化方案对比
- 对比维度：准确率提升、计算速度、稳健性
- 生成对比图表（柱状图/折线图对比两项指标）

**Step 7.3 — 敏感性分析**
- 对关键参数 ±10% 扰动，观察输出变化
- 输出变化 < 20% → 模型稳健
- 输出变化 > 50% → 模型对参数过于敏感，论文中应说明

**Step 7.4 — 模型优缺点总结**
- 优点：具体到技术层面（不是"模型合理"这种）
- 缺点：诚实但不致命

### 输出
```
【验证报告】
◆ 准确性指标：[MAE=XXX, RMSE=XXX, ...]
◆ 对比实验结果：[你的模型 vs 基线模型，指标提升 XX%]
◆ 敏感性分析：[参数 P ±10%→ 输出变化 ±X%，结论：稳健/敏感]
◆ 模型评价：
  - 优点：1. ... 2. ...
  - 缺点：1. ... 2. ...
  - 改进方向：1. ... 2. ...
```

## 阶段 8：论文撰写

### 输入
- 所有前序阶段的输出报告
- 论文模板（LaTeX/Word）

### 处理步骤

**Step 8.1 — 摘要（最后写，但最终放在最前面）**
- 第 1 句：问题定位
- 第 2-5 句：每个子问题的方法+关键结果（每个结果必须有数字）
- 第 6 句：创新点
- 字数：中文 500-800 字

**Step 8.2 — 问题重述**
- 用自己的话复述题目（不是抄题）
- 格式：1.1 问题背景 → 1.2 问题描述 → 1.3 本文要解决的问题
- 加一张"研究框架图"（流程图形式）

**Step 8.3 — 模型假设与符号说明**
- 从阶段 5 的输出直接移植
- 符号表用三线表格式

**Step 8.4 — 各子问题建模与求解**
- 每个子问题独立成章
- 结构：问题分析 → 模型建立（公式）→ 算法设计（流程图）→ 结果分析（图表+数据）
- 每个问题的结果用表格+图表双重展示

**Step 8.5 — 模型评价**
- 从阶段 7 的输出直接移植
- 格式：优点（按问题分段）+ 缺点（按问题分段）+ 改进方向

**Step 8.6 — 参考文献**
- 10-15 篇，中英文混合
- 包含：方法论文（算法来源）、领域文献（题目相关背景）、教材/经典专著
- 格式：按 GB/T 7714 标准

**Step 8.7 — 附录**
- 核心代码（非全部，选关键部分）
- 中间数据表（过大则放云盘）

### 输出
- 完整的 .docx 或 .tex 论文文件

## 阶段 8.5：文档输出（比赛第 5 天最后，~1-2h）

### 输入
- 完整的 Markdown 论文（阶段 8 输出）
- `results/图表/` 中的图表文件

### 处理步骤

**Step 8.5.1 — 选择输出格式**
- CUMCM/GMCM 国赛 → 生成 .docx（官方模板为 Word）
- MCM/ICM 美赛 → 生成 .pdf（最终提交格式）

**Step 8.5.2 — .docx 生成（python-docx）**
- 从官方 .doc 模板读取样式（页边距/字体/字号/行距）
- 逐模块写入：封面→摘要→正文各章→参考文献→附录
- 公式处理：Markdown LaTeX → OMML 数学公式
- 图表嵌入：从 results/图表/ 读取图片按引用顺序插入

**Step 8.5.3 — .pdf 生成（LaTeX / Pandoc）**
- 方案A：使用 gmcmthesis.cls 模板编译 .tex
- 方案B：pandoc Markdown→PDF（快速但排版不如手写LaTeX）

**Step 8.5.4 — 质检**
- 公式渲染正确、图片清晰≥300dpi、页码连续、无乱码

### 输出
- `paper/Word/论文终稿.docx` 或 `paper/LaTeX/论文终稿.pdf`

参考文档：`skills/modeling/文档输出流程.md`

## 阶段 9：最终检查

### 检查清单

**□ 数学合理性**
- [ ] 所有公式在给定假设下逻辑自洽
- [ ] 约束条件没有遗漏
- [ ] 没有除零、log(负数) 等数学错误
- [ ] 概率值在 [0,1] 范围内
- [ ] 量纲统一一致

**□ 模型完整性**
- [ ] 每个子问题都有对应的模型和求解结果
- [ ] 子问题之间的数据流清晰（前一个问题输出→后一个问题输入）
- [ ] 没有用"显然""易证"跳过关键推导

**□ 结果可信度**
- [ ] 所有数值结果与图表一致
- [ ] 对比实验中基线模型的结果为真实计算所得（非编造）
- [ ] 没有过拟合的明显迹象（训练误差远小于验证误差）

**□ 论文完整性**
- [ ] 摘要包含所有子问题的核心结果
- [ ] 每个图表都有编号和标题
- [ ] 参考文献全部在正文中被引用
- [ ] 页码连续、目录正确
- [ ] 附录与正文交叉引用正确

**□ 创新性**
- [ ] 至少有一处不是"课本方法直接套用"
- [ ] 至少有一处"针对本题特点的改进"
- [ ] 创新点已在摘要和结语中明确标注

**□ 格式合规**
- [ ] 使用官方模板（页边距、字体、字号、行距）
- [ ] 图标题在下，表标题在上
- [ ] 公式居中，编号右对齐
- [ ] 无错别字（特别是"的/地/得"、"建立/构建"）
