# 验证报告规则

> 模型验证结果怎样组织成论文中的"验证报告"？

---

## 一、验证报告结构

```
模型验证报告
├── 1. 准确性验证
│   ├── 测试集指标（R²/RMSE/准确率）
│   └── 实际 vs 预测对比表
├── 2. 稳定性验证
│   ├── 交叉验证结果
│   └── 参数扰动测试（±10%）
├── 3. 可解释性验证
│   ├── 系数方向合理性
│   └── 变量重要性排序
├── 4. 鲁棒性验证
│   ├── 敏感性分析
│   └── 噪声测试（如果在论文中需要）
└── 5. 模型对比
    └── 与基线/替代模型的对比表
```

---

## 二、各验证维度的论文表达

### 准确性

```
"模型在测试集上的R²为0.94，RMSE为2.34，MAE为1.87。通过10折交叉验证，
R²的均值为0.92±0.03，表明模型具有稳定的预测能力。"

如果表现不佳:
"模型在测试集上的R²为0.58，RMSE为5.23。性能有限的主要原因可能是：
(1) 训练数据量不足（仅50个样本）；
(2) 特征中可能遗漏了关键影响因素。
后续研究可通过扩充数据和引入更多特征来提升性能。"
```

### 稳定性

```
"对关键参数α进行±10%的扰动测试，最优解的变化不超过3%，说明模型对参数α不敏感，
具有良好的稳定性。表X展示了不同α值下的最优解变化情况。"

如果表现不佳:
"当α扰动±10%时，最优解变化达25%，说明模型对α高度敏感。
在实际应用中，建议通过实验精确测定α值，并建立动态调整机制。"
```

### 可解释性

```
"各变量系数方向与经济学常识一致：GDP增速与投资呈正相关（β=0.34），
与失业率呈负相关（β=-0.21）。特征重要性排序中，GDP增速贡献最大（35%）。"

如果表现不佳:
"变量X的系数方向与预期相反（正相关预期，实际为负），可能原因是
(1) 存在遗漏变量偏误；(2) X与Y之间存在非线性关系，在当前线性框架下表现异常。"
```

---

## 三、验证报告输出格式

验证完成后，Agent 应输出：

```
【模型验证报告】
模型: [名称]
执行时间: [日期]

① 准确性:
  指标: [R²=0.XX, RMSE=0.XX, MAE=0.XX]
  评价: [良好/一般/需改进]
  论文表达: [...]

② 稳定性:
  交叉验证: [均值±标准差]
  参数扰动: [最大变化%]
  评价: [稳定/敏感]
  论文表达: [...]

③ 可解释性:
  系数方向: [一致/部分异常]
  关键因素: [TOP 3 特征]
  论文表达: [...]

④ 鲁棒性:
  敏感性: [参数影响评估]
  论文表达: [...]

⑤ 综合结论:
  [模型是否通过验证，是否可以进入论文撰写阶段]
```
