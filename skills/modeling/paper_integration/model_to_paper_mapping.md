#### GM(1,1) — 灰色预测

| 章节 | 内容 | 来源 |

## 通用结构模板（所有模型适用）

```
一、摘要           ← 所有问题结果汇总
二、关键词         ← 问题类型 + 模型名称
三、问题重述       ← 题型识别输出
四、问题分析       ← 题型识别 + 问题特征
五、模型假设与符号  ← 模型知识 §4 的参数定义
六、数据预处理     ← data_processing 输出（如果用到）
七、问题1建模与求解 ← [模型建立] + [模型求解] + [结果分析]
八、问题2建模与求解 ← （同上，如果有子问题）
九、问题3建模与求解 ← （同上）
十、模型评价与推广   ← 所有模型的 §7-8 优缺点 + 评价指标
十一、参考文献       ← 模型知识 §12 GitHub来源 + 引用文献
```
