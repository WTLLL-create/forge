# 结果→论文内容转换规则

> 数值结果怎样变成论文中的中文表达？

---

## 一、转换原则

1. **数值不能裸奔** — 每个数字都要有单位、有解释、有对比
2. **先结论后证据** — 论文写法是先说"模型表现良好"，再给 R²=0.95
3. **一个数字一句话** — 不堆砌数据，每个关键数值用独立句子解读

---

## 二、常见数值→论文表达

### 拟合/预测

| 数值 | 论文表达模板 |
|------|-------------|
| R² = 0.95 | "模型的决定系数 R² 达到 0.95，说明模型能够解释 95% 的数据变异，拟合效果良好。" |
| R² = 0.55 | "R² 为 0.55，表明模型对数据变异的解释力有限，可能遗漏了某些重要影响因素。" |
| RMSE = 0.023 | "均方根误差 (RMSE) 仅为 0.023，预测精度较高。" |
| MAPE = 8.5% | "平均绝对百分比误差 (MAPE) 为 8.5%，在可接受范围内（通常 <10% 视为良好）。" |

### 优化

| 数值 | 论文表达模板 |
|------|-------------|
| 最优值 = 9400 | "在给定资源约束下，最大利润可达 9400 元。此时资源利用率为 100%，不存在浪费。" |
| 影子价格 = 50 | "钢材的影子价格为 50 元/kg，意味着每增加 1kg 钢材供应，利润可增加约 50 元。" |
| 约束宽松 | "工时约束存在松弛，说明工时不是瓶颈资源，可适当调减工时投入。" |

### 评价

| 数值 | 论文表达模板 |
|------|-------------|
| CR = 0.03 | "一致性比率 CR=0.03（<0.1），判断矩阵通过一致性检验，权重（w=0.XX）合理可靠。" |
| 贴近度排序 | "方案 A 的贴近度最高（C=0.892），表明其综合表现最优，是最值得推荐的方案。" |

### 统计检验

| 数值 | 论文表达模板 |
|------|-------------|
| p = 0.003 | "p 值 (0.003) 远小于显著性水平 0.05，表明两组之间存在统计上显著的差异。" |
| p = 0.42 | "p 值 (0.42) 大于 0.05，不能拒绝原假设，表明两组数据间无显著差异。" |

## 三、对比类表达

| 场景 | 模板 |
|------|------|
| 模型对比 | "与 X 模型 (R²=0.72) 相比，Y 模型 (R²=0.85) 提升约 18%，在非线性拟合方面表现更优。" |
| 方案对比 | "方案 B 比方案 A 利润高 12%，但能耗增加 8%，需要在经济效益和环保之间权衡。" |
| 参数影响 | "当参数 α 从 0.1 增加到 0.3 时，最优值变化不超过 5%，说明模型对参数 α 不敏感。" |

---

## 四、异常结果处理

| 异常 | 论文处理 |
|------|----------|
| 模型效果差 | 诚实报告，分析原因（数据不足？假设不当？），讨论改进方向 |
| 结果违反直觉 | 标注"值得注意的变化"，分析可能的原因，不强行解释 |
| 与文献不一致 | 讨论差异原因（场景不同？方法不同？数据不同？），不回避 |

---

## 五、转换检查清单

- [ ] 每个关键数字都有论文表达对应
- [ ] 没有"如表所示"但没有"表X展示了..."
- [ ] 图表引用→图表存在（无悬空引用）
- [ ] 数值保留合理有效数字（3-4位）
- [ ] 所有百分比标注了基数
- [ ] 对比类表达有"提升/降低 X%"的具体数值
