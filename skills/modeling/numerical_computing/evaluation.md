## 二、测试题

### 测试 1：优化问题识别

**题目**：
> 某工厂生产 A、B 两种产品。每件 A 利润 300 元，耗材 2kg 钢材 + 3 工时；每件 B 利润 200 元，耗材 4kg 钢材 + 1 工时。现有钢材 100kg，工时 80 小时。求最大利润生产方案。

**Agent 应输出**：

```
问题类型：线性规划（优化问题）
识别关键词：最大利润、耗材、约束
数学形式：max 300x_A + 200x_B
          s.t. 2x_A + 4x_B <= 100
               3x_A + 1x_B <= 80
               x_A, x_B >= 0
推荐工具：scipy.optimize.linprog
来源仓库：SciPy
参考案例：examples/case2_linear_program.py
```

### 测试 2：拟合问题识别

**题目**：
> 某地区 2010-2025 年人口数据（万人）：[102, 106, 110, 115, 121, 127, 133, 139, 145, 152, 158, 165, 171, 178, 184, 191]。请预测 2030 年人口。

**Agent 应输出**：

```
问题类型：数据拟合/预测
识别关键词：历史数据、预测
数学形式：y ≈ a * exp(b * t) 或多项式拟合
推荐工具：scipy.optimize.curve_fit
来源仓库：SciPy
参考案例：examples/case3_exponential_fit.py
```

### 测试 3：微分方程识别

**题目**：
> 某传染病在 10000 人的封闭群体中传播。初始感染者 10 人，康复者 0 人。传染率 β=0.3，康复率 γ=0.1。请模拟未来 100 天的感染人数变化。

**Agent 应输出**：

```
问题类型：常微分方程（动力系统）
识别关键词：传播、微分方程、SIR
数学形式：dS/dt = -βSI/N, dI/dt = βSI/N - γI, dR/dt = γI
推荐工具：scipy.integrate.solve_ivp
来源仓库：SciPy
参考案例：examples/case4_sir_model.py
```
