# 模型验证方法

> 不同类型数学模型的验证方法体系。
> 核心原则：验证不是模型完成后的补充，而是建模过程的一部分。

---

## 第一部分：模型验证总流程

```
模型建立
    ↓
验证方案设计  ← 在建模时同步设计，不是建完再想
    ↓
指标选择      ← 按题型选择必选指标 + 可选指标
    ↓
实验验证      ← 准确��� + 对比 + 敏感性 三管齐下
    ↓
稳定性分析    ← 参数扰动 / 数据扰动 / 评委扰动
    ↓
结论评价      ← 模型行不行？为什么行/不行？
```

### 为什么"验证不是在最后补"

| 错误做法 | 正确做法 |
|----------|----------|
| 建完模型，随便算个误差 | 建模时就留出测试集，不偷看 |
| 只用训练集精度 | 训练集/验证集/测试集严格分离 |
| 只和空气比（没基线） | 至少和 1 个简单基线对比 |

## 第二部分：预测模型验证

### 核心指标

| 指标 | 公式 | 适用场景 | 论文中的解读 |
|------|------|----------|-------------|
| MAE | Σ\|ŷ-y\|/n | 需要与目标同单位 | "平均误差 X 个单位" |
| RMSE | √(Σ(ŷ-y)²/n) | 对大误差更敏感 | "RMSE > MAE 说明存在较大偏差的预测点" |
| MAPE | Σ\|(ŷ-y)/y\|/n ×100% | y>0 时，给出百分比 | "平均误差率为 X%" |
| R² | 1 - SS_res/SS_tot | 线性模型解释力 | "模型解释了 X% 的目标变量变异" |

### 验证方法

| 方法 | 操作 | 何时使用 |
|------|------|----------|
| 留出法 | 70% 训练 / 30% 测试 | 数据量 >1000 |
| K 折交叉验证 | K=5 或 K=10 | 数据量 200-1000 |
| 滚动验证 | 固定窗口，逐日/月滚动预测 | **时序预测专用**（不可随机切分！） |

### 检查清单

```
□ 训练集/测试集是否按时间切分（时序问题守则）
□ MAE + RMSE 至少汇报两个
□ 绘��了 ŷ vs y 散点图（点在 y=x 线附近=无系统性偏差）
□ 与至少 1 个基线模型对比（如简单平均、一次预报）
□ 残差是否近似正态？
```

## 第三部分：优化模型验证

### 验证维度

```
         优化模型验证
             │
    ┌────────┼────────┐
    ↓        ↓        ↓
 可行性   最优性    稳定性
```

### 可行性验证

**问题**：求出的解满足所有约束吗？

```
检查方法：
  将解代入每条约束，验证不等式是否成立
  如果任何一条不成立 → 模型有 Bug，必须修

论文中：
  "经验证，本文求得的最优解满足全部 N 条约束条��"
```

### 最优性验证

**问题**：这个解真的是"最优"的吗？

```
方法 1（精确算法）：给出 gap = (UB-LB)/UB
  gap < 1% → 近最优
  gap < 5% → 可接受

方法 2（启发式算法）：
  - 多次运行取统计（最好/平均/最差）
  - 与简单启发式对比（如贪心 → 证明你的算法有提升）
  - 与精确解对比（小规模实例 → 证明接近最优）

论文中：
  "随机运行 20 次，最优解 X，平均解 Y，标准差 Z"
  "对比贪心算法（得分 W），本文遗传算法得分 X，提升 (X-W)/W%"
```

### 稳定性验证

**问题**：参数变一点，结果变很多吗？

```
方法：敏感性分析
  - 选择 2-3 个关键参数
  - ±10% 扰动
  - 观察目标函数值变化
  - 输出变化 < 5% → 稳健
  - 输出变化 > 20% → 敏感，论文中说明

论文中：
  "对权重 α 在 [0.36, 0.44] 扰动，
   最优解波动仅 ±3%，模型具有较高稳健性"
```

### 检查清单

```
□ 约束条件逐条验证通过
□ 有收敛曲线（启发式算法）
□ 与至少 1 个基准方案对比
□ 有敏感性分析（2-3 个参数）
□ 多目标问题有 Pareto 前沿图
```

## 第四部分：评价模型验证

### 权重合理性验证

```
方法 1：多种权重方案对比
  方案 A：专家 AHP 权重 → 排名结果
  方案 B：熵权法客观权重 → 排名结果
  方案 C：等权 → 排名结果
  → 三种方案结果的 Kendall τ
  → τ > 0.8 说明权重选择对排名影响不大（稳健）

方法 2：敏感性分析
  每个权重 ±10% → 重新计算排名 → Top-K 变化率
  → 变化率 < 30% → 排名稳健
```

### 一致性检验

| 方法 | 适��范围 | 计算方式 | 通过标准 |
|------|----------|----------|:---:|
| AHP 一致性 | AHP 权重 | CR = CI/RI | CR < 0.1 |
| Kendall τ | 两组排名对比 | τ = (P-Q)/[n(n-1)/2] | τ > 0.7 高度一致 |
| Shapley 值 | 多人评分 | 每位评委的边际贡献 | 接近 1/M 为理想 |

### 检查清单

```
□ AHP 权重通过一致性检验（CR < 0.1）
□ 多种权重方案的排名做 Kendall τ 对比
□ 权重敏感性分析（±10% 扰动）
□ Shapley 值分析（多人评分场景）
□ 排名结果与常识/文献一致性的讨论
```

## 第五部分：分类模型验证

### 核心指标

| 指标 | 公式 | 何时必用 |
|------|------|----------|
| Accuracy | (TP+TN)/(TP+TN+FP+FN) | 类别平衡时 |
| Precision | TP/(TP+FP) | 关注"误报"代价 |
| Recall | TP/(TP+FN) | 关注"漏报"代价 |
| F1 | 2×P×R/(P+R) | **类别不平衡时必用！** |
| ROC-AUC | AUC 面积 | 评估整体区分能力 |

### 验证方法

```
混淆矩阵：
  ┌──────────┬──────┬──────┐
  │          │ 预测正│ 预测负│
  ├──────────┼──────┼──────┤
  │ 实际正   │  TP  │  FN  │
  │ 实际负   │  FP  │  TN  │
  └──────────┴──────┴──────┘
  → 必须可视化！热力图最优。

ROC 曲线：
  横轴 FPR，纵轴 TPR
  AUC > 0.8 → 良好区分能力

K 折交叉验证（K=5/10）：
  每折计算指标 → 报告均值和标准差
  "5 折交叉验证 Accuracy=0.85±0.03"
```

### 检查清单

```
□ 有混淆矩阵（热力图可视化）
□ 不平衡数据必须汇报 F1（不是只用 Accuracy）
□ 有 ROC-AUC（二分类）
□ 讨论了误报和漏报的代价
□ 有多分类指标（macro/micro F1）
```

## 第六部分：机器学习模型验证规范

### 数据分离铁律

```
                   原始数据
                      │
          ┌───────────┼───────────┐
          ↓           ↓           ↓
      训练集 70%   验证集 15%   测试集 15%
     （调模型）   （调超参）   （最终评估，只用一次！）

⚠️ 时序数据：按时间切分，不能随机！
   训练=历史，验证=中期，测试=最近
```

### 防止过拟合的验证

```
现象：训练集误差 << 测试集误差

检测方法：
  画训练/验证 loss 曲线
  - 两者都下降 → 正常
  - 训练下降、验证上升 → 过拟合！
  - 两者都不动 → 欠拟合

处理：
  过拟合 → 增加正则化/减少特征/更多数据/早停
  欠拟合 → 增加特征/��低正则化/更复杂模型
```

### 论文中如何描述

```
"本文将数据集按 7:1.5:1.5 划分为训练集、验证集和测试集。
 训练集用于模型参数学习，验证集用于超参数调优，
 测试集仅用于最终评估，不与训练和调优过程有任何数据泄露。

 为防止过拟合，采用早停策略（patience=10），
 并监控训练集与验证集的误差曲线。
 最终在测试集上汇报 MAE=0.23, RMSE=0.31。"
```

### 检查清单

```
□ 三集分离（训练/验证/测试）
□ 时序数据按时间切分（不可随机）
□ 训练/验证 loss 曲线可判断无过拟合
□ 测试集仅使用一次
□ 论文中描述了数据划分方式
```

## 第七部分：论文验证章节模板

### 通用结构

```
第 X 章 模型验证与分析

X.1 验证方案设计
  说明验证的目标和维度

X.2 准确性验证
  核心指标：[MAE=0.23, RMSE=0.31]
  [表：指标汇总]
  [图：预测值 vs 真实值]
  [文字：3-4 句解读]

X.3 对比实验
  [表：本文方法 vs 基线方法 的指标对比]
  [图：对比柱状图]
  [文字：提升了多少，为什么]

X.4 稳定性分析（敏感性分析）
  [表：参数扰动→输出变化]
  [图：敏感性分析图]
  [文字：稳健性结论]

X.5 验证结论
  综合 X.2-X.4，本文模型在 [准确性] [对比] [稳定性]
  三个维度上 [表现优秀/基本合格]。
  主要优势：[1 句话]。主要局限：[1 句话]。
```

### 按题型的关键验证章节差异

| 题型 | 验证章节的特色段落 |
|------|------|
| 预测 | X.2 误差指标表 + 预测值vs真实值散点图 |
| 优化 | X.2 收敛曲线 + 与基准方案对比 + X.3 敏感性分析 |
| 评价 | X.2 排序表 + Kendall τ + X.3 权重敏感性 |
| 分类 | X.2 混淆矩阵热力图 + ROC-AUC + X.3 F1 对比 |

## 第八部分：检查清单

```
模型验证完成前自检：

□ 基础验证
  □ 每个子问题至少有一种验证方式
  □ 预测类：MAE+RMSE 两个指标都汇报了
  □ 分类类：不平衡数据用 F1 而非 Accuracy
  □ 评价类：有敏感性分析

□ 对比实验
  □ 至少与 1 个基线方案对比
  □ 对比结果有表格+图表
  □ 提升数据有百分比计算

□ 稳定性
  □ 关键参数做了敏感性分析（±10%）
  □ 分析结果有文字解读（稳健/敏感+原因）

□ 图表
  □ 验证结果有可视化（散点图/热力图/收敛曲线）
  □ 图表有编号和标题
  □ 每张图配 2-3 句解读

□ 防过拟合
  □ 训练/验证/测试三集分离
  □ 时序数据按时间切分
  □ 训练/验证 loss 曲线可判断状态

□ 论文描述
  □ 数据划分方式有描述
  □ 每个指标的含义有简短解释
  □ 验证结论有优缺点总结
```

## 五、多模型对比验证 (Stage 20.5 新增)

### 适用场景

当用到多模型竞争/分而治之架构时, 需要统一框架对比 N 个模型。

### 标准流程

```
□ 1. 确定统一验证集 (所有模型共用同一测试集)
□ 2. 确定统一指标 (RMSE, MAE, R², MAPE)
□ 3. 批量运行 (参考 strategy_planner/experiment_planner.md)
□ 4. 生成对比表
     | 模型 | RMSE | MAE | R² | 排名 | 训练时间 | 优势 | 劣势 |
     |------|------|-----|----|------|---------|------|------|
     | ARIMA | 2.34 | 1.81 | 0.82 | 3 | 5s | 趋势合理 | 非线性差 |
     | XGBoost | 1.92 | 1.45 | 0.91 | 1 | 120s | 精度最高 | 可解释性差 |
     | LSTM | 2.15 | 1.62 | 0.88 | 2 | 600s | 时序强 | 训练慢 |
□ 5. 分析差异原因
     - 为什么A优于B？(模型特性 vs 数据特征)
     - 哪些场景下各模型有优势？
     - 差异性本身就是论文的"思考深度"
□ 6. 选择或集成
     - Top-1 单模型: 选综合最优
     - Ensemble: architecture_patterns/ensemble_stacking.md
```

### 论文表达

"为验证模型有效性，建立了统一的多模型对比框架。从预测精度(RMSE/MAE/R²)、计算效率、可解释性四个维度对四种候选模型进行了系统对比。结果表明，XGBoost在精度维度最优，但LSTM在捕捉长期趋势方面更稳定。基于此，采用XGBoost作为主模型，同时保留LSTM结果作为参考。"
