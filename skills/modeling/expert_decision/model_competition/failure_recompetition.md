# 失败重竞争（Failure Recompetition）

> 模型失败后不是"换个模型试试"，而是"重新进入竞争流程，但带着失败诊断的信息"。
> 本文件是 Stage 27.2（诊断）+ Stage 27.3（替代规则）+ Stage 27.4（竞争引擎）的闭环铰链。

---

## 一、为什么需要重竞争

普通做法（差）：

```
ARIMA 失败 → 换 RF
RF 失败 → 换 XGBoost
XGBoost 失败 → ... → 时间耗尽
```

→ 试出来的，不是诊断出来的。论文无法解释。

专家做法：

```
ARIMA 失败 → 诊断：残差非线性（Ljung-Box p<0.01）
    ↓
进入重竞争：候选池剔除 ARIMA + 同类线性模型
    ↓
非线性候选池：RF / XGBoost / SVR / Hybrid
    ↓
重新竞争 → 输出推荐 + 论证
    ↓
论文："ARIMA 因非线性残差而失效→本文转向非线性方法
        → 在 RF/XGBoost/SVR 中竞争 → 选择 RF"
```

→ 失败=诊断信息，进入竞争=有理有据的替换。

## 二、重竞争流程

```
Step 1: 接收失败诊断报告
  来自 Stage 27.2 model_diagnosis/
  根因：[数据层/参数层/模型层/理论层]
  失败症状：[具体表现+定量]

Step 2: 失败模型标记
  - 将失败模型从候选池中剔除
  - 将"同类"模型也剔除（如果失败根因是模型类型的结构性问题）
    例：ARIMA 因非线性失败 → 剔除所有线性时序模型
    例：RF 因外推失败 → 剔除所有树模型

Step 3: 失败信息注入竞争
  失败诊断作为新的"问题特征"注入：
  例：原特征 = [Nt=100, 平稳, 单变量]
      失败信息 = [强非线性残差]
      新特征 = [Nt=100, 不平稳的时序依赖已被线性模型提取, 残差含强非线性]
      → 候选池从 [ARIMA, RF] 变为 [RF, XGBoost, LSTM残差]

Step 4: 重新竞争
  使用更新后的特征 + 缩小的候选池
  评分时：
  - 降低与"失败根因"相关的维度权重
  - 提高"失败根因对应的解决能力"的维度权重

Step 5: 输出升级方案
  A方案（原始推荐）：ARIMA → 失败原因：非线性残差
  B方案（重竞争推荐）：RF → 选择理由：自动处理非线性 + ...
  论文中呈现为"发现不足→改进→对比"的逻辑链
```

## 三、按失败类型的重竞争策略

### 类型 A：数据层失败

```
失败：右删失导致全局模型 R²=-0.26
    ↓
剔除：所有假设"观测=真实值"的模型（OLS, 标准RF, XGBoost）
    ↓
候选池：Tobit回归, 考虑删失的贝叶斯方法, 分段建模
    ↓
重竞争焦点：谁最擅长在删失数据上学习？
    ↓
论文："数据右删失意味着标准回归模型不可用。
       本文在候选方案中比较了..."
```

### 类型 B：参数层失败

```
失败：RF 训练R²=0.98, 测试R²=0.35（过拟合）
    ↓
不剔除 RF：通过降低复杂度修复（仍在同一模型框架内）
    ↓
候选池不变，但 RF 的复杂度评分下调
    ↓
重竞争：验证修复后的 RF 是否仍然是最优？
        如果降低复杂度后精度不降反升 → 维持 RF
        如果降低后精度大幅下降 → 需要更强的模型
```

### 类型 C：模型层失败

```
失败：ARIMA 残差非线性（Ljung-Box 通过但残差-拟合值图非线性）
    ↓
剔除：ARIMA + 所有线性时序模型（SARIMA, VAR, 指数平滑）
    ↓
候选池：RF+Lag, XGBoost+Lag, LSTM, Prophet
    ↓
重竞争：在非线性候选池内重新评分
    ↓
论文："ARIMA 提取了线性趋势结构（R²=0.45），
       但其残差分析揭示了显著的非线性模式（图X）。
       这意味着需要非线性模型对残差进行二次建模。
       本文比较了..."
```

### 类型 D：理论层失败

```
失败：传统问题表述下所有模型都表现不佳
    ↓
不进入常规重竞争 → 回到 Stage 26 矛盾分析
    ↓
重新审视：问题的数学表述是否合理？
        是否可以改变视角/重构/分解？
    ↓
论文："传统视角下的 [问题] 对 [某特征] 不敏感。
       本文发现，将问题重新表述为 [新视角] 后，
       原本的失败不再出现。"
```

## 四、重竞争的论文价值

重竞争不是内部流程——它本身就是论文的核心论证手段。

### 论文中的呈现

```
✗ 差（失败不说）：
  "本文选择 RF 模型。"（没说 ARIMA 试过且失败了）

✓ 好（诚实报告）：
  "初步使用 ARIMA 建模，虽然 R² 达到 0.45，
   但残差分析揭示了系统性非线性模式（图X）。
   这表明 ARIMA 仅提取了线性结构，残差信息仍可挖掘。
   
   因此，本文在 [N] 个非线性模型中进行了二次筛选：
   [候选池 + 竞争过程]。
   最终选择 RF+Lag 方案，在 ARIMA 的基础上
   将残差的解释方差提升了 60%。"

★ 优秀（诊断本身=发现）：
  "ARIMA 的残差非线性不是随机噪声——
   其模式（图X）显示，污染物浓度在特定气象条件下
   （高温+低风速）会发生非线性的光化学反应增强。
   ARIMA 的'失败'恰恰揭示了这一机制——
   它的残差就是光化学效应的信号。
   
   基于这一发现，本文设计了一种趋势-机制双层模型：
   ARIMA 提取气象驱动的线性趋势，
   非线性模型捕捉光化学驱动的非线性增强。
   消融实验（表X）证实了双层结构的必要性。"
```

**核心原则**：模型失败不是羞耻，是发现。重竞争论文的加分点在于"从失败中学习"而非"我一开始就选对了"。

## 五、重竞争与已有系统的衔接

```
模型执行
    ↓
失败 → Stage 27.2 诊断（症状→根因→ErrorLifecycle分类）
    ↓
Stage 27.3 model_substitution_rules → 预定义替代路径
    ↓
Stage 27.4（重竞争）→ 带着失败信息重新进入竞争
    ├─ 更新问题特征
    ├─ 剔除失败模型+同类
    ├─ 调整评分权重
    └─ 输出升级方案
    ↓
论文："从失败中学习→改进→验证"的完整论证链
    ↓
FailureMemory ← 记录：重竞争的触发条件、选择的替代方案、修复效果
```

## 六、最大迭代次数

```
重竞争最多 2 轮。
第 1 轮失败 → 重竞争 → 第 2 轮失败 → 不再重竞争，转为：

方案 A（失败）：[原推荐] + 失败原因分析
方案 B（重竞争1）：[替代1] + 效果
方案 C（重竞争2）：[替代2] + 效果

论文中诚实报告三次尝试的结果：
"本文尝试了三种方案，其中 [方案B] 表现最优，
原因是 [方案B 如何解决了方案A的失败原因]。
方案C 的失败进一步验证了 [某个结论]。"
```
