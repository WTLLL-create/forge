# 优化/评价/综合类模型竞争模式

---

## 一、优化类竞争模式

### 动态权重

| 维度 | 默认 | 精确求解优先 | 创新导向 |
|------|:---:|:---:|:---:|
| 约束处理能力 | 35% | 40% | 25% |
| 求解可靠性 | 25% | 35% | 15% |
| 复杂度/效率 | 20% | 15% | 20% |
| 创新空间 | 20% | 10% | 40% |

**触发条件**：能精确求解→"精确求解优先"列。只能启发式→"创新导向"列。

### 模式 O-A：精确 vs 启发式竞争

**典型候选**：LP/MIP vs GA vs PSO vs NSGA-II

**竞争铁律**：

```
第一回合：先问"哪个候选能保证最优性？"
  LP → ✅ 全局最优保证
  MIP(规模<100) → ✅ 分支定界保证
  MIP(规模>100) → ⚠️ 报告最优性间隙
  GA/PSO → ❌ 不能保证

如果精确方法可用 → 直接胜出，无需继续竞争
如果不可用 → 进入第二回合

第二回合：启发式之间的竞争
  编码效率、收敛性、可复现性
  论文中必须解释"为什么不用精确方法"
```

### 模式 O-B：多目标竞争

**典型候选**：加权→单目标 vs NSGA-II vs MOEA/D

**竞争焦点**：

| 维度 | 加权单目标 | NSGA-II | MOEA/D |
|------|:---:|:---:|:---:|
| 权重已知 | ★★★ | ★ | ★ |
| 权重未知 | ★(需论证) | ★★★ | ★★★ |
| 2目标 | ★ | ★★★ | ★★ |
| 3+目标 | ✗ | ★★ | ★★★ |
| 论文表达空间 | ★ | ★★★ | ★★ |

**关键判断**：如果题目给了明确权重 → 加权法（简单、直接）。如果权重未知 → Pareto 方法（揭示权衡本身=加分）。

### 论文表达模板

```
针对 [问题] 的优化需求，本文首先分析了问题的数学结构：

[检查1：线性？] → [结论]
[检查2：整数变量？] → [结论]
[检查3：目标数+冲突性？] → [结论]

基于此分析，候选求解方案包括：
[A/B/C]

精确方法（[A]）在此问题上的可行性分析：
[可→直接用 / 不可→原因（规模/非线性/多目标）]

因此，本文选择 [方案X]。其核心优势在于 [与问题特征的匹配]。
```

## 二、评价类竞争模式

### 动态权重

| 维度 | 权重 | 说明 |
|------|:---:|------|
| 指标体系合理性 | 35% | 不是权重，不是算法——指标体系决定上限 |
| 赋权方法匹配度 | 20% | 与数据特征/专家资源的匹配 |
| 结果稳健性 | 25% | 敏感性分析是必须的 |
| 可解释性 | 20% | 评价结果必须有现实意义 |

### 竞争模式

**候选池**：AHP+TOPSIS / 熵权+TOPSIS / CRITIC+TOPSIS / 模糊综合评价 / 灰色关联

**竞争核心**：评价类竞争的关键不在算法，在指标体系+赋权策略。

```
第一层竞争：指标体系
  谁的指标体系更有层次？更有依据？
  → 目标-准则-指标三层结构 > 指标平铺

第二层竞争：赋权合理性
  有专家 → AHP（需CR<0.1）
  无专家 + 指标变异大 → 熵权
  无专家 + 指标冲突 → CRITIC
  混合 → AHP+熵权组合

第三层竞争：结果稳健性
  谁的敏感性分析更充分？
  → 三维敏感性（权重+方法+指标）> 二维 > 一维 > 无
```

### 论文表达模板

```
本文从 [N] 个维度建立了 [三层/二层] 评价指标体系（表X）。
在赋权策略上，比较了 [方法A] 和 [方法B]：
- [A] 的 [优势+劣势]
- [B] 的 [优势+劣势]

最终采用 [组合策略]，因为 [与数据特征和问题需求的匹配关系]。

三维敏感性分析（表Y）验证了评价结果的稳健性。
```

## 三、综合问题竞争模式

### 动态权重

| 维度 | 权重 | 说明 |
|------|:---:|------|
| 跨Q一致性 | 30% | 多个子问题的模型是否一致 |
| 依赖处理 | 25% | 跨Q的数据/模型依赖是否正确处理 |
| 增量建模 | 25% | 是否在前一Q基础上增量而非重做 |
| 整体创新 | 20% | 组合方案的整体创新性 |

### 竞争模式

**候选**：不是单个模型，而是"方案架构"（pipeline/architecture）。

```
方案A：独立求解
  各Q独立建模，互不干扰
  ✓ 简单、稳健
  ✗ 割裂、不统一

方案B：增量构建
  在Q1基础上增量修改得Q2,Q3
  ✓ 一致性强，论证链清晰
  ✗ Q1的选择决定后面一切

方案C：统一框架
  所有Q共享同一框架，参数按Q调整
  ✓ 最一致
  ✗ 框架设计复杂，可能过设计
```

### 论文表达模板

```
本题包含 [N] 个子问题，它们之间存在 [依赖关系描述]。
本文比较了三种求解架构：[方案A/B/C]。
权衡 [一致性/灵活性/复杂度] 后，选择 [方案X]。
[方案X]的核心策略是 [增量/统一/分层]，使得 [具体优势]。
```
