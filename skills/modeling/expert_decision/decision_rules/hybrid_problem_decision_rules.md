# 综合问题专家决策规则（Hybrid Problem Decision Rules）

> 大多数国赛题目不是单一的预测/优化/评价，而是多个子问题组成的综合体。
> 专家的核心能力不在于解单个子问题，而在于：识别依赖关系 → 编排求解顺序 → 保持模型一致性 → 增量构建。

---

## 规则总览

```
输入：包含多个子问题的题目
    ↓
第一关：子问题类型判定（逐Q判定题型，调用对应决策规则）
    ↓
第二关：依赖关系分析（哪个Q依赖哪个Q的输出？）
    ↓
第三关：求解顺序优化（有向无环图→拓扑排序）
    ↓
第四关：模型一致性检查（跨Q的假设/符号/数据必须一致）
    ↓
第五关：增量建模策略（尽量在前一Q基础上修改，而非完全重建）
    ↓
输出：综合求解方案 + 跨Q论文表达
```

---

## 规则 H-1：子问题类型判定与分解

### 操作流程

```
Step 1: 逐个子问题（Q1/Q2/Q3/Q4）独立判定题型
  使用 数学建模题型识别.md 的标准流程
  → Q1: [类型A]，Q2: [类型B]，Q3: [类型C]，Q4: [类型D]

Step 2: 标注每个Q的输入和输出
  输入：依赖哪些数据？依赖哪个前序Q的结果？
  输出：产出什么？（数值/排序/方案/分析）

Step 3: 识别Q之间的共同基础
  是否共享同一套数据？
  是否有共同的假设？
  是否可以用同一个模型家族？
```

### 常见组合模式

| 组合模式 | Q1→Q2→Q3→Q4 典型链路 | 经典题目 |
|----------|------|------|
| 数据处理→建模→分析 | Q1(数据清洗)→Q2(建模)→Q3(改进)→Q4(建议) | 2021B空气质量 |
| 预测→优化 | Q1(预测未来)→Q2(基于预测优化) | 2024B生产过程 |
| 评价→优化 | Q1(评价现状)→Q2(基于评价优化) | 2017B拍照赚钱 |
| 机理→数据 | Q1(建立机理模型)→Q2(数据校正)→Q3(优化) | 2019A高压油管 |
| 分类→预测 | Q1(分类识别场景)→Q2(分场景预测) | 2022C古代玻璃 |

## 规则 H-2：子问题依赖关系分析

### 依赖类型

```
类型A：数据依赖
  Q2的计算需要Q1的输出作为输入
  例：Q1预测了未来排放量→Q2以排放量为约束进行优化

类型B：模型依赖
  Q2在Q1的模型基础上修改/扩展
  例：Q1建立了基础传热模型→Q2在模型中增加了新的材料层

类型C：发现依赖
  Q1的数据分析发现了某个规律→Q2围绕这个规律展开
  例：Q1发现右删失→Q2设计处理右删失的模型

类型D：独立
  Q1和Q2无依赖关系，可并行处理
```

### 依赖图构建

```
画出Q之间的有向无环图（DAG）：
  Q1 → Q2 → Q4
    ↘ Q3 ↗

拓扑排序确定求解顺序：
  Q1(最先) → Q2和Q3(可并行) → Q4(最后，依赖Q2和Q3)
```

### 论文表达

```
本题包含四个子问题，它们之间存在递进依赖关系：
- Q1建立 [基础分析]，其结论 [发现X] 是Q2和Q3的输入
- Q2在Q1的 [结论] 基础上，进一步 [扩展]  
- Q3从 [另一角度] 补充了Q2的分析
- Q4整合Q2和Q3的结果，形成 [最终方案]

因此，本文按 Q1→Q2/Q3→Q4 的顺序求解，
并在每步中明确标注前后依赖关系。
```

## 规则 H-3：模型一致性与增量建模

### 模型一致性检查（跨Q）

```
□ 符号一致：同一个物理量在所有Q中使用相同的符号
  （不能Q1用x表示产量，Q2用y表示产量）

□ 假设一致：Q2的假设不能与Q1的假设矛盾
  （不能Q1假设"排放与功率线性相关"，Q2又用非线性模型）

□ 数据一致：所有Q使用同一版本的清洗后数据

□ 量纲一致：Q1和Q2中的同一个量必须有相同的单位
```

### 增量建模策略

```
原则：让后面的Q在前面的Q基础上「增量修改」，而非「完全重建」

❌ 差的做法：
   Q1: 线性回归模型
   Q2: 全新随机森林模型（与Q1完全不同）
   Q3: 又是另一个全新模型
   → 三个模型毫无关系，显得割裂

✅ 好的做法：
   Q1: 线性模型（作为基线）
   Q2: 在Q1的线性模型上增加非线性项（对比改进效果）
   Q3: 在Q2的基础上增加时间依赖特征（进一步改进）
   → 三个模型构成一条清晰的改进链路
```

### 论文表达

```
Q1建立的 [基础模型] 为全文奠定了分析框架。
在此基础上，各后续问题的建模遵循增量原则：

Q2发现，Q1的线性假设在 [条件] 下不成立（证据：[定量]）。
因此，Q2在Q1的模型结构上增加了 [非线性项]，
使得 [指标] 从 [A] 改善至 [B]。

Q3进一步发现，[因素X] 对 [目标] 有显著影响但未被Q1和Q2纳入。
因此，Q3在Q2模型基础上增加了 [因素X的数学表示]。

三个模型的递进关系为：
线性基线（Q1）→ 非线性扩展（Q2）→ 多因素完善（Q3），
每一步的改进都有明确的动机（矛盾驱动）和定量验证（消融对比）。
```

## 规则 H-4：综合问题的论文组织策略

### 章节结构

```
§1 问题重述（所有Q的统一背景）

§2 全局分析
  - 全题的数据审计（所有Q共享的数据质量分析）
  - 子问题依赖关系图
  - 全局符号表（所有Q的统一符号定义）

§3 Q1 建模与求解
  - [Q1的标准结构]
  - 结尾明确标注："Q1的输出 [具体内容] 将作为Q2的 [输入/约束]"

§4 Q2 建模与求解
  - 开头明确标注："在Q1建立的 [基础] 上，Q2进一步 [方向]"
  - [Q2的标准结构]

§5 Q3 建模与求解
  - 同上

§6 Q4 综合分析与建议
  - 整合所有Q的结果
  - 综合建议

§7 模型评价与推广
  - 对整体方案的评价（不是逐Q评价）
```

### 关键过渡句

| Q之间关系 | 过渡句模板 |
|-----------|-----------|
| 数据依赖 | "Q1的输出 [具体] 构成了Q2的输入约束——Q2的目标是在Q1给出的 [框架/范围] 内寻找最优解" |
| 模型扩展 | "Q1的 [模型] 揭示了 [基本规律]，但它在 [方面] 做了简化（假设 [HX]）。Q2放宽了这一假设，考虑了 [实际情况]" |
| 发现驱动 | "Q1的数据分析发现 [反直觉/意外的规律]。这一发现构成了Q2的核心动机——为什么需要 [新方法]" |
| 互补视角 | "Q2从 [角度A] 研究，Q3从 [角度B] 研究。两者分别揭示了 [方面A] 和 [方面B]，共同构成了对 [问题] 的完整理解" |

## 规则 H-5：综合问题的常见陷阱

| 陷阱 | 表现 | 修复 |
|------|------|------|
| **独立王国** | 每个Q各自为政，模型/假设/符号不统一 | 建立全局符号表，强制一致性检查 |
| **跳跃依赖** | Q3的结论实际上需要Q1的输出，但论文中没说 | 画出DAG，每一条边都要在论文中明确标注 |
| **重复工作** | Q2和Q3做了几乎相同的分析 | 检查是否可以在Q1中统一处理 |
| **线性思维** | 论文按Q照搬题目顺序，没有任何交叉引用 | 每个Q的结尾必须有"对后续Q的影响" |
| **假设飘移** | Q1假设A，Q2暗含非A，但没说明 | 建立跨Q假设冲突检测 |

### 假设冲突检测

```
跨Q一致性自检：
□ Q1的假设清单 vs Q2的假设清单 → 是否有直接矛盾？
□ Q1的模型输出格式 vs Q2的模型输入格式 → 是否直接兼容？
□ Q1中定义的符号 vs Q2中同一符号的含义 → 是否一致？
□ Q1的数据范围 vs Q2使用的数据子集 → 是否一致？
```
