# 预测类专家决策规则（Prediction Decision Rules）

> 从「预测问题→选模型」升级为「问题特征→决策→模型」。
> 每条规则定义一个决策场景，包含完整的判断链路和论文表达。

---

## 规则总览

```
输入：预测类题目 + 数据
    ↓
第一关：数据规模判定 → 决定模型复杂度上限
    ↓
第二关：时序特性判定 → 决定是否需要时序模型
    ↓
第三关：关系形态判定 → 决定线性/非线性
    ↓
第四关：特殊需求判定 → 决定是否需要外推/解释性/实时性
    ↓
输出：推荐模型 + 备选模型 + 不推荐模型 + 论文表达
```

---

## 规则 P-1：小样本预测（N < 100）

### 场景

数据量极少，无法支撑复杂模型的训练。常见于年度统计、稀有事件预测。

### 输入特征

| 特征 | 判定方法 | 阈值 |
|------|----------|:---:|
| 样本量 N | 直接统计 | N < 30（极） / 30-100（小） |
| 趋势性 | 目视 + 差分平稳性 | 明显趋势/波动为主/平稳 |
| 是否有领域知识 | 题目是否给出物理/经济约束 | 有/无 |

### 专家判断

```
N < 30（极小样本）：
  机器学习不可用（样本量 < 特征数 × 10 的风险极高）
  → 必须依赖强假设模型或领域知识

30 < N < 100（小样本）：
  简单模型可用，复杂模型（RF/NN）极易过拟合
  → 选择参数少、结构简单的模型
```

### 推荐方案

| 条件组合 | 推荐模型 | 理由 |
|----------|----------|------|
| 有趋势 + 无周期 | GM(1,1) 灰色预测 | 仅需4个数据点，自建微分方程捕捉趋势 |
| 有明显周期 | Holt-Winters 指数平滑 | 三参数分解趋势+季节性，参数少 |
| 有明显因果关系 | 简单线性回归 + 先验约束 | 自由度低，可通过先验注入领域知识 |
| 完全无规律 | 贝叶斯方法 + 强先验 | 用先验弥补数据不足 |
| N>50 且特征<3 | 高斯过程回归（GPR） | 非参数但需要至少中等样本 |

### 不推荐方案

| 模型 | 为什么不适合 |
|------|-------------|
| 随机森林 | Bootstrap采样在N<100时不稳定，OOB误差方差大 |
| XGBoost/LightGBM | 需要≥500样本才能发挥boosting优势 |
| LSTM/神经网络 | 参数数远超样本数，过拟合不可避免 |
| ARIMA | 需要≥50个时间点才能可靠估计ACF/PACF |

### 风险

- **最大风险**：过拟合——模型"记忆"了数据而非学习规律
- **缓解**：交叉验证时必须用LOOCV（留一法），不能用k-fold
- **论文必须做的**：报告训练集和验证集的指标差异，差异>15%=过拟合警告

### 真实案例

**2022 C题 古代玻璃成分分析**：样本量仅~60，特征维度高（~20种化学成分）。
- 选择：先PCA降维到3维（保留85%方差），再用LDA分类
- 放弃：RF（N=60→bootstrap不稳定，每次运行结果差异大）
- 论文表达："鉴于样本量有限，本文选择参数效率最高的线性方法，
  通过先验知识（玻璃类型的化学成分约束）指导特征选择"

### 论文表达方式

```
本题的数据规模（N=[X]）限制了可选模型的复杂度。
维度分析表明：
- 标准RF需要估计 [~N_trees×max_depth] 个有效参数，远超N/10的安全边界
- GM(1,1)仅需估计 [2] 个参数（发展系数a和灰作用量b），远低于安全边界

因此，在数据效率与模型表达力之间，本文优先选择数据效率高的方法。
具体而言，采用 [模型] [简述模型]，并通过 [验证策略] 控制过拟合风险。
```

## 规则 P-2：非线性预测（|ρ|max < 0.5）

### 场景

特征与目标之间线性关系弱（Spearman相关系数普遍<0.5），且样本量足够支撑稍复杂的模型。

### 输入特征

| 特征 | 判定方法 | 阈值 |
|------|----------|:---:|
| 线性相关强度 | 各特征与目标的 Spearman \|ρ\| | \|ρ\|max < 0.5 |
| 样本量 N | 直接统计 | N ≥ 200 |
| 特征数 p | 直接统计 | p 任意 |
| 需要解释 | 题目是否要求分析"影响因素" | 是/否 |

### 专家判断

```
非线性 ≠ 必须用复杂模型。
中等非线性 → RF/Gradient Boosting
强非线性 + 高维 → XGBoost
强非线性 + 需要解释 → RF + SHAP
强非线性 + 小样本 → 核方法（SVR/GPR）
```

### 推荐方案

| 条件组合 | 推荐模型 | 理由 |
|----------|----------|------|
| N>500, p任意, 不需解释 | XGBoost/LightGBM | 表格数据的王者，自动处理缺失值和特征交互 |
| N>200, p>10, 需要解释 | RandomForest + SHAP | 树模型可解释性强，SHAP提供归因 |
| N>200, p<10, 需要解释 | GAM（广义加性模型） | 每个特征的非线性效应独立可见 |
| N<200, p>N/3 | SVR（RBF核）+ PCA降维 | 核方法在小样本高维场景下表现好 |
| N>1000, 序列数据 | LSTM | 如果有时序依赖且非线性强 |

### 不推荐方案

| 模型 | 为什么不适合 |
|------|-------------|
| 线性回归及变体（Ridge/Lasso） | 线性假设从根本上不成立 |
| 单棵决策树 | RF的袋外估计更稳定，单棵树方差大 |
| KNN | 高维下距离度量失效（维度灾难） |

### 真实案例

**2021 B题 空气质量预测**：23个气象/污染特征，仅3个与PM2.5的|ρ|>0.7。
- 选择：RF + 时间滞后特征
- 论文表达："Spearman分析显示73个特征（87%）与目标呈非线性关系，
  这意味着线性假设不成立。本文选择RF作为核心预测器，
  其树结构天然捕捉非线性交互，无需显式构造交互项"

### 论文表达方式

```
相关性分析（表X）揭示了特征与目标之间的非线性本质：
[Spearman |ρ|max = X，仅 X/X特征达中度以上相关]。
这表明标准线性模型（Ridge/Lasso）在此问题上受限于结构性欠拟合。

对于此类数据，基于树的集成方法具有天然优势——
无需特征变换即可拟合非线性关系。
本文在RF和XGBoost之间进行了对比选择：
[对比结果和最终选择]。

同时，通过 [验证策略] 和 [过拟合控制] 确保模型的泛化能力。
```

## 规则 P-3：时间序列预测

### 场景

数据有明确的时间维度，需要利用历史值预测未来值。

### 输入特征

| 特征 | 判定方法 | 阈值 |
|------|----------|:---:|
| 平稳性 | ADF检验 p-value | p<0.05→平稳 |
| 季节性 | ACF/PACF图 + 频谱分析 | 明显周期峰 |
| 趋势性 | Mann-Kendall检验 | p<0.05→有显著趋势 |
| 外部变量 | 是否有多个外生变量 | 是/否 |
| 样本量 | 时间点数 | Nt |

### 专家判断流程

```
时间序列是否平稳？
  ├─ 是 → 是否有明显季节性？
  │   ├─ 是 → SARIMA / Prophet
  │   └─ 否 → ARIMA / 指数平滑
  │
  └─ 否 → 差分后是否平稳？
      ├─ 是 → SARIMA(d>0) / ARIMA(d>0)
      └─ 否 → 放弃经典时序模型，转：
          ├─ 有外生变量 → 转为监督学习（RF+XGBoost+滞后特征）
          └─ 无外生变量 → 深度时序模型（LSTM），但需要Nt>500
```

### 推荐方案

| 条件组合 | 推荐模型 | 理由 |
|----------|----------|------|
| 平稳 + 单变量 + Nt>50 | ARIMA | 经典，可解释性强，p/d/q参数物理含义清晰 |
| 平稳 + 季节性 + Nt>100 | SARIMA | ARIMA的季节性扩展，适合年/月/周日周期 |
| 非平稳但可差分 + 多变量 | VAR/VECM | 多变量时序的标准武器，可分析Granger因果关系 |
| 有外生变量 + Nt>200 | ARIMAX / RF+滞后特征 | 将外生变量纳入时序框架 |
| 完全不平稳 + 无外生 + Nt>500 | LSTM | 当经典时序方法全部失效时的备选 |
| 有强先验趋势（如S型增长） | Prophet | 趋势+季节性+节假日效应分解，对缺失值鲁棒 |

### 不推荐方案

| 情况 | 为什么 |
|------|--------|
| 对非平稳序列直接ARIMA | ADF p>0.05下ARIMA残差不是白噪声，预测区间不可靠 |
| 小样本（Nt<30）用LSTM | 即使最简单的LSTM也有数千参数 |
| 使用随机划分训练/测试集 | 时序数据必须按时间切分，随机抽样=数据泄漏 |

### 关键诊断工具

```
ACF图 → 确定MA阶数q（截尾位置）
PACF图 → 确定AR阶数p（截尾位置）
ADF检验 → 确定差分阶数d
Ljung-Box检验 → 验证残差是否为白噪声（模型充分性的终极检验）
```

### 论文表达方式

```
时间序列分析的第一步是平稳性检验。
ADF检验（p=[值]）表明该序列 [平稳/不平稳]。
若平稳，则直接进入模型阶数识别：
ACF图在lag=[q]处截尾→MA阶数q=[q]
PACF图在lag=[p]处截尾→AR阶数p=[p]

若不平稳，则进行d阶差分直至ADF通过。
选定模型ARIMA([p],[d],[q])后，
通过Ljung-Box检验验证残差独立性（p=[值]>0.05→残差为白噪声✓）。
若Ljung-Box未通过，说明模型尚未充分提取时序结构，
需重新调整(p,d,q)。
```

## 规则 P-4：需要外推的预测

### 场景

题目要求预测训练数据范围之外的未来值——树模型和神经网络会系统性失败。

### 输入特征

| 特征 | 判定方法 |
|------|----------|
| 外推需求 | 题目是否要求预测训练范围之外的值 |
| 外推距离 | 近外推（训练范围的1.1-1.5倍）还是远外推（>2倍） |

### 专家判断

```
外推预测的核心矛盾：
  数据驱动模型只能「内插」，不能「外推」。
  树模型→预测值不出训练范围
  LSTM→可以外推但不可控

解决方案取决于：
  有无物理机理？
    ├─ 有 → 机理模型为主导（物理保证外推合理性）
    └─ 无 → 
        ├─ 近外推 → 线性/多项式回归（外推行为可控）
        └─ 远外推 → 灰色模型GM(1,1)（微分方程骨架，有理论可解释的外推行为）
```

### 推荐方案

| 条件组合 | 推荐模型 | 理由 |
|----------|----------|------|
| 有物理机理 | 机理模型（ODE/PDE）+ 数据校正 | 物理定律保证外推合理性 |
| 近外推（1.1-1.5倍）+ 线性趋势 | 线性回归/多项式回归 | 外推行为可预测、可解释 |
| 远外推（>2倍） | GM(1,1) 灰色预测 | 微分方程骨架，外推有理论支撑 |
| 外推+不确定性量化 | 高斯过程回归（GPR） | 外推时不确定性增长→给出置信区间变宽 |
| 绝对禁止 | RF / XGBoost / 任何树模型 | 预测值永远不会超出训练范围 |

### 真实案例

**水泥窑不同排放标准下的优化**：题目要求预测排放标准从10→5时的最优参数。
- RF代理模型：预测排放在[50, 50.1]内几乎不变（被压缩在了训练数据范围内）
- 论文发现转化为贡献："RF的外推失败不是模型的缺陷，而是右删失数据的本质特征——标准模型在删失数据上不具备外推能力。本文通过诊断这一现象，为优化策略的选择提供了关键约束"

### 论文表达方式

```
本题要求对 [训练范围外] 的情景进行预测，这对模型的外推能力提出了要求。
树模型（RF/XGBoost）本质上是训练数据空间的划分，
对超出训练范围的值只能输出最近叶节点的均值——这在外推场景下意味着
系统性偏差。

本文通过 [策略] 应对这一挑战：
[具体做法]。
为确保外推的可靠性，本文通过 [验证方法] 评估外推的合理性
（如：外推值与物理约束的一致性、外推趋势的物理可解释性）。
```

## 规则 P-5：需要高解释性的预测

### 场景

题目不仅要求预测准确，还要求分析"哪些因素最重要""为什么这样预测"。

### 输入特征

| 特征 | 判定方法 |
|------|----------|
| 解释需求 | 题目是否要求"分析影响因素""解释原因""给出建议" |

### 推荐方案

| 解释深度 | 推荐模型 | 解释能力 |
|:---:|------|------|
| 轻度（只需因素排序） | RF + 特征重要性 | 排序 + 大致权重 |
| 中度（需知每个因素贡献方向） | 线性回归 + 标准化系数 | 符号 + 量级 |
| 深度（需知每个预测的归因） | RF/XGBoost + SHAP | 逐样本归因 |
| 深度 + 非线性可视化 | GAM（广义加性模型） | 每个特征的平滑函数图 |

### 论文表达方式

```
预测精度和模型可解释性之间存在天然张力。
本文选择 [模型] + [解释工具] 的组合策略：
以 [模型] 保证预测精度，
以 [解释工具] 提供归因分析。

[解释分析]的结果（图X）验证了 [关键发现]：
[特征A] 在 [条件] 下贡献了 [X%] 的预测方差。
这一发现与 [领域知识/常识] [一致/不一致]，
[合理的解释]。
```

## 预测决策速查表

| 你想知道 | 看哪条规则 |
|----------|:---:|
| 数据太少怎么办 | P-1 |
| 关系非线性用什么 | P-2 |
| 时序数据怎么选 | P-3 |
| 要预测未来范围外的值 | P-4 |
| 评委问"为什么"怎么答 | P-5 |

| 条件 | → | 结论 |
|------|---|------|
| N<30 | → | GM(1,1)，放弃ML |
| N=30-100 + 非线性 | → | SVR/GPR |
| N>500 + 表格数据 | → | RF/XGBoost |
| 时序 + 平稳 + 单变量 | → | ARIMA |
| 时序 + 不平稳 + 多变量 | → | VAR 或 监督学习+Lag特征 |
| 需要外推 | → | 绝对不用树模型 |
| 需要解释 | → | RF+SHAP 或 GAM |
