# 评价类专家决策规则（Evaluation Decision Rules）

> 评价问题的核心不是「选什么评价方法」，而是「这个评价体系为什么合理」。
> 专家先建立评价的「指标体系」，再选择匹配的「赋权+排序」方法。

---

## 规则总览

```
输入：评价类题目
    ↓
第一关：建立指标体系（目标层→准则层→指标层）★ 最重要
    ↓
第二关：指标性质分析（正负向/量纲/相关性/数据可得性）
    ↓
第三关：赋权方法选择（主观/客观/组合）
    ↓
第四关：综合评价方法选择（TOPSIS/模糊/灰色关联/...）
    ↓
输出：完整的评价方案 + 论文表达
```

**核心原则**：指标体系是灵魂，赋权和排序只是工具。国一评价类论文的差距不在用了什么方法，而在指标体系是否有思想。

---

## 规则 E-1：指标体系建立 ★ 最关键

### 场景

题目要求对多个对象进行评价/排序/分级。第一步永远是建立指标体系。

### 专家做法 vs 普通做法

```
普通做法：
  随便选几个指标 → 熵权法赋权 → TOPSIS排序 → 结束

专家做法：
  目标层：这个评价的最终目的是什么？
    ↓
  准则层：从哪几个维度来衡量目标？
    ↓
  指标层：每个维度下有哪些可量化的具体指标？
    ↓
  逐个指标：定义 + 计算公式 + 数据来源 + 方向性
```

### 指标体系质量检查

| 检查维度 | 好 | 差 |
|----------|----|-----|
| 层级结构 | 目标→准则→指标三层清晰 | 指标平铺，没有层级 |
| 指标定义 | 每个指标有明确的计算公式 | "经济发展水平"（太模糊） |
| 数据可得 | 所有指标有数据来源 | 提了但没数据 |
| 完备性 | 覆盖了题目要求的所有评价维度 | 漏掉关键维度 |
| 独立性 | 指标间相关性<0.8 | 多个高度相关指标（冗余） |

### 论文表达

```
本文构建了 [目标] 的三级评价指标体系：
- 目标层：[评价的最终目的]
- 准则层：[维度1]、[维度2]、[维度3]
- 指标层：[N]个具体指标

指标体系的建立基于 [三个原则]：
1. [原则1——如：覆盖题目要求的所有评价维度]
2. [原则2——如：指标可量化、数据可获取]
3. [原则3——如：指标间低冗余（相关性<0.8）]

其中 [指标X1] 为正向指标（越大越好），
[指标X2] 为负向指标（越小越好）。
各指标的计算公式和数据来源见表X。
```

## 规则 E-2：赋权方法选择

### 决策树

```
有权威专家可以提供两两比较的判断吗？
  ├─ 是 → AHP（层次分析法）
  │   → 需要：≥3位专家的判断矩阵，CR一致性检验
  │
  └─ 否 → 完全依赖客观数据
      ├─ 指标间变异程度差异大？
      │   ├─ 是 → 熵权法
      │   └─ 否 → CRITIC法（考虑对比强度和冲突性）
      │
      ├─ 需要动态权重（随时间/场景变化）？
      │   └─ 是 → 变权综合评价
      │
      └─ 组合赋权：AHP（主观）+ 熵权（客观）→ 乘法/加法组合
```

### 推荐方案

| 条件 | 推荐方法 | 论文必须做的 |
|------|----------|-------------|
| 有专家判断矩阵 | AHP | 报告CR值（必须<0.1）+ 判断矩阵 |
| 纯客观数据 + 指标变异大 | 熵权法 | 解释为什么变异=信息量 |
| 纯客观 + 指标变异不大但冲突 | CRITIC法 | 报告各指标的对比强度和冲突性 |
| 主客观结合 | AHP+熵权 组合 | 解释组合方式（乘法/加法）+ 组合权重 |
| 指标重要性随时间变化 | 变权综合评价 | 定义变权函数 + 与定权对比 |

### AHP使用注意事项

- ❌ 没有报告CR值（一致性比率）→ 直接扣分
- ❌ 一人主观打分 → 评委认为不客观
- ✅ 多人打分+CR检验+CR>0.1时的调整策略

## 规则 E-3：综合评价方法选择

### 决策矩阵

| 条件 | 推荐方法 | 优势 | 局限 |
|------|----------|------|------|
| 指标均定量 + 需要排序 | TOPSIS | 几何直观（距理想解的距离） | 不处理指标相关性 |
| 有模糊/定性指标 | 模糊综合评价 | 处理"较好""一般"等模糊评价 | 隶属函数选择主观 |
| 样本量小 + 信息有限 | 灰色关联分析 | 数据少时也能用 | 只考虑曲线相似性 |
| 指标冗余度高 | PCA→TOPSIS | 去相关 + 降维 | 主成分解释困难 |
| 需要分类（非排序） | 聚类+评价 | 先分组，再组内排序 | — |

### TOPSIS 标准流程检查

```
□ 正向化：所有指标统一为正向（极大型）
  （负向→取倒数或 max-x；中间型→|x-best|；区间型→超出区间的距离）

□ 标准化：消除量纲差异
  （z-score标准化 或 min-max归一化 或 向量规范化）

□ 加权标准化矩阵：用规则E-2确定的权重

□ 正理想解 Z⁺ = max(每列加权值)
  负理想解 Z⁻ = min(每列加权值)

□ 计算每个对象到Z⁺和Z⁻的距离 D⁺_i, D⁻_i

□ 相对贴近度 C_i = D⁻_i / (D⁺_i + D⁻_i)

□ 按C_i排序
```

### 论文表达

```
经过 [赋权方法] 确定的权重（表X），
本文使用TOPSIS方法对 [N] 个评价对象进行排序。

TOPSIS的核心思想是：最优方案应同时满足
(1) 距离正理想解最近，且
(2) 距离负理想解最远。

评价结果（表Y）显示：
排名前3的 [对象] 为 [A], [B], [C]（得分分别为 [X], [Y], [Z]）。
[分析排名差异的原因]。
```

## 规则 E-4：评价结果的敏感性分析

### 为什么必须做

评价结果依赖于：(1)权重；(2)指标选择；(3)赋权/评价方法。如果改变这些因素后排名发生剧烈变化，说明评价不可靠。

### 三种敏感性分析

| 类型 | 做法 | 论文表达 |
|------|------|----------|
| 权重敏感性 | 各权重±10%，看排名变化 | "前3名排名不变→权重选择稳健""第5名和第6名互换→两者本质接近" |
| 方法敏感性 | 换一种赋权方法（如熵权→CRITIC），看排名变化 | "两种方法下前3名一致→赋权稳健""排序差异集中在尾部→尾部对象区分度低" |
| 指标敏感性 | 删除某个指标，看排名变化 | "删除[指标X]后排名基本不变→[指标X]信息冗余""删除后变化>2名→该指标不可省略" |

### 论文表达

```
为验证评价结果的可靠性，本文进行了三维敏感性分析：
(1) 权重敏感性（表X）：各指标权重±10%扰动下，
    前3名排名不变，验证了结果的稳健性。
(2) 方法敏感性（表Y）：熵权法与CRITIC法下的排名
    Spearman相关系数=0.92（p<0.01），高度一致。
(3) 指标敏感性（表Z）：删除 [指标X] 后，
    第4-6名的排名变动>2名，表明该指标对区分中间段对象
    具有不可替代的作用。
```

## 评价决策速查表

| 条件 | → | 结论 |
|------|---|------|
| 有专家判断矩阵 | → | AHP（必须CR<0.1） |
| 纯数据 + 指标变异大 | → | 熵权+TOPSIS |
| 纯数据 + 指标冲突 | → | CRITIC+TOPSIS |
| 有模糊定性指标 | → | 模糊综合评价 |
| 指标很多（>15个）| → | 先PCA降维再评价 |
| 样本量<10 | → | 灰色关联分析 |
| 需要排名 | → | TOPSIS |
| 需要分级 | → | 聚类+评价 或 模糊综合评价 |
| 做完后 | → | 必须做三维敏感性分析 |
