# 优化类专家决策规则（Optimization Decision Rules）

> 优化问题的决策核心不是「选哪个算法」，而是「先判断问题复杂度，再选对应层次的求解方法」。
> 专家和初学者的最大区别：专家先问「这个问题的数学结构是什么」，初学者直接上算法。

---

## 规则总览

```
输入：优化类题目
    ↓
第一关：问题形式化（写出目标函数和约束的数学形式）
    ↓
第二关：复杂度判定（线性/非线性？凸/非凸？连续/离散？规模？）
    ↓
第三关：求解方法选择（精确→近似→启发式→元启发式，逐层降级）
    ↓
输出：推荐方法 + 备选方法 + 论文表达
```

**核心原则**：「能用精确算法就不用启发式」。国赛审稿人一定会问"为什么不用线性规划/整数规划？"

---

## 规则 O-1：线性规划（LP）——最高优先级检查

### 场景

目标函数和所有约束都是决策变量的线性函数，且决策变量连续。

### 判定方法

```
检查清单：
□ 目标函数：是否形如 c₁x₁ + c₂x₂ + ... + cₙxₙ？
  （没有 x₁×x₂、x²、sin(x)、log(x)等非线性项）
□ 约束条件：是否形如 a₁x₁ + a₂x₂ + ... ≤ b？
□ 决策变量：是否连续（可以取任意实数）？
□ 变量数量：是否 < 1000？（超过则需大规模LP求解器）

如果以上全部 ✓ → 线性规划，用单纯形法/内点法。
```

### 推荐方案

| 条件 | 推荐方法 | 求解器 |
|------|----------|--------|
| 任何LP | 单纯形法（小规模）/ 内点法（大规模） | scipy.optimize.linprog (method='highs') |
| 需要灵敏度分析 | 单纯形法 + 对偶变量 | 对偶变量 = 约束的影子价格 |
| 大规模（>10000变量） | 内点法 | 专用LP求解器 |

### 论文表达

```
经检验，[问题]的目标函数和约束均为决策变量的线性函数。
因此，该问题属于线性规划（LP），其标准形式为：
[公式]

本文使用 [方法] 求解。LP在此问题上具有全局最优性保证——
任何局部最优解即为全局最优解，不存在陷入局部最优的风险。

通过对偶变量分析（表X），[约束A]的影子价格为[X]，
意味着 [该约束的实际意义]。
```

### 不推荐方案

| 模型 | 为什么 |
|------|--------|
| 遗传算法/粒子群 | LP有精确求解器，GA无法保证最优性，调参复杂 |
| 神经网络 | 过度设计——用大炮打蚊子 |

### 警告

**如果在LP可解的问题上用遗传算法，论文必须明确回答"为什么不直接用线性规划？"**

## 规则 O-2：非线性规划（NLP）

### 场景

目标函数或约束包含非线性项（x²，x₁×x₂，sin，log，指数等）。

### 判定流程

```
非线性问题
    ↓
目标函数是否凸？
  ├─ 凸 + 约束凸 → 凸优化（局部最优=全局最优）
  │   → scipy.optimize.minimize (method='SLSQP'/'trust-constr')
  │
  └─ 非凸 → 多起点策略
      ├─ 变量数 < 10 → 多起点 + 梯度方法
      └─ 变量数 > 10 → 全局优化算法
          ├─ 变量数 10-50 → 差分进化（scipy.optimize.differential_evolution）
          └─ 变量数 > 50 → 粒子群/模拟退火
```

### 推荐方案

| 条件 | 推荐方法 | 理由 |
|------|----------|------|
| 凸优化 | SLSQP / trust-constr | 有全局最优性保证 |
| 非凸 + 变量<10 | 多起点 + L-BFGS-B | 多起点策略能大概率找到全局最优附近 |
| 非凸 + 变量10-50 | 差分进化 | 不依赖梯度，全局搜索能力强 |
| 非凸 + 变量50-200 | 粒子群（PSO） | 参数少，收敛快 |
| 非凸 + 变量>200 | 模拟退火 / CMA-ES | 高维下PSO容易早熟 |
| 目标函数不可微 | Nelder-Mead（单纯形法） | 不需要梯度信息 |

### 真实案例

**2018 A题 高温作业服优化**：设计作业服的各层厚度以最小化外层温度同时满足隔热要求。
- 凸性判定：传热方程+各层热阻串联→目标函数凸，约束线性→凸优化
- 论文表达："问题的凸性保证局部最优即是全局最优，因此使用梯度方法即可获得全局最优解"

## 规则 O-3：混合整数规划（MIP）

### 场景

部分决策变量必须是整数（如：人数、设备数、选址0-1变量）。

### 判定流程

```
是否有整数/0-1变量？
  ├─ 是 →
  │   ├─ 变量总数 < 100 + 约束<500 → 分支定界（精确求解）
  │   │   → scipy.optimize.milp / pulp / ortools
  │   │
  │   └─ 变量总数 > 100 → 
  │       ├─ 可以接受近似解 → 松弛+圆整 或 启发式
  │       └─ 必须精确解 → 尝试问题重构（改变变量定义减少整数变量）
  │
  └─ 否 → 规则O-2（NLP）
```

### 推荐方案

| 条件 | 推荐方法 | 理由 |
|------|----------|------|
| 小规模MIP（变量<100） | 分支定界/分支切割 | 精确解 |
| 中等MIP（变量100-1000） | Gurobi/CPLEX（如有）/ ortools CP-SAT | 商业求解器远优于开源 |
| 大规模MIP（变量>1000） | 先尝试启发式求上界，再判断是否值得精确求解 | 直接精确求解可能不可行 |

### 关键警告

**MIP是NP-hard问题**。规模每增加一倍，求解时间可能增加10-100倍。竞赛中如果规模太大：
1. 先松驰整数约束→解LP松弛→得到下界
2. 用启发式得到一个可行解→得到上界
3. 如果上下界差距<5%，可以直接用启发式解，论文中论证"最优性间隙"

## 规则 O-4：多目标优化

### 场景

存在两个或以上目标函数，且目标之间存在冲突（一个变好通常意味着另一个变差）。

### 决策流程

```
几个目标？
  ├─ 2-3个 →
  │   ├─ 权重已知（如题目给定） → 加权求和 → 转化为单目标
  │   └─ 权重未知 →
  │       ├─ 目标数=2 → Pareto前沿（NSGA-II）
  │       └─ 目标数=3 → 3D Pareto可视化 + NSGA-III
  │
  └─ >3个 →
      ├─ 先降维（PCA/相关性分析合并冗余目标）
      └─ 再按2-3目标处理
```

### 推荐方案

| 条件 | 推荐方法 | 论文核心竞争力 |
|------|----------|--------------|
| 权重已知 | 加权求和→单目标 | "给权重一个理由""权重敏感度分析" |
| 2目标，权重未知 | NSGA-II | "Pareto前沿揭示权衡关系""膝盖点分析" |
| 3目标，权重未知 | NSGA-III / MOEA/D | "3D Pareto面投影到决策者可理解的2D切面" |
| >3目标 | 降维 → NSGA-II/III | "目标合并的物理依据" |

### 论文表达

```
[问题] 中 [目标A] 和 [目标B] 存在明确的冲突关系：
[冲突的定量证据]。

本文采用Pareto方法而非加权法，原因有二：
(1) [目标A] 和 [目标B] 的量纲/尺度不同，加权法的权重设定缺乏客观依据；
(2) Pareto前沿能够完整揭示 [A] 和 [B] 之间的定量权衡关系，
    为决策者提供明确的"以多少[A]换取多少[B]"的信息。

Pareto前沿分析（图X）揭示了一个关键特征：
[发现]。
基于此，本文推荐取膝盖点方案。
```

## 规则 O-5：启发式算法选型

### 场景

问题规模太大或约束太复杂，精确算法不可行。

### 决策矩阵

| 问题特征 | GA | PSO | SA | ACO | DE |
|:---|:---:|:---:|:---:|:---:|:---:|
| 连续变量 | ★★★ | ★★★ | ★★ | ★ | ★★★ |
| 离散/组合变量 | ★★★ | ★ | ★★ | ★★★ | ★ |
| 路径/排序类 | ★★ | ★ | ★★ | ★★★ | ★ |
| 多目标 | NSGA-II | MOPSO | — | — | — |
| 变量数<20 | ★★ | ★★★ | ★★★ | ★★ | ★★★ |
| 变量数>100 | ★★ | ★★ | ★ | ★ | ★★ |
| 需要快速响应 | ★ | ★★★ | ★★ | ★ | ★★ |

### 遗传算法三段式

使用GA时，论文中必须回答三个问题：

```
1. 编码方式：决策变量如何编码为染色体？
   - 实数编码（连续变量）
   - 二进制编码（0-1变量）
   - 排列编码（排序/路径问题）
   → 编码必须保存约束可行性

2. 遗传算子：交叉和变异如何设计？
   - 交叉：模拟二进制交叉(SBX)、均匀交叉、顺序交叉
   - 变异：多项式变异、位翻转、交换变异
   → 选择必须匹配编码方式

3. 适应度函数：如何评价一个个体的优劣？
   - 目标函数值本身？
   - 目标函数+约束惩罚？
   - 多目标的Pareto支配关系？
```

## 规则 O-6：具体问题的求解器映射

### 路径/网络类问题

| 问题 | 算法 | 库 |
|------|------|-----|
| 最短路径 | Dijkstra / Floyd-Warshall | scipy.sparse.csgraph / networkx |
| TSP（小规模<20城市） | 动态规划（Held-Karp） | 自行实现 |
| TSP（中大规模） | 遗传算法 / 蚁群算法 / OR-Tools Routing | ortools |
| VRP（车辆路径） | OR-Tools Routing Solver | ortools |
| 最大流/最小费用流 | Edmonds-Karp / 单纯形网络流 | networkx |
| 最小生成树 | Kruskal / Prim | networkx |

### 资源分配/调度类

| 问题 | 算法 | 库 |
|------|------|-----|
| 线性分配 | 匈牙利算法 | scipy.optimize.linear_sum_assignment |
| 背包（小规模） | 动态规划 | 自行实现 |
| 背包（大规模） | 分支定界 + 启发式 | ortools |
| 调度（Job Shop） | CP-SAT | ortools |
| 调度（Flow Shop） | NEH启发式 + 局部搜索 | 自行实现 |

## 优化决策速查表

| 你想知道 | 看哪条规则 |
|----------|:---:|
| 能用线性规划吗 | O-1 |
| 非线性怎么解 | O-2 |
| 有整数变量怎么办 | O-3 |
| 两个目标冲突怎么处理 | O-4 |
| 大规模问题精确解不可行 | O-5 |
| 路径/调度/背包等具体问题 | O-6 |

| 条件 | → | 结论 |
|------|---|------|
| 目标+约束全部线性 | → | LP（不用想别的） |
| 有整数变量 + 规模<100 | → | 分支定界（精确解） |
| 有整数变量 + 规模>100 | → | 松弛+启发式 |
| 凸 + 可微 | → | 梯度方法 |
| 非凸 + 变量<10 | → | 多起点 |
| 非凸 + 变量10-50 | → | 差分进化 |
| 非凸 + 变量>50 | → | PSO/SA |
| 2目标 + 冲突 | → | NSGA-II Pareto |
