# 按模型类型的专项审查

> 每个模型有独特的审查要点，不是泛泛的"模型好不好"

---

## 预测模型

### GM(1,1)

| 检查项 | 方法 | 通过标准 |
|--------|------|----------|
| 级比检验 | σ(k) = x(k-1)/x(k) | 全部落在 (e^{-2/(n+1)}, e^{2/(n+1)}) 内 |
| 数据量 | 直接计数 | ≥ 4 个（否则灰色预测无意义） |
| 单调性 | 目测数据趋势 | 近似单调（无明显上下震荡） |
| 后验差比 | C = S₂/S₁ | < 0.35 优，< 0.5 合格 |
| 小误差概率 | P = P(|ε| < 0.6745S₁) | > 0.95 优，> 0.80 合格 |
| 预测期数 | 预测期数 / 数据期数 | ≤ 1/3 |

### ARIMA

| 检查项 | 方法 | 通过标准 |
|--------|------|----------|
| 平稳性 | ADF 检验 | p < 0.05（差分后） |
| 定阶合理性 | ACF/PACF 图 | 显著截尾，参数 ≤ 5 |
| 残差白噪声 | Ljung-Box 检验 | p > 0.05（残差无自相关） |
| 残差正态性 | Jarque-Bera 或 QQ图 | p > 0.05 |
| AIC/BIC | 直接计算 | 在候选模型中最小或接近最小 |

### Linear Regression

| 检查项 | 方法 | 通过标准 |
|--------|------|----------|
| R² | 回归输出 | > 0.5（太低说明线性假设不对） |
| 系数显著性 | t 检验 p 值 | < 0.05 |
| 多重共线性 | VIF | < 10 |
| 残差正态性 | Q-Q 图 / Shapiro | p > 0.05 |
| 异方差 | Breusch-Pagan | p > 0.05 |

### Random Forest

| 检查项 | 方法 | 通过标准 |
|--------|------|----------|
| OOB 误差 | 模型输出 | 合理范围内（不爆炸） |
| 特征重要性 | 模型输出 | TOP 特征与常识一致 |
| 过拟合 | 训练 vs 测试 R² 差距 | < 0.15 |
| n_estimators | 直接检查 | ≥ 50 |

## ��价模型

### AHP

| 检查项 | 方法 | 通过标准 |
|--------|------|----------|
| 判断矩阵一致性 | CR = CI/RI | < 0.1 |
| 指标数 | n | ≤ 9（否则一致性难维护） |
| 标度合理性 | 检查极值 | 无 9（极端重要）和 1/9 同时出现 |

### 熵权法

| 检查项 | 方法 | 通过标准 |
|--------|------|----------|
| 权重分布 | 检查标准差 | 不能所有权重趋近相等（说明指标无区分度） |
| 正向化处理 | 检查 | 负向指标必须转换 |
| 零值处理 | 数据扫描 | 零值会导致 ln(0) 错误 |

### TOPSIS

| 检查项 | 方法 | 通过标准 |
|--------|------|----------|
| 标准化 | 检查公式 | 向量归一化（不是 Min-Max） |
| 权重来源 | 追溯 | 明确来自 AHP 或熵权法 |
| 排名稳定性 | 改变权重 ±10% | 排名变化 < 3 位 |
| 正向/负向 | 检查 | 所有指标方向统一 |

## 优化模型

### Linear Programming

| 检查项 | 方法 | 通过标准 |
|--------|------|----------|
| 变量数 vs 约束数 | 直接计数 | 约束数 ≥ 变量数 |
| 可行性 | solver.status | success=True |
| 资源利用率 | 计算 | 关键资源利用率 > 80% 或标注瓶颈 |
| 影子价格 | 合理性检查 | 非负，有经济含义 |
| 敏感性 | 改变目标系数 ±10% | 最优解不变或变化 < 20% |

### Integer Programming

| 检查项 | 方法 | 通过标准 |
|--------|------|----------|
| 整数约束 | 检查解 | 所有整数变量确实是整数 |
| 求解间隙 | mip_gap | < 5%（否则标注未收敛） |
| 0-1 变量数量 | 计数 | < 100（否则可能超时） |

### Genetic Algorithm

| 检查项 | 方法 | 通过标准 |
|--------|------|----------|
| 收敛性 | 适应度曲线 | 平稳（最后 20% 代数的变化 < 1%） |
| 种群规模 | pop_size | ≥ 50 |
| 多次运行稳定性 | 运行 5 次 | 最优值标准差 < 均值的 5% |
| 参数说明 | 检查论文 | crossover_prob / mutation_prob 有说明 |
