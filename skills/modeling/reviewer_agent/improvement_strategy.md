# 自动修改策略

> 参考 SWE-agent 的闭环：发现问题 → 定位 → 修改 → 重验
>
> 评审发现问题后，自动映射到具体的修改动作

---

## 一、问题→动作映射表

### 模型层面

| 发现问题 | 修改动作 | 调用模块 |
|----------|----------|----------|
| 模型选择理由不足 | 补充"为什么选这个模型"的对比分析 | `models/xxx.md` §9 |
| 假设不合理 | 修改假设 + 标注"在XX条件下成立" | `models/xxx.md` §2 |
| 数学推导跳步 | 展开中间步骤 | `models/xxx.md` §4 |
| 变量未定义 | 补充符号说明表 | `models/xxx.md` §6 |

### 求解层面

| 发现问题 | 修改动作 | 调用模块 |
|----------|----------|----------|
| 参数来源不明 | 补充参数确定方法说明 | `模型求解流程.md` Step 2 |
| 求解方法不合适 | 换备选方法 | `numerical_computing/decision_rules.md` Failover |
| 结果缺少置信区间 | 增加区间估计 | `numerical_computing/scipy/stats` |

### 验证层面

| 发现问题 | 修改动作 | 调用模块 |
|----------|----------|----------|
| 缺少敏感性分析 | 增加参数±10%扰动测试 | `模型验证方法.md` |
| 缺少模型对比 | 增加与基线模型/常用模型的对比表 | `models/xxx.md` §9 |
| 验证指标不足 | 增加交叉验证/残差分析 | `模型验证方法.md` |

### 论文层面

| 发现问题 | 修改动作 | 调用模块 |
|----------|----------|----------|
| 图不足 | 按模型类型补充必需图（图依据 figure_table_rules.md；表格无固定配额，补表须符合 standards/academic_table_standard.md 与锁定 table_spec.json） | `paper_integration/figure_table_rules.md` |
| 结果解释不足 | 将数值转换为论文语言 | `paper_integration/result_to_content_rules.md` |
| 章节结构残缺 | 按 11 章模板补充 | `paper_integration/section_generation_rules.md` |
| 引用不规范 | 修正为 GB/T 7714 格式 | `paper_integration/latex_output_rules.md` §6 |

## 二、修改优先级

```
致命错误（数学错误/结果不可能）
  → 立即退回建模阶段，最高优先级
     ↓
高影响问题（验证缺失/推导跳步）
  → 下一轮必须修复
     ↓
中影响问题（图表不足/参数说明不充分）
  → 本轮修复或标注"已知局限"
     ↓
低影响问题（格式小瑕疵/措辞可优化）
  → 有精力时处理
```

---

## 三、修改闭环流程

```
Reviewer 输出审查报告
        │
        ▼
分诊：致命错误？→ 退回 S2 MODEL_SELECTION
      高影响？  → 启动 §6 Paper Agent 修改 + 重新调用对应模块
      中影响？  → §6 修改对应章节
      低影响？  → 标记为"已知局限"
        │
        ▼
修改完成 → Reviewer 再次审查（最多 3 轮）
        │
        ├── 通过(≥85) → 输出最终论文
        ├── 3轮后仍<70 → 人工介入
        └── 得分提升但未达标 → 继续第 N+1 轮
```
