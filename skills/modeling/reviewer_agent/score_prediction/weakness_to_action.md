# 弱点诊断 → 改进行动（Weakness to Action）

> 不是"这篇论文哪里不好"，而是"修改什么收益最大"。
> 输出：按优先级排序的改进行动清单，每条标注预期分数提升。

---

## 一、诊断输出格式

```
预测总分：[X] / 100
预估等级：[省一/省二/国二/国一]

各维度得分：
  D1 问题理解: [X]/15
  D2 模型合理性: [X]/25
  D3 创新性: [X]/20
  D4 求解可靠性: [X]/20
  D5 验证完整性: [X]/15
  D6 论文表达: [X]/5

改进优先级：
  P0: [最紧急] — 预期+[X]分
  P1: [次紧急] — 预期+[Y]分
  P2: [锦上添花] — 预期+[Z]分
```

| 弱点信号 | 改进行动 | 预期提升 | 对接到 |

## 三、改进优先级算法

```
优先级计算：预期提升 / 实施成本

实施成本估算：
  仅需改写文本（无新实验）：成本=1
  需要补一个新实验（如单因素敏感性）：成本=2
  需要补多个实验（如消融实验）：成本=3
  需要换模型重新求解：成本=4

P0: 收益/成本 ≥ 5  → 立即改
P1: 收益/成本 ≥ 2  → 改
P2: 收益/成本 < 2  → 时间充裕时改
```

## 四、完整诊断示例

**输入**：2026 A 题水泥窑论文初稿

**诊断输出**：

```
预测总分：78/100 — 省一水平

各维度：
  D1: 13/15 ✅ 矛盾清晰，问题分析到位
  D2: 20/25 ✅ 三层论证完整，有候选对比
  D3: 12/20 ⚠️  L2创新但无消融验证
  D4: 18/20 ✅ 求解可靠
  D5: 10/15 ⚠️  缺敏感性+鲁棒性
  D6: 5/5  ✅ 表达专业

改进优先级：
  P0: 补充消融实验 → 预期+8分（D3+D5）
      做法：去掉右删失处理→看R²退化；去掉工况分层→看目标退化
      成本：3（需要重跑实验）

  P1: 补充敏感性+鲁棒性 → 预期+5分（D5）
      做法：V1/V2/Rap ±20% 龙卷风图 + 5次随机种子运行
      成本：2

  P2: 增加统计显著性检验 → 预期+3分（D4）
      做法：RF vs XGBoost 配对t-test
      成本：1

修改后预估：78 → 89-94 — 国一水平
```
