---

## 一、总分构成

| # | 维度 | 分值 | 核心问题 |
|---|------|------|----------|
| 1 | 问题理解 | 15 | 题目拆解是否准确？关键问题是否识别？ |
| 2 | 模型合理性 | 25 | 模型选择有据？假设合理？推导严谨？ |
| 3 | 求解可靠性 | 20 | 算法合适？参数合理？结果可信？ |
| 4 | 验证完整性 | 15 | 误差分析？敏感性？稳定性？对比？ |
| 5 | 创新性 | 15 | 有改进？组合创新？新方法？ |
| 6 | 论文规范 | 10 | 结构完整？图表规范？引用正确？ |

---

## 二、各维度评分细则

### 1. 问题理解（15分）

| 分数 | 标准 |
|------|------|
| 13-15 | 问题分析透彻，本质把握准确，子问题拆解合理 |
| 10-12 | 基本理解正确，但缺少深度分析或某些约束被遗漏 |
| 7-9 | 理解有偏差，部分关键信息未注意到 |
| <7 | 明显误解题意 |

**扣分项**：遗漏题给约束条件(-3)、假设与问题矛盾(-5)、未区分问题优先级(-2)

---

### 2. 模型合理性（25分）

| 分数 | 标准 |
|------|------|
| 22-25 | 模型选择有充分理由，假设标注清晰且合理，数学推导完整 |
| 17-21 | 模型选择合理但理由不够充分，推导有小疏漏 |
| 12-16 | 模型可用但选择理由薄弱（如直接套用不说明原因） |
| <12 | 模型选择明显不匹配问题特征 |

**扣分项**：未说明为什么选这个模型(-4)、假设不合理(-5)、推导跳步(-3)、变量未定义(-3)

---

### 3. 求解可靠性（20分）

| 分数 | 标准 |
|------|------|
| 18-20 | 算法选择恰当，参数确定有依据，求解过程可复现 |
| 14-17 | 求解正确但参数设定缺乏说明，或缺少关键中间结果 |
| 10-13 | 求解有结果但过程不透明，无法判断正确性 |
| <10 | 求解方法明显错误或结果不可能 |

**扣分项**：参数来源不明(-4)、未说明求解器(-2)、结果无单位(-3)

---

### 4. 验证完整性（15分）

| 分数 | 标准 |
|------|------|
| 13-15 | 有误差分析 + 敏感性分析 + 稳定性检验 + 模型对比 |
| 10-12 | 有基本验证（误差分析）但缺少敏感性或对比 |
| 7-9 | 只有最基本的误差数值，缺少深入分析 |
| <7 | 完全没有验证或验证方法错误 |

**扣分项**：缺少敏感性分析(-5)、缺少模型对比(-4)、验证方法与模型不匹配(-3)

---

### 5. 创新性（15分）

| 分数 | 标准 |
|------|------|
| 13-15 | 有新模型/新算法/新指标体系，或对现有方法有实质性改进 |
| 10-12 | 模型组合创新（如 AHP+TOPSIS 组合），有一定新意 |
| 7-9 | 标准模型套用，无明显创新但应用得当 |
| <7 | 简单抄模型，无任何思考和改编 |

**注意**：创新不等于炫技。创新性得分低不等于论文差，但高分需要"思考过的痕迹"。

---

### 6. 论文规范（10分）

| 分数 | 标准 |
|------|------|
| 9-10 | 结构完整，三线表规范，图表编号正确，参考文献≥8篇且格式正确 |
| 7-8 | 基本规范，有小瑕疵（如图表编号跳跃、缺少某些引用） |
| 5-6 | 明显不规范（图表无编号、结构残缺） |
| <5 | 格式混乱，无法正常阅读 |

**扣分项**：图表无标题/无单位(-2)、参考文���<5篇(-2)、章节结构不完整(-3)

## 三、综合评级

| 总分 | 等级 | 处理 |
|------|------|------|
| ≥ 90 | 国一水平 | 直接通过 → S8 DONE |
| 85-89 | 国二水平 | 直接通过 → S8 DONE（有小建议） |
| 75-84 | 省一水平 | 退回 S6 修改论文（最多 3 轮） |
| 70-74 | 省二水平 | 退回 S6 修改论文（最多 3 轮） |
| 65-69 | 表达层问题 | 退回 S6 重写/优化（最多 2 轮） |
| < 65 | 模型层问题 | 退回 S2 重建模 |

> 详细策略见 `evaluation_protocol.md` 和 `canonical_state_machine.md`
