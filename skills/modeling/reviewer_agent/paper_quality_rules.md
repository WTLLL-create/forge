# 论文规范性检查

> 格式不是加分项，但不规范一定扣分

---

## 一、结构完整性

| 章节 | 必需？ | 检查要点 |
|------|--------|----------|
| 摘要 | ✅ | 700-1000字，覆盖所有子问题+关键结果 |
| 关键词 | ✅ | 3-5 个，按"领域；模型；方法"顺序 |
| 问题重述 | ✅ | 用自己的话，非抄题 |
| 问题分析 | ✅ | 含三层递进流程图 |
| 模型假设与符号 | ✅ | 三线表符号表 |
| 数据预处理 | 视情况 | 有数据必有此章 |
| 问题 X 建模求解 | ✅ | 每子问题独立一章 |
| 模型评价 | ✅ | 优缺点+推广 |
| 参考文献 | ✅ | ≥ 5 篇，GB/T 7714 |
| 附录 | 可选 | 代码/大数据表 |

---

## 二、图表规范

| 检查项 | 通过标准 |
|--------|----------|
| 图编号 | 图1, 图2...连续不跳号 |
| 表编号 | 表1, 表2...连续不跳号 |
| 三线表 | 顶线1.5pt + 表头下线0.75pt + 底线1.5pt |
| 图标题 | 图在下，标题在下；表在上，标题在上 |
| 坐标轴 | 含变量名+单位 |
| 引用 | 正文有"如图X所示""如表X所示" |

---

## 三、数学表达

| 检查项 | 通过标准 |
|--------|----------|
| 公式编号 | 重要公式有编号 (1), (2)... |
| 公式环境 | 居中，与上下文分行 |
| 变量字体 | 标量用斜体，向量/矩阵用粗体（至少一致） |

---

## 四、参考文献

| 检查项 | 通过标准 |
|--------|----------|
| 数量 | ≥ 5 篇（< 5 扣 2 分） |
| 格式 | GB/T 7714 标准 |
| 引用匹配 | 正文中每处 [X] 在参考文献列表中有对应 |
| 类型 | 至少含 1 篇教材/论文 + 1 篇官方文档 |

---

## 五、语言表达

| 问题 | 扣分 |
|------|------|
| 大段口语化表述 | -2 |
| 图表前无引导句（直接扔一张图） | -2 |
| 关键术语不统一（一会儿"优化"一会儿"最优化"） | -1 |
| 明显语法错误 | -1/处 |
