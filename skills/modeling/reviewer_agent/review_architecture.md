# Review Architecture — 双层审查体系

> 治理后架构：AI 深度审查 + 队员快速自查，分工明确

---

## 双层架构

```
                    ┌──────────────────────┐
                    │    论文生成完成        │
                    └──────────┬───────────┘
                               │
              ┌────────────────┼────────────────┐
              ▼                                 ▼
   ┌──────────────────────┐        ┌──────────────────────┐
   │   Layer 1: 快速自查   │        │  Layer 2: AI 深度审查  │
   │   skills/review/      │        │  reviewer_agent/      │
   │                      │        │                      │
   │  使用者: 参赛队员      │        │  使用者: AI Agent      │
   │  耗时:  10-15分钟     │        │  耗时:  完整执行        │
   │  粒度:  关键检查点     │        │  粒度:  逐维打分+扣分    │
   │  输出:  ✅/❌ 标记    │        │  输出:  评分报告+建议    │
   └──────────────────────┘        └──────────┬───────────┘
                                              │
                                     ┌───────┴───────────────────┐
                                     ▼                           ▼
                              评分 ≥ 85                    评分 < 85
                           → 直接通过 S8              → 三档处理（见下）
                                                       70-84 → S6 修改（≤3轮）
                                                       65-69 → S6 重写（≤2轮）
                                                       <65 → S2 重建模
```

---

## Layer 1: 快速自查 (skills/review/)

**文件**:
| 文件 | 内容 |
|------|------|
| `常见失分问题.md` | 8类高频失分 + 修复方法 |
| `数学建模论文审查标准.md` | 7章逐章检查清单 |
| `README.md` | 本层定位说明 |

**使用时机**: 论文完成后、提交前

**特点**:
- 低认知负担：每条检查点一句话，不需要理解评分体系
- 快速扫查：10-15 分钟完成
- 关注"是否遗漏"而非"好不好"

---

## Layer 2: AI 深度审查 (reviewer_agent/)

**文件**:
| 文件 | 用途 |
|------|------|
| `evaluation_framework.md` | 评审框架总则 |
| `scoring_rules.md` | 6维100分评分（Canonical） |
| `model_review_rules.md` | 按模型类型的专项审查 |
| `mathematical_check_rules.md` | 数学严谨性检查 |
| `innovation_check_rules.md` | 创新性评估（L0-L3） |
| `paper_quality_rules.md` | 论文规范性检查 |
| `improvement_strategy.md` | 问题→修改动作映射 |
| `review_report_template.md` | 评审报告输出模板 |

**使用时机**: AI 生成论文后自动执行（S7 REVIEW 阶段）

**特点**:
- 深度：逐维度打分，每项有具体扣分原因
- 闭环：发现问题 → 定位 → 修改 → 重审（最多3轮）
- 竞赛对标：评分等级对应国一/国二/省一/省二

---

## 闭环流程

```
Paper Agent 生成论文
    │
    ▼
Layer 2: reviewer_agent/ 执行审查（使用 `evaluation_protocol.md` 评分标准）
    │
    ├── 评分 ≥ 85 → 输出最终论文 → S8 DONE
    │
    ├── 评分 70-84 → improvement_strategy.md 生成修改建议
    │       │
    │       ▼
    │   Paper Agent 按建议修改 → 再次审查（最多3轮）
    │       3轮后仍 70-84 → 标注「建议人工润色」→ S8 DONE
    │       3轮后降至 <65 → 退回 S2
    │
    ├── 评分 65-69 → 表达层问题，退回 S6（最多2轮）
    │
    └── 评分 < 65 → 退回 S2 MODEL_SELECTION（模型层重建）

Layer 1: skills/review/ 
    任何时候队员都可以手动执行快速自查
```

## 与旧版的关系

旧版两套审查标准并存的问题已解决：
- `skills/review/math-modeling/` 不再包含深度评分（已移至 reviewer_agent/）
- 保留其"快速自查"的独特价值（常见失分 + 逐章检查）
- reviewer_agent/ 成为唯一权威的深度审查入口
