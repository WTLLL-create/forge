# 模型调用接口

> 知识模块之间的数据交换格式规范。
> 每个阶段有明确的 JSON 结构输入/输出，确保模块间可以接力。

---

## 一、总接口：建模任务描述

```json
{
  "task_id": "唯一任务标识（日期+题目编号）",
  "problem_type": "预测 | 优化 | 评价 | 分类 | 聚类 | 机理 | 综合",
  "model_name": "来自模型选择决策树的叶子节点",
  "data": {
    "source": "CSV文件路径 | Excel文件路径 | 嵌入数据",
    "shape": [500, 12],
    "features": ["列名1", "列名2", "..."],
    "target": "目标变量名（如果有）"
  },
  "objective": "用自然语言描述建模目标",
  "constraints": [
    "约束1描述",
    "约束2描述"
  ],
  "checkpoints": ["人工确认点1", "人工确认点2"]
}
```

---

## 二、模块间数据交换

### 2.1 题型识别 → 模型选择决策树

```
输入（来自题型识别）:
{
  "problem_type": "优化",
  "sub_type": "资源分配",
  "solution_level": "经典方法",
  "keywords": ["最大利润", "约束", "生产计划"],
  "data_characteristics": {
    "has_time_dimension": false,
    "has_labels": false,
    "sample_size": 1,
    "feature_count": 2
  }
}

输出（来自决策树）:
{
  "model_name": "线性规划",
  "selection_reason": [
    "目标函数和约束都是线性的",
    "决策变量连续",
    "属于资源分配子类型"
  ],
  "rejected_models": [
    {"name": "非线性优化", "reason": "问题本身是线性的，不需要非线性方法"},
    {"name": "整数规划", "reason": "没有整数约束"}
  ],
  "failover_model": "混合整数规划（如果需要增加整数约束）"
}
```

### 2.2 模型选择 → 求解流程

```
输入（来自决策树）:
{
  "model_name": "线性规划",
  "selection_reason": [...],
  "failover_model": "混合整数规划"
}

输出（来自求解流程 Step 1 形式化）:
{
  "math_form": {
    "variables": "x = [x_A, x_B]",
    "objective": "max 300*x_A + 200*x_B",
    "constraints": [
      "2*x_A + 4*x_B ≤ 100",
      "3*x_A + x_B ≤ 80",
      "x_A ≥ 0, x_B ≥ 0"
    ]
  }
}
```

### 2.3 求解流程 → data_processing Skill

```
输入（需要处理的数据）:
{
  "data_source": "raw/sales.csv",
  "required_operations": [
    "缺失值检测与填充",
    "异常值检测(IQR)",
    "日期格式标准化"
  ],
  "output_format": "numpy.ndarray"
}

输出（清洗后数据）:
{
  "clean_data_shape": [500, 12],
  "missing_handled": {"col_A": "中位数填充(3个)", "col_B": "前向填充(7个)"},
  "outliers_handled": {"amount": "IQR截断(5个)"},
  "feature_matrix": "numpy.ndarray (500, 12)",
  "target_vector": "numpy.ndarray (500,)",
  "feature_names": ["feat1", "feat2", "..."]
}
```

### 2.4 求解流程 → numerical_computing Skill

```
输入（数学问题）:
{
  "problem_type": "linear_programming",
  "params": {
    "c": [300, 200],
    "A_ub": [[2, 4], [3, 1]],
    "b_ub": [100, 80],
    "bounds": [[0, null], [0, null]]
  },
  "solver": "linprog",
  "solver_method": "highs"
}

输出（求解结果）:
{
  "status": "success",
  "x_opt": [22.0, 14.0],
  "f_opt": 9400,
  "iterations": 2,
  "constraint_satisfaction": {
    "钢材": "100/100 (100%)",
    "工时": "80/80 (100%)"
  }
}
```

### 2.5 求解结果 → 论文生成

```
输入（所有结果汇总）:
{
  "sections": [
    {"name": "数据预处理", "figures": ["fig1_missing_matrix.png"], "tables": ["tab1_descriptive.csv"]},
    {"name": "问题1求解", "figures": ["fig2_optimal_solution.png"], "tables": ["tab2_solution.csv"]},
    {"name": "问题2求解", "figures": ["fig3_pareto.png"], "tables": ["tab3_comparison.csv"]}
  ],
  "results_text": {
    "问题1": "在给定资源约束下，最优方案为生产A产品22件、B产品14件，最大利润9400元...",
    "问题2": "通过多目标优化，帕累托前沿显示..."
  }
}
```

## 三、模型→模块映射表

| 问题类型 | 典型模型 | 数据模块 | 计算模块 | 外部依赖 |
|----------|---------|---------|---------|---------|
| 预测 | ARIMA/GM(1,1) | data_processing | numerical_computing | statsmodels |
| 预测 | 曲线拟合 | data_processing | numerical_computing (curve_fit) | — |
| 优化 | 线性规划 | — | numerical_computing (linprog) | — |
| 优化 | 非线性优化 | data_processing | numerical_computing (minimize) | — |
| 优化 | 整数规划 | — | numerical_computing (milp) | — |
| 评价 | AHP/TOPSIS | data_processing | numerical_computing (numpy) | — |
| 评价 | 熵权法 | data_processing | numerical_computing (numpy) | — |
| 分类 | Logistic/RF | data_processing | numerical_computing | sklearn |
| 聚类 | K-means/DBSCAN | data_processing | numerical_computing | sklearn |
| 机理 | ODE求解 | — | numerical_computing (solve_ivp) | — |
| 机理 | PDE求解 | — | 自定义差分/有限元 | — |
| 统计 | t检验/ANOVA | data_processing | numerical_computing (stats) | — |
| 统计 | 相关分析 | data_processing | numerical_computing (pearsonr) | — |
| 时间序列 | 滑动平均/分解 | data_processing (rolling/resample) | — | — |

## 四、调用链示例

### 示例：工厂生产计划优化

```
用户输入: "某工厂...求最大利润方案"

题型识别:
  → problem_type: "优化", sub_type: "资源分配"

模型选择决策树:
  → model_name: "线性规划"

模型求解流程 Step 1:
  → math_form: {objective: "max 300x_A+200x_B", constraints: [...]}

模型求解流程 Step 3:
  → 调用 numerical_computing → scipy.optimize.linprog

求解结果:
  → {x_opt: [22, 14], f_opt: 9400}

论文生成:
  → 第七章节: 问题1建模与求解
```

## 五、数据流转图

```
原始文件(CSV/Excel)
    │
    ▼
data_processing Skill ──→ 干净的 numpy.ndarray
    │                           │
    │                           ▼
    │              numerical_computing Skill
    │                    │
    │                    ├─ linprog / minimize / curve_fit / solve / eig
    │                    ├─ solve_ivp / quad
    │                    └─ stats.ttest / pearsonr / ...
    │                    │
    ▼                    ▼
模型调用接口 ──→ 统一 JSON 输出
    │
    ▼
论文生成 (math-modeling-paper Skill)
```
